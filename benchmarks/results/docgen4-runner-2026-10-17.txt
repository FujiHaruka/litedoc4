doc-gen4 and litedoc4 building Mathlib v4.35.0's documentation from nothing, one after the other on one runner
==============================================================================================================
Date: 2026-10-17. One job on a GitHub-hosted ubuntu-latest runner (run 39033244521, branch probe/docgen4-runner,
commit 55e0f1903bb99d287cad499e795f7b97f1a513f5, deleted afterwards; the workflow and the driver are reproduced
under CODE). Both arms ran on the same machine in sequence, so runner-to-runner variation does not enter the
comparison. One run per arm: single measurements, not converged series.

QUESTIONS
---------
(1) How long does doc-gen4 take to build Mathlib's documentation from nothing on a standard runner?
(2) How long does litedoc4 take to build Mathlib's site from nothing on the same machine?
(3) Does doc-gen4 stall on memory there, as the M1 build (benchmarks/doc-gen4-report.md section 4.6) did?
(4) What does Mathlib's own documentation job take (leanprover-community/mathlib4_docs, docs.yaml)?

SCOPE
-----
- litedoc4: the 8,625 modules of Mathlib v4.35.0's `Mathlib` library; 8,631 HTML pages, 31,956 files, 64,065,253 B
  stored (162,300 KiB on disk). Dependencies (17 roots from 8 packages + core) are linked, not documented.
  hosting/mathlib/litedoc4.toml (no_equations_under = Mathlib.Meta, Mathlib.Tactic), equations and refs on.
- doc-gen4: Mathlib:docs walks the import closure. Its log has 8,626 "Built mathlib/..." lines, plus 195 batteries,
  132 aesop, 35 importGraph, 14 Qq, 13 proofwidgets, 13 plausible, 4 LeanSearchClient, and one `coreDocs` job for
  Lean's own Init/Std/Lean/Lake (767 s by itself; it ran in parallel with module jobs). Output: 11,548 HTML files,
  2,548,468,696 B under .lake/build/doc; 1,223,721,291 B under doc-data; api-docs.db 836,108 KiB.
- So doc-gen4 documents more: 11,548 - 8,631 = 2,917 more HTML files (dependencies and core). Bytes: doc-gen4's
  .lake/build/doc is 2,548,468,696 B; litedoc4's site is 464,797,287 B before its own compression and
  64,065,253 B as written. The 12x above is the cost of each tool's own definition of "Mathlib's documentation",
  not a per-module ratio.

WHAT IS NOT MEASURED
--------------------
- Repeat runs; variation between runners; cold vs warm on the runner.
- doc-gen4 restricted to the same 8,625 modules (it has no switch for that); litedoc4 documenting core and deps.
- Where doc-gen4's 7,240 s of system time goes.
- Why the runner did not stall where the M1 did (parallelism is the inference above).
- The hardware of Mathlib's own doc-gen runners.

#!/bin/bash
# litedoc4 and doc-gen4 building Mathlib's documentation from nothing, one after the
# other on one runner. One subcommand per workflow step; everything it writes goes to $LOGS.
#   probe.sh start               timings header, the machine at the start, the repository's HEAD
#   probe.sh free-disk           the runner's preinstalled toolchains this run does not use
#   probe.sh elan                elan with no default toolchain
#   probe.sh litedoc4-bin        litedoc4 built as tools/mathlib-site.sh setup builds it
#   probe.sh mathlib             Mathlib $MATHLIB_TAG (--depth 1) and `lake exe cache get`
#   probe.sh mathlib-build       `lake build --no-build Mathlib`, then `lake build Mathlib`
#   probe.sh litedoc4            the litedoc4 arm: one version, empty --out
#   probe.sh docgen-ws           the workaround workspace of mathlib4_docs' docs.yaml
#   probe.sh docgen-build        `lake build doc-gen4`
#   probe.sh docgen-minutes      the doc-gen4 step's timeout-minutes into $GITHUB_OUTPUT
#   probe.sh docgen              the doc-gen4 arm: Mathlib:docs, then Mathlib:docsHeader
#   probe.sh end                 the machine at the end
# Environment: JOB_START (epoch seconds, set by the workflow's first step), SMOKE (1: no
# litedoc4 arm, doc-gen4 on one module), PROBE_WORK, LOGS, MATHLIB_TAG, DOCGEN_REV,
# JOB_MINUTES, RESERVE_MINUTES, STEP_RESERVE_MINUTES, LITEDOC4_TIMEOUT, MATHLIB_BUILD_TIMEOUT.
set -euo pipefail

P=$(cd "$(dirname "$0")" && pwd)
ROOT=$(cd "$P/../.." && pwd)
W=${PROBE_WORK:-$HOME/probe-work}
LOGS=${LOGS:-$W/logs}
MATHLIB=$W/mathlib
WS=$W/workaround
LD4OUT=$W/litedoc4-out
LITEDOC4=$ROOT/.lake/build/bin/litedoc4
TAG=${MATHLIB_TAG:-v4.35.0}
DOCGEN_REV=${DOCGEN_REV:-v4.35.0}
SMOKE=${SMOKE:-1}
SMOKE_MODULE=${SMOKE_MODULE:-Mathlib.Logic.Pairwise}
JOB_MINUTES=${JOB_MINUTES:-360}
RESERVE_MINUTES=${RESERVE_MINUTES:-30}
STEP_RESERVE_MINUTES=${STEP_RESERVE_MINUTES:-15}
LITEDOC4_TIMEOUT=${LITEDOC4_TIMEOUT:-7200}
MATHLIB_BUILD_TIMEOUT=${MATHLIB_BUILD_TIMEOUT:-1800}
mkdir -p "$W" "$LOGS"
export PATH="$HOME/.elan/bin:$PATH"

utc() { date -u +%Y-%m-%dT%H:%M:%SZ; }

timing_line() {
  printf '%s\t%s\t%s\t%s\t%s\n' "$1" "$2" "$3" "$4" "$5" | tee -a "$LOGS/timings.txt"
}

timed() {
  local name=$1; shift
  local s0 t0 t1 rc
  s0=$(utc); t0=$(date +%s.%N)
  if "$@"; then rc=0; else rc=$?; fi
  t1=$(date +%s.%N)
  timing_line "$name" "$s0" "$(utc)" "$(awk -v a="$t0" -v b="$t1" 'BEGIN{printf "%.1f", b-a}')" "$rc"
  return "$rc"
}

remaining() {
  : "${JOB_START:?JOB_START comes from the first workflow step}"
  echo $(( JOB_START + (JOB_MINUTES - RESERVE_MINUTES) * 60 - $(date +%s) ))
}

record() {
  {
    echo "## date"; utc
    echo "## image"; echo "ImageOS=${ImageOS:-?} ImageVersion=${ImageVersion:-?} RUNNER_OS=${RUNNER_OS:-?}"
    echo "## kernel"; uname -a
    echo "## nproc"; nproc || true
    echo "## lscpu"; lscpu || true
    echo "## meminfo"; cat /proc/meminfo || true
    echo "## swap"; swapon --show || true; free -b || true
    echo "## vmstat"; grep -E '^(pswpin|pswpout|pgmajfault|oom_kill) ' /proc/vmstat || true
    echo "## df"; df -h || true
    echo "## vm sysctl"; sysctl vm.swappiness vm.overcommit_memory 2>/dev/null || true
    echo "## oom"; sudo -n dmesg 2>/dev/null | grep -iE 'out of memory|oom-kill|killed process' || echo "(none)"
  } > "$LOGS/machine-$1.txt" 2>&1
}

tree_pids() {
  ps -e -o pid=,ppid= | awk -v root="$1" '
    { parent[$1] = $2 }
    END {
      inside[root] = 1
      grew = 1
      while (grew) {
        grew = 0
        for (p in parent) if (!(p in inside) && (parent[p] in inside)) { inside[p] = 1; grew = 1 }
      }
      for (p in inside) print p
    }'
}

sample() {
  local root=$1 out=$2 top=$3 tick=0
  printf 't\tVmRSS\tRssAnon\tRssFile\tVmSwap\tMemAvailable\tCached\tSwapFree\tpswpin\tpswpout\tpgmajfault\tnprocs\tRootAvailKB\n' > "$out"
  : > "$top"
  while kill -0 "$root" 2>/dev/null; do
    local files rss anon file swap n mi vs disk
    files=$(tree_pids "$root" | sed 's#.*#/proc/&/status#')
    read -r rss anon file swap n <<<"$({ cat $files 2>/dev/null || true; } | awk '
      /^VmRSS:/ { a += $2 } /^RssAnon:/ { b += $2 } /^RssFile:/ { c += $2 } /^VmSwap:/ { d += $2 }
      /^Pid:/ { n++ }
      END { printf "%d %d %d %d %d\n", a, b, c, d, n }')"
    mi=$(awk '/^(MemAvailable|Cached|SwapFree):/{printf "%s\t", $2}' /proc/meminfo 2>/dev/null || true)
    vs=$(awk '/^(pswpin|pswpout|pgmajfault) /{printf "%s\t", $2}' /proc/vmstat 2>/dev/null || true)
    disk=$(df -k --output=avail / 2>/dev/null | tail -1 | tr -d ' ' || true)
    printf '%s\t%s\t%s\t%s\t%s\t%s%s%s\t%s\n' "$(date +%s)" "$rss" "$anon" "$file" "$swap" "$mi" "$vs" "$n" "$disk" >> "$out"
    if [ $((tick % 12)) -eq 0 ]; then
      { echo "== $(utc)"; ps -eo pid,ppid,rss,etimes,args --sort=-rss 2>/dev/null | head -8 | cut -c1-240; } >> "$top" || true
    fi
    tick=$((tick + 1))
    sleep 5
  done
}

measure() {
  local name=$1 budget=$2 log=$3; shift 3
  local s0 t0 t1 rc root sp wall outcome progress
  if [ "$budget" -lt 60 ]; then
    timing_line "$name" "$(utc)" "$(utc)" 0 124
    printf 'outcome\tnot started: %s s left before the deadline\n' "$budget" | tee "$LOGS/$name-outcome.txt"
    return 124
  fi
  record "before-$name"
  echo "$name: budget $budget s, $*"
  s0=$(utc); t0=$(date +%s)
  /usr/bin/time -v -o "$LOGS/$name.time" timeout -k 120 "$budget" "$@" > "$log" 2>&1 &
  root=$!
  sample "$root" "$LOGS/$name-sampler.tsv" "$LOGS/$name-top.txt" &
  sp=$!
  if wait "$root"; then rc=0; else rc=$?; fi
  t1=$(date +%s)
  wait "$sp" || true
  wall=$((t1 - t0))
  timing_line "$name" "$s0" "$(utc)" "$wall" "$rc"
  record "after-$name"
  if [ "$rc" -eq 0 ]; then outcome=finished
  elif { [ "$rc" -eq 124 ] || [ "$rc" -eq 137 ]; } && [ "$wall" -ge $((budget - 1)) ]; then outcome=timeout
  else outcome=failed
  fi
  progress=$(grep -oE '\[[0-9]+/[0-9]+\]' "$log" | tail -1 || true)
  {
    printf 'outcome\t%s\n' "$outcome"
    printf 'exit\t%s\n' "$rc"
    printf 'wall_s\t%s\n' "$wall"
    printf 'budget_s\t%s\n' "$budget"
    printf 'command\t%s\n' "$*"
    printf 'last_progress\t%s\n' "${progress:-(none)}"
    printf 'last_line\t%s\n' "$(tail -1 "$log" | cut -c1-400)"
  } | tee "$LOGS/$name-outcome.txt"
  return "$rc"
}

tree_size() {
  local dir=$1 listing
  if [ -e "$dir" ]; then
    listing=$(mktemp)
    find "$dir" -type f -printf '%s %p\n' > "$listing"
    printf '%s\tfiles %s\thtml %s\tbytes %s\tdisk_kb %s\n' "$dir" \
      "$(wc -l < "$listing")" "$(grep -c '\.html$' "$listing" || true)" \
      "$(awk '{ s += $1 } END { printf "%d", s }' "$listing")" "$(du -sk "$dir" | cut -f1)"
    rm -f "$listing"
  else
    printf '%s\tabsent\n' "$dir"
  fi
}

    exit 0
    ;;

    timed mathlib-nobuild lake build --no-build Mathlib > "$LOGS/mathlib-nobuild.log" 2>&1 || true
    timed mathlib-build env LEAN_ABORT_ON_PANIC=1 timeout -k 60 "$MATHLIB_BUILD_TIMEOUT" lake build Mathlib > "$LOGS/mathlib-build.log" 2>&1
    tail -3 "$LOGS/mathlib-build.log"
    exit 0
    ;;
  litedoc4)
    budget=$(remaining)
    if [ "$budget" -gt "$LITEDOC4_TIMEOUT" ]; then budget=$LITEDOC4_TIMEOUT; fi
    rm -rf "$LD4OUT"; mkdir -p "$LD4OUT"
    rc=0
    measure litedoc4 "$budget" "$LOGS/litedoc4.log" \
      "$LITEDOC4" build --root "$MATHLIB" --lib Mathlib --out "$LD4OUT" --jobs 4 \
      --config "$ROOT/hosting/mathlib/litedoc4.toml" --lake "$(command -v lake)" \
      --timings "$LOGS/litedoc4-timings.jsonl" || rc=$?
    {
      tree_size "$LD4OUT/site"
      for d in "$LD4OUT"/*; do
        if [ -d "$d" ]; then printf '%s\tdisk_kb %s\n' "$d" "$(du -sk "$d" | cut -f1)"; fi
      done
      printf '%s\tdisk_kb %s\n' "$LD4OUT" "$(du -sk "$LD4OUT" | cut -f1)"
    } | tee "$LOGS/litedoc4-output.txt"
    for f in "$LD4OUT"/*.json; do
      if [ -f "$f" ]; then cp "$f" "$LOGS/litedoc4-out-$(basename "$f")"; fi
    done
    rm -rf "$LD4OUT"
    df -h / | tee -a "$LOGS/litedoc4-output.txt"
    exit "$rc"
    ;;
  docgen-ws)
    rm -rf "$WS"
    cd "$W"
    timed docgen-lake-new lake "+$(cat "$MATHLIB/lean-toolchain")" new workaround lib > "$LOGS/docgen-lake-new.log" 2>&1
    cd "$WS"
    cp -f "$MATHLIB/lean-toolchain" .
    rm -f lakefile.lean
    printf '%s\n' \
      'name = "workaround"' \
      'defaultTargets = ["workaround"]' \
      '' \
      '[[lean_lib]]' \
      'name = "Workaround"' \
      '' \
      '[[require]]' \
      'scope = "leanprover"' \
      'name = "doc-gen4"' \
      "rev = \"$DOCGEN_REV\"" \
      '' \
      '[[require]]' \
      'name = "mathlib"' \
      "path = \"../$(basename "$MATHLIB")\"" > lakefile.toml
    cp lakefile.toml "$LOGS/workaround-lakefile.toml"
    if [ ! -d .git ]; then git init -q; fi
    git config user.email "mathlib4_docs@leanprover-community.github.io"
    git config user.name "mathlib4_docs CI"
    git add .
    git commit -q -m workaround
    git remote add origin "https://github.com/leanprover-community/workaround"
    mkdir -p .lake/packages
    timed docgen-copy-packages cp -r "$MATHLIB"/.lake/packages/* .lake/packages
    MATHLIB_NO_CACHE_ON_UPDATE=1 timed docgen-lake-update lake update > "$LOGS/docgen-lake-update.log" 2>&1
    mkdir -p docs
    cp "$MATHLIB/docs/references.bib" docs/references.bib
    cp lake-manifest.json "$LOGS/workaround-lake-manifest.json"
    cp "$MATHLIB/lake-manifest.json" "$LOGS/mathlib-lake-manifest.json"
    python3 -I - "$MATHLIB/lake-manifest.json" lake-manifest.json <<'PY' | tee "$LOGS/docgen-manifest-diff.txt"
import json, sys
def revs(path):
    return {p["name"]: p.get("rev", p.get("dir", "?")) for p in json.load(open(path))["packages"]}
mathlib, workaround = revs(sys.argv[1]), revs(sys.argv[2])
for name in sorted(set(mathlib) | set(workaround)):
    a, b = mathlib.get(name, "-"), workaround.get(name, "-")
    print(f"{'same' if a == b else 'DIFF'}\t{name}\tmathlib {a}\tworkaround {b}")
PY
    printf 'workaround .lake\t%s KiB\n' "$(du -sk .lake | cut -f1)" | tee -a "$LOGS/run.txt"
    exit 0
    ;;
  docgen-build)
    cd "$WS"
    timed docgen-build lake build doc-gen4 > "$LOGS/docgen-build.log" 2>&1
    tail -3 "$LOGS/docgen-build.log"
    exit 0
    ;;
  docgen-minutes)
    : "${JOB_START:?JOB_START comes from the first workflow step}"
    minutes=$(( (JOB_START + (JOB_MINUTES - STEP_RESERVE_MINUTES) * 60 - $(date +%s)) / 60 ))
    if [ "$minutes" -lt 1 ]; then minutes=1; fi
    echo "minutes=$minutes" | tee -a "${GITHUB_OUTPUT:-/dev/null}"
    exit 0
    ;;
  docgen)
    cd "$WS"
    rc=0
    if [ "$SMOKE" = 1 ]; then
      measure docgen4-smoke "$(remaining)" "$LOGS/docgen4-smoke.log" lake build "+$SMOKE_MODULE:docs" || rc=$?
    else
      measure docgen4-docs "$(remaining)" "$LOGS/docgen4-docs.log" lake build Mathlib:docs || rc=$?
      if [ "$rc" -eq 0 ]; then
        measure docgen4-header "$(remaining)" "$LOGS/docgen4-header.log" lake build Mathlib:docsHeader || rc=$?
      else
        timing_line docgen4-header - - - skipped
      fi
    fi
    {
      tree_size .lake/build/doc
      tree_size .lake/build/doc-data
      for f in .lake/build/api-docs.db*; do
        if [ -f "$f" ]; then printf '%s\tdisk_kb %s\n' "$f" "$(du -sk "$f" | cut -f1)"; fi
      done
      df -h /
    } | tee "$LOGS/docgen4-output.txt"
    exit "$rc"
    ;;
  end)
    record end
    ls -la "$LOGS"
    exit 0
    ;;
  *)
    sed -n '2,/^set -/p' "$0" | sed '$d'
    exit 2
    ;;
esac
