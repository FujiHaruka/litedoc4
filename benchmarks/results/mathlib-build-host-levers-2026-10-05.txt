The build host for the multi-version build: where the hybrid's memory, CPU and disk go, which levers make them smaller, and print reuse across versions with its falsifier
==================================================================================================================================================================
Date: 2026-10-05. Context: docs/multiversion/plan.md U5 (can the build host carry it), U9 (the reader and the hybrid,
"per version end to end ~6.5 min wall, ~19 min CPU"), D2 (all versions from nothing in <= 2 h on one machine, one new
release in <= 15 min), D3 (build host), D5 (content-addressed declarations), D10 (one reader, every version printed
by the newest Lean and Mathlib). The hybrid is the one of benchmarks/results/mathlib-hybrid-full-extraction-2026-10-05.txt
(the "full-extraction log" below), rebuilt from that log's CODE section and the reader log's
(benchmarks/results/olean-reader-prototype-2026-10-04.txt) and extended with inert instrumentation and a key pass. A
measurement in scratch Lake projects on this M1; nothing in src/ or extractor/ was changed. The runner part is a
prepared, not-yet-run probe (PROBE below).

QUESTIONS
---------
(1) Does the rebuilt hybrid reproduce the full-extraction log?
(2) Memory split: of the hybrid's ~9 GB, how much is the newest Mathlib import, the decoded old data (with and
    without proofs), the extractor's working set at 1, 2 and 4 jobs? Do the jobs share one environment? Which lever
    brings it under 12 GB and under 8 GB, at what time cost?
(3) Print reuse: every version is printed by the same newest printer, so a declaration whose "print key" is equal
    to one already printed need not be printed again. Design the key, falsify it on Mathlib v4.31.0 (hybrid) against
    v4.34.1 (native), and price the key pass.
(4) The smaller levers: one newest import per process for all versions, proofs skipped, reading from the cache's
    compressed archives, fewer or more jobs.
(5) The "one new release in 15 min" line and the from-nothing line for 11 and 51 versions, on this M1 and
    (theoretical) on a GitHub-hosted ubuntu-latest runner.

    byte-identical (`diff -r`).

    - The jobs share one environment in one process (threads of one `IO.asTask` pool over one `env`, read in the code;
      measured: 1 -> 4 jobs adds 1.27 GB, not three more environments).
    - The extraction's share grows linearly with the declarations done (sampler: native 0.5 -> 4.0 GB over the
      analysis; hybrid 1 job 4.0 -> 6.5 GB): it is the results held until the IR is written, plus whatever the
      equation generator caches. Tagged code alone is 1.1 GB of it (measured natively by ablation); the rest is not
      attributed.
    - Swap: the machine had 3.80 GB of swap in use before the reproduction run, 4.11 GB at most during it, 3.87 GB
      after (measured, `vm.swapusage`). The full-extraction log's "~3.5 GB swap, no baseline" was the machine's
      baseline, not the hybrid's. What macOS did instead is compress: up to 5.1 GB of the hybrid process's memory was
      held compressed (`top` CMPRS, measured). Linux on the runner does not compress, so the number that transfers is
      the dirty total (9.1 GB at 4 jobs), plus whatever of the 5.2 GB of mapped newest oleans the run keeps touching.
    - Under 12 GB: already, at any job count, as dirty memory (measured). Under 8 GB: 1 job (7.83 GB, +288 s of
      extraction, measured); 2 jobs is 8.29 GB (+84 s). Streaming the IR per module instead of holding every result
      would take most of the +3.6-4.9 GB away (theoretical; 1.1 GB of it measured as tagged code).
(3) Print reuse. The key is a set of hashes of what the printed fields are computed from (KEY below). Falsified on
    the 308,089 declarations present in both Mathlib v4.31.0 (hybrid) and v4.34.1 (native), 3 minor releases apart,
    printed fields equal on 277,504 (90.07%):

                                                                           among key-equal     key-different
      G7 (the key proposed)                             221,484  71.89%      6                  56,026
      G2 = G7 + reducibility + reducible values         157,193  51.02%      4                 120,315
      F0 strict (full types and values)                  87,998  28.56%      4                 189,510
      F9 own declaration only, as shown                 254,322  82.55%     27                  23,209
    Every hole is classified (HOLES): the 4 that every variant has are 2 declarations printed through a notation
    whose delaborator synthesises instances (`⊔` vs `max` on Prop) and 2 parent-projection paths in printed instance
    values (cause not isolated); G7 adds 2 equation-generation failures in the hybrid (the full-extraction log's
    class G). By time, the key-equal declarations are 60.6% of the v4.31.0 analysis time under G7 (36.6% under G2;
    measured with the per-declaration profile). The key pass takes 101 s single-threaded per version on either side
    (557,366 / 580,218 candidates), against 779 s of printing CPU (pp + equations) in the 4-job extraction: 7.7x
    cheaper than what it can save, not free. Net (theoretical): ~370 s CPU saved per old version, but on the M1
    wall clock only ~25 s single-threaded or ~100 s with the key pass parallelised, because decoding and assembly
    (141 s) do not shrink.
    Consecutive releases share more content (other log: 97.89% of declarations at the minor pair v4.32.2 -> v4.33.0,
    99.9994% at the patch pair, mathlib-release-sharing-2026-10-04.txt), but the key-equal share was measured at 3
    minors apart only; at 1 apart it is unmeasured.
(4) Smaller levers (all on M1):
    - Proofs omitted is already the design: kept, decoding takes 110.1 s instead of 82.5 s and the heap 7.69 GB
      instead of 3.19 GB (measured). The task's "88 -> ~45 s" premise mixed the prototype's 11-extension decoding
      with this one; the 88 s of the full-extraction log were already proofs-omitted (its CONDITIONS say so).
    - One newest import per process, swapping old data between versions: decoding + assembling twice in one process
      does not release the first round (measured): footprint 4.0 -> 14.8 GB with the environment leaked (as the
      extractor does), 4.1 -> 13.5 GB with `leakEnv := false`. Two causes: the old round stays (heap 3.6 -> 6.0 GB
      after the second decode even unleaked), and the second newest import cannot mmap the oleans at their address
      (taken by the first) and reads them into 6.9 GB of malloc. Only the newest `importModulesCore` (12.5 s per
      version) could be shared, and only by keeping its ModuleData rather than importing again (theoretical).
    - Archives: one version's 8,908 cache archives are 451.4 MB (v4.34.1, measured); extracted they are 6.90 GB, of
      which the reader needs .olean / .olean.server / .olean.private / .ir = 6.10 GB; .c (0.49 GB) and .ilean
      (0.29 GB) are never read (.ilean only if D10 mechanism 3 is built). Reading each old version module by module
      straight from the archives turns 6.9 GB of disk into 0.45 GB, at the same decompression work: leantar unpacked
      a 5.17 GiB set in 14.4-14.5 s here (measured 2026-08, ci-warmstart-summary.txt). The newest version is
      imported by Lean, which maps files: it stays extracted. Disk is not the runner's problem (87 GB free).
    - Jobs on M1: 1 / 2 / 4 jobs = extraction 517 / 312 / 228 s, CPU (process, minus the key pass) ~755 / ~867 /
      ~1,119 s, footprint 7.83 / 8.29 / 9.10 GB. More jobs cost CPU (E-cores, contention) and memory, and buy wall
      clock. On 2 physical cores with SMT the shape is unmeasured: the probe runs 4 and 2 jobs.
(5) Lines (composition; parts measured where named, the rest theoretical):
    - One new release in 15 min holds only if old versions are not re-printed (D7's "keep each version's output as
      printed when it was added"): the new release is the newest, extracted natively (243 s on M1, measured;
      ~6-8 min on the runner, theoretical) plus toolchain, cache fetch and the multi-version render. Re-printing the
      10 older versions with the new printer is 10 hybrid runs, ~1 h on M1 even with print reuse.
    - From nothing, 11 versions: M1 ~66 min without print reuse (extrapolated: 243 s native newest + 10 x 369 s),
      ~49-61 min with it (theoretical). 51 versions: ~5.2 h without, ~3.8-4.8 h with (theoretical); decoding and assembly
      alone are 50 x 141 s = ~2.0 h (extrapolated). So from nothing at 51 versions does not fit 2 h on one M1 with
      or without print reuse; the runner is slower (~11 min per old version, theoretical: ~2 h for 11, ~9 h for 51).

KEY
---
Two passes of the same code (PrintKey.lean), both in Lean v4.34.1: natively after importing v4.34.1 (`nativekeys`),
and in the hybrid after assembly (`HYBRID_KEYS`). For each candidate the extractor visits, it writes components,
each a 64-bit hash; a key is a set of components. Printed fields covered: type, binders, implicits, typeCode,
binderCode, equations, equationCode, members (all but their docstring), refs as names. Not covered and recomputed
per version: placement (line, col, ranges, index, module, the module of each ref, `generated`, which reads the own
ranges) and the cheap fields (kind, modifiers, doc, attrs, instClass, instTypes, sorry, member docstrings: 12 s of
CPU in the 4-job extraction against 779 s of printing).
Own components:
  N    name, kind, universe parameter names
  T    type (structural hash with binder names and binder kinds); TS the same "as shown": in an application of a
       constant that is not a constructor, arguments in implicit, strict-implicit and instance positions (read off the
       constant's type, no reduction) are a placeholder
  V    value of a definition; VS the same as shown
  E    stored equation lemmas (`f.eq_<n>`, `f.eq_def`), the structural / well-founded / partial-fixpoint recursion
       data, and the lemmas registered by Mathlib's `eqns` attribute (which `irreducible_def` uses; read through the
       extension named `eqnsAttribute`)
Over the constants that survive in the "as shown" type and value (members included), sorted by name:
  SN names; ST types; STS types as shown; SSH shapes (per leading binder its kind and the head of its type, and the
  head of the result: what the app delaborator and field notation read); SLP universe names; SRED reducibility;
  SPROJ projection info; SCLS class; SSTR structure fields and parents; SCOE coercion info; SINST instance and
  priority; SPP pp_nodot / pp_using_anonymous_constructor; SMAT matcher info; SPROT protected; SV values of
  definitions; SRV values of reducible definitions; SAUX values of opaques and matchers; SPSTR the flattened field
  layout of a projection's structure and all its ancestors; SRES name resolution (every reverse alias and every
  suffix of the name resolved as the printer resolves it, in the declaration's namespace and each member's).
The proposed key, G7 = N TS VS E SN SSH SRES SAUX SPSTR SPROJ SCLS SSTR SCOE SPP SMAT SPROT.

THE FALSIFIER
-------------
keycmp2.py (Python) pairs declarations by name between the native v4.34.1 IR and the hybrid v4.31.0 IR (IR-A
322,958, IR-B 311,345, in both 308,089; A only 14,869, B only 3,256), takes the key components of both passes
(580,218 and 557,366 candidates; every declaration of both IRs has components), and for each key variant counts
key-equal / key-different against printed-fields-equal / different. No exception list; a field it does not know
stops it. Made to fail once (measured): on a 20-module copy with one type changed by one character and one
component changed for another declaration, every variant reported exactly 1 key-equal output-different (that
declaration, field `type`) and 1 key-different output-equal (the other), nothing else.
Printed fields equal on 277,504 of 308,089 (90.07%).

  F2  F1 with SSH for STS                           158,623  51.49%      5      118,886
  F4  F2 without SRES                               158,833  51.55%      8      118,679

The first key tried (all referenced constants with full types and their printing data, equivalent to F0 over every
referenced constant instead of the shown ones; the run before the components) was key-equal on 80,204 (26.03%)
with 3 holes. Key iterations, each made to fail on real data first and then fixed:
  - the "as shown" skeleton first dropped hidden arguments of constructor applications too, which structure-instance
    notation prints: 91 holes (`{ toMul := ... }` with renamed parent fields); constructors now keep every argument;
  - name resolution dropped: 3 more holes (`_root_.id`, `Finset.mulAntidiagonal` qualification) -> SRES kept;
  - structure data dropped: 11 more holes (renamed structure fields in printed instances, `acm` ->
    `addCommMonoidSyn`, `smul_vsub_vadd_mem` -> `smul_vsub_vadd_mem'`) -> SSTR kept;
  - a matcher's value (the `match` arms with name literals in `Mathlib.Tactic.Abel.isAtom`) -> SAUX;
  - `irreducible_def` (`nhds`, `tangentConeAt`): the printed equation is the lemma registered by the `eqns`
    attribute, whose type moved from `setOf` to `Set.ofPred` -> E reads that attribute.

HOLES (every key-equal declaration whose printed fields differ, final key pass)
--------------------------------------------------------------------------------
G7, 6 (0.0027% of key-equal):
  H1 (2) sup_Prop_eq, inf_Prop_eq: `(fun x1 x2 => x1 ⊔ x2)` natively, `max x1 x2` in the hybrid; refs lose
     Max.max / Min.min. Same term, same key data; the newest Mathlib's delaborator chooses between `⊔` and `max`
     (`⊓` / `min`) by synthesising an order instance, i.e. it reads the whole instance set, which differs between
     the two versions' data (inferred from the output; the instance query itself was not traced). A key cannot
     carry "every instance"; these are in every variant, F0 included.
  H3 (2) Nat.instMulZeroClass (equation: `Nat.instAddMonoid.toAddZeroClass.toAddZero.toZero` natively,

-------------------------------------
- Time (measured, single-threaded, final key): 101.2 s for 580,218 candidates natively (v4.34.1), 101.1 s for
  557,366 in the hybrid (v4.31.0); the first, coarser keys took 139-153 s. Peak footprint of the native import +
  key pass 1.16 GB (the key pass adds ~0.25 GB over the import).
- Against printing: the 4-job extraction spends 779.1 s of thread time in printing (pp 531.0 + equations 248.1),

- Reusable share at 3 minors apart (v4.31.0 reusing v4.34.1's prints), G7: 221,484 of the 311,345 produced v4.31.0

  the profiler on, so the shares assume the profiler's overhead is proportional). G2: 50.49% by count, 36.64% by
  time.
- Net per old version, G7 (theoretical; premises: the time shares above hold without the profiler, the key pass is

WHAT FAILED, AND WHY
--------------------
1. The first key pass panicked 1,210 times ("unreachable @ extractMainModule" inside Name.append): appending a
   hygienic name (macro scopes) with `++`. The printer itself returns such names unabbreviated; the resolution
   component now does the same, and builds suffixes with `appendCore`. Its keys from that run (k1/k2) were used only
   for the first comparison (26.03% / 3 holes) and its timing; every later pass had 0 panics.
2. The first "as shown" skeleton dropped hidden arguments of constructor applications: 91 holes, all printed
   structure instances. Fixed as in THE FALSIFIER; each later component was added after a hole showed it was
   missing, and each addition was measured against the same two IRs (holes 91 -> 7 -> 4 under G2, 6 under G7).
3. In zsh, one `rm -rf a/ir b/ir c*/ir` with an unmatched glob removed nothing ("no matches found"); caught by
   listing the directories afterwards.
4. A Lean elaboration change: after one more structure field, two field accesses in PrintKey.lean no longer
   elaborated (`hash ·.structName`, `.reducible`); written with explicit types.

/-! A memory snapshot taken by a child process while this one waits, so the numbers belong to a
known point of the run. Inert unless `HYBRID_SNAPSHOT` names the script. -/

def snap (label : String) : IO Unit := do
  let some script ← IO.getEnv "HYBRID_SNAPSHOT" | return
  let pid ← IO.Process.getPID
  let t0 ← IO.monoMsNow
  let out ← IO.Process.output { cmd := script, args := #[toString pid, label] }
  let t1 ← IO.monoMsNow
  IO.eprintln s!"snapshot {label}: paused {t1 - t0} ms (exit {out.exitCode})"

/-! The print key: hashes of what the printed fields of one declaration are computed from, read
from the environment the extractor prints in, written as components so that a key is a choice
of them. -/

@[inline] def mix (h x : UInt64) : UInt64 := mixHash h x

def mixList (h : UInt64) (xs : List UInt64) : UInt64 := xs.foldl mix h

def biCode : BinderInfo → UInt64
  | .default => 0 | .implicit => 1 | .strictImplicit => 2 | .instImplicit => 3

unsafe def hashExprM (e : Expr) : StateM (Std.HashMap USize UInt64) UInt64 := do
  let p := ptrAddrUnsafe e
  if let some h := (← get)[p]? then return h
  let h ← match e with
    | .bvar i => pure (mix 1 (hash i))
    | .fvar f => pure (mix 2 (hash f.name))
    | .mvar m => pure (mix 3 (hash m.name))
    | .sort l => pure (mix 4 (hash l))
    | .const n ls => pure (mix (mix 5 (hash n)) (hash ls))
    | .app f a => do let x ← hashExprM f; let y ← hashExprM a; pure (mix (mix 6 x) y)
    | .lam n t b bi => do
      let x ← hashExprM t; let y ← hashExprM b
      pure (mixList 7 [hash n, biCode bi, x, y])
    | .forallE n t b bi => do
      let x ← hashExprM t; let y ← hashExprM b
      pure (mixList 8 [hash n, biCode bi, x, y])
    | .letE n t v b nd => do
      let x ← hashExprM t; let y ← hashExprM v; let z ← hashExprM b
      pure (mixList 9 [hash n, hash nd, x, y, z])
    | .lit l => pure (mix 10 (hash l))
    | .mdata d b => do
      let y ← hashExprM b
      pure (mixList 11 (d.entries.map (fun (k, v) => mix (hash k) (hash (toString v))) ++ [y]))
    | .proj s i b => do let y ← hashExprM b; pure (mixList 12 [hash s, hash i, y])
  modify (·.insert p h)
  return h

unsafe def hashExpr (e : Expr) : UInt64 := (hashExprM e |>.run' {}) |> Id.run

/-- Binder infos of a constant's leading `∀`s, read off its type without reduction. -/
def binderInfos (env : Environment) (c : Name) : Array BinderInfo := Id.run do
  let some ci := env.find? c | return #[]
  let mut t := ci.type
  let mut out := #[]
  while true do
    match t with
    | .forallE _ _ b bi => out := out.push bi; t := b
    | _ => break
  return out

structure SkelState where
  memo : Std.HashMap USize UInt64 := {}
  bis : Std.HashMap Name (Array BinderInfo) := {}
  consts : NameSet := {}

/-- The hash of what the printer shows by default: an application of a constant loses its
implicit, strict-implicit and instance arguments (hidden unless `@` is printed); everything else
as `hashExprM`. Also collects the constants that survive. -/
unsafe def hashSkelM (env : Environment) (e : Expr) : StateM SkelState UInt64 := do
  let p := ptrAddrUnsafe e
  if let some h := (← get).memo[p]? then return h
  let h ← match e with
    | .app .. =>
      let fn := e.getAppFn
      let args := e.getAppArgs
      match fn with
      | .const c ls => do
        modify fun st => { st with consts := st.consts.insert c }
        let bis ← match (← get).bis[c]? with
          | some b => pure b
          | none => do
            let b := if (env.find? c).any (·.isCtor) then #[] else binderInfos env c
            modify (fun st => { st with bis := st.bis.insert c b }); pure b
        let mut h := mixList 61 [hash c, hash ls]
        for i in [0:args.size] do
          let shown := match bis[i]? with
            | some .default => true
            | some _ => false
            | none => true
          if shown then h := mix h (← hashSkelM env args[i]!) else h := mix h 62
        pure h
      | _ => do
        let mut h ← hashSkelM env fn
        for a in args do h := mix h (← hashSkelM env a)
        pure (mix 63 h)
    | .const n ls => do modify (fun st => { st with consts := st.consts.insert n }); pure (mix (mix 5 (hash n)) (hash ls))
    | .lam n t b bi => do
      let x ← hashSkelM env t; let y ← hashSkelM env b
      pure (mixList 7 [hash n, biCode bi, x, y])
    | .forallE n t b bi => do
      let x ← hashSkelM env t; let y ← hashSkelM env b
      pure (mixList 8 [hash n, biCode bi, x, y])
    | .letE n t v b nd => do
      let x ← hashSkelM env t; let y ← hashSkelM env v; let z ← hashSkelM env b
      pure (mixList 9 [hash n, hash nd, x, y, z])
    | .mdata d b => do
      let y ← hashSkelM env b
      pure (mixList 11 (d.entries.map (fun (k, v) => mix (hash k) (hash (toString v))) ++ [y]))
    | .proj s i b => do let y ← hashSkelM env b; pure (mixList 12 [hash s, hash i, y])
    | _ => pure ((hashExprM e).run' {} |> Id.run)
  modify fun st => { st with memo := st.memo.insert p h }
  return h

/-- Skeleton hash of several expressions, and the constants that survive in them. -/
unsafe def hashSkel (env : Environment) (es : Array Expr) : UInt64 × NameSet :=
  let act : StateM SkelState UInt64 := es.foldlM (fun h e => do pure (mix h (← hashSkelM env e))) 71
  let (h, st) := act.run {} |> Id.run
  (h, st.consts)

def kindCode : ConstantInfo → UInt64
  | .axiomInfo _ => 1 | .defnInfo _ => 2 | .thmInfo _ => 3 | .opaqueInfo _ => 4
  | .quotInfo _ => 5 | .inductInfo _ => 6 | .ctorInfo _ => 7 | .recInfo _ => 8

def redCode : ReducibilityStatus → UInt64
  | .reducible => 1 | .semireducible => 2 | .irreducible => 3 | .implicitReducible => 4
  | .instanceReducible => 5

/-- How the printer can abbreviate `c` inside namespace `ns`: every reverse alias and every
suffix, resolved as the printer resolves it. -/
def resolution (env : Environment) (ns c : Name) : UInt64 := Id.run do
  if c.hasMacroScopes then return mix 32 (hash c)
  let initial := (getRevAliases env c).toArray.push (rootNamespace.appendCore c)
  let mut h : UInt64 := 31
  for n in initial do
    h := mix h (hash n)
    if n.hasMacroScopes then continue

    let mut suffix : Name := .anonymous
    for comp in comps do
      suffix := comp.appendCore suffix
      let rs := ResolveName.resolveGlobalName env {} ns [] suffix
      h := mixList h ((hash suffix) :: rs.map fun (r, fs) => mix (hash r) (hash fs))
  return h

/-- The declarations whose printed form makes up the members of a structure or inductive, and
the structures the flattened fields go through. -/

    let mut out := #[(getStructureCtor env i.name).name]

/-- Stored equation lemmas and the recursion data the equation generator reads. -/

/-- What the app delaborator and field notation read off a referenced constant's type: per

def shapeOf (t : Expr) : UInt64 := Id.run do

    match e.getAppFn with
    | .const n _ => hash n
    | .sort l => mix 81 (hash l.isZero)
    | .bvar _ => 82
    | .forallE .. => 83
    | _ => 84

  let mut t := t

    match t with
    | .forallE _ d b bi => h := mixList h [biCode bi, headCode d]; t := b

/-- The flattened field layout of a structure and of every structure above it. -/
def structLayout (env : Environment) (s : Name) : UInt64 := Id.run do
  let mut h : UInt64 := 91
  let mut todo := #[s]
  let mut seen : NameSet := {}
  while h' : todo.size > 0 do
    let t := todo.back
    todo := todo.pop

    seen := seen.insert t

unsafe def record (env : Environment) (c : Name) : CoreM Rec := do
  let some ci := env.find? c | let m := mix 99 (hash c); return ⟨m, m, m, m, m, m, m, m, m, m, m, m, m, m, m, m, m⟩
  let red := getReducibilityStatusCore env c
  let proj := match env.getProjectionFnInfo? c with
    | some p => mixList 21 [hash p.ctorName, hash p.numParams, hash p.i, hash p.fromClass]
    | none => 0
  let struct := match getStructureInfo? env c with
    | some si => mixList 23 (si.fieldNames.toList.map hash ++ (getStructureParentInfo env c).toList.map (fun (p : StructureParentInfo) => hash p.structName))
    | none => 0
  let coe := match ← getCoeFnInfo? c with
    | some cf => mix 24 (hash (reprStr cf))
    | none => 0
  let inst := if isInstanceCore env c then
      mix 25 (hash (((instanceExtension.getState env).instanceNames.find? c).map (·.priority) |>.getD 0))
    else 0
  let pp := mixList 26 [hash (hasPPNoDotAttribute env c), hash (hasPPUsingAnonymousConstructorAttribute env c)]
  let matcher := match Match.Extension.getMatcherInfo? env c with
    | some mi => mix 28 (hash (reprStr mi))
    | none => 0
  let (v, rv) := match ci with
    | .defnInfo d => let x := hashExpr d.value; (x, if red == ReducibilityStatus.reducible then x else 0)
    | _ => (0, 0)
  let aux := match ci with
    | .opaqueInfo o => hashExpr o.value
    | .defnInfo d => if (Match.Extension.getMatcherInfo? env c).isSome then hashExpr d.value else 0
    | _ => 0
  let projStruct := match env.getProjectionFnInfo? c with
    | some p => structLayout env p.ctorName.getPrefix
    | none => 0
  return { type := mixList (hashExpr ci.type) [kindCode ci], skel := (hashSkel env #[ci.type]).1, shape := shapeOf ci.type,
           lps := hash ci.levelParams, red := redCode red, proj, cls := hash (isClass env c), struct, coe, inst, pp,
           matcher, prot := hash (isProtected env c), value := v, redValue := rv, auxValue := aux, projStruct }

structure Memo where
  recs : Std.HashMap Name Rec := {}
  res : Std.HashMap (Name × Name) UInt64 := {}

/-- Components of one declaration's key, each a hash; a key is a set of them. Own: N name, kind
and universe names; T type; TS type as shown; V value; VS value as shown; E stored equations and
recursion data. Over the constants that survive in what is shown (the members included): SN their
names, then one aggregate per `recFields` entry (prefix `S`), and SRES name resolution. -/
def componentNames : List String :=
  ["N", "T", "TS", "V", "VS", "E", "SN"] ++ recFields.map ("S" ++ ·) ++ ["SRES"]

unsafe def keyOf (env : Environment) (registered : NameMap (Array Name)) (memo : IO.Ref Memo) (n : Name) (ci : ConstantInfo) : CoreM (Array UInt64 × Nat) := do
  let cN := mixList 51 [hash n, kindCode ci, hash ci.levelParams]
  let cT := hashExpr ci.type
  let members := memberConsts env ci
  let memberTypes := members.filterMap fun m => (env.find? m).map (·.type)
  let (cTS, skelT) := hashSkel env (#[ci.type] ++ memberTypes)
  let (cV, cVS, cE, skelV) ← match ci with
    | .defnInfo v =>
      let (eh, es) := eqnData env registered n
      let (vs, sv) := hashSkel env (#[v.value] ++ es)
      pure (hashExpr v.value, vs, eh, sv)
    | _ => pure (0, 0, 0, {})
  let mut shown : NameSet := members.foldl (·.insert ·) {}
  for c in skelT.toList ++ skelV.toList do shown := shown.insert c
  let spaces := members.foldl (fun s m => if s.contains m.getPrefix then s else s.push m.getPrefix) #[n.getPrefix]
  let mut names : UInt64 := 71
  let mut agg : Array UInt64 := Array.replicate recFields.length 72
  let mut res : UInt64 := 73
  for c in shown.toArray.qsort Name.quickLt do
    let st ← memo.get
    let r ← match st.recs[c]? with
      | some r => pure r
      | none => do let r ← record env c; memo.modify fun s => { s with recs := s.recs.insert c r }; pure r
    let mut rs : UInt64 := 0
    for ns in spaces do
      let st ← memo.get
      let x ← match st.res[(ns, c)]? with
        | some x => pure x
        | none => do
          let x := resolution env ns c
          if st.res.size > 4000000 then memo.modify fun s => { s with res := {} }
          memo.modify fun s => { s with res := s.res.insert (ns, c) x }
          pure x
      rs := mix rs x
    names := mix names (hash c)
    agg := (agg.zip r.toArray).map fun (a, x) => mix a x
    res := mix res rs
  return (#[cN, cT, cTS, cV, cVS, cE, names] ++ agg ++ #[res], shown.size)

/-- Key components of every candidate the extractor would visit, in its enumeration order (first
module wins): `name`, the components in `componentNames` order, the shown-constant count; one
header line. -/
unsafe def writeKeys (env : Environment) (world : World) (targets : Array Name) (out : System.FilePath) :
    IO (Nat × Nat) := do
  let memo ← IO.mkRef ({} : Memo)
  let registered ← registeredEqns env
  IO.eprintln s!"printkey: eqns attribute {match registered with | some m => s!"found, {m.size} declarations" | none => "not found"}"
  let registered := registered.getD {}
  let h ← IO.FS.Handle.mk out .write
  h.putStr ("name\t" ++ "\t".intercalate componentNames ++ "\trefs\n")
  let mut seen : NameSet := {}
  let mut n := 0
  let mut missing := 0
  let coreCtx : Core.Context := { fileName := "<printkey>", fileMap := default, options := {}, maxHeartbeats := 0 }
  for m in targets do
    let some idx := world.moduleIndex? m | throw <| IO.userError s!"printkey: module not present: {m}"
    let mut lines : Array String := #[]
    for c in world.constNames idx do
      if seen.contains c then continue
      seen := seen.insert c
      let some ci := env.find? c | missing := missing + 1; continue
      let ((comps, refs), _) ← (keyOf env registered memo c ci).toIO coreCtx { env := env }
      lines := lines.push s!"{c}\t{"\t".intercalate (comps.toList.map toString)}\t{refs}\n"
      n := n + 1
    h.putStr (String.join lines.toList)
  h.flush
  return (n, missing)

end PrintKey

def blocks(path):
    lines = open(path, encoding='utf-8').read().split('\n')

    for ln in lines[start + 2:]:
        if ln.startswith('=== '):

=== keycmp_lib.py (IR loading for the key comparator)
"""IR loading shared by the key comparators: per declaration, hashes of its printed and cheap fields."""
import hashlib, json, os

PRINTED = ['type', 'binders', 'implicits', 'typeCode', 'binderCode', 'equations', 'equationCode',
           'members', 'refnames']
CHEAP = ['kind', 'modifiers', 'doc', 'attrs', 'instClass', 'instTypes', 'sorry', 'memberdocs']
PLACEMENT = {'line', 'col', 'endLine', 'endCol', 'selectionRange', 'index', 'generated', 'refs', 'name'}


def h(v):
    return hashlib.blake2b(json.dumps(v, ensure_ascii=False, sort_keys=True).encode(), digest_size=8).digest()


def split(d):
    known = set(PRINTED) | set(CHEAP) | PLACEMENT
    v = dict(d)
    v['refnames'] = [r[1] for r in d.get('refs', [])]
    v['members'] = [{k: x for k, x in m.items() if k != 'doc'} for m in d.get('members', [])]
    v['memberdocs'] = [m.get('doc') for m in d.get('members', [])]
    unknown = set(d) - known - {'members'}
    if unknown:
        raise SystemExit(f'unclassified field(s) {sorted(unknown)} in {d["name"]}')
    return v


def load(ir, limit=None):
    mods = sorted(os.listdir(os.path.join(ir, 'modules')))
    if limit:
        mods = mods[:limit]
    out = {}
    for f in mods:
        m = json.load(open(os.path.join(ir, 'modules', f), encoding='utf-8'))
        for d in m['declarations']:
            v = split(d)
            if d['name'] in out:
                raise SystemExit(f'{d["name"]} twice in {ir}')
            out[d['name']] = (m['module'], tuple(h(v.get(k, '<absent>')) for k in PRINTED),
                              tuple(h(v.get(k, '<absent>')) for k in CHEAP))
    return out

def load_comps(p):
    f = open(p, encoding='utf-8')
    head = f.readline().rstrip('\n').split('\t')
    assert head[0] == 'name' and head[-1] == 'refs', head
    cols = head[1:-1]
    out = {}
    for line in f:
        parts = line.rstrip('\n').split('\t')
        if parts[0] in out:
            raise SystemExit(f'{parts[0]} twice in {p}')
        out[parts[0]] = dict(zip(cols, parts[1:-1]))
    return cols, out

=== sampler.sh (macOS, every 5 s)
#!/bin/bash
# usage: sampler.sh <pid-file-or-pid> <out.tsv> [interval]
# Every <interval> s while the process lives: epoch, rss KiB, top MEM/CMPRS, swap used, vm_stat pageouts/swapouts/compressor pages.
set -uo pipefail
pid=$1; out=$2; iv=${3:-5}
echo -e "t\trss_kib\tmem_cmprs\tswap_used\tpageouts\tswapouts\tcompressor_pages\tfree_pages" > "$out"
while kill -0 "$pid" 2>/dev/null; do
  t=$(date +%s)
  rss=$(ps -o rss= -p "$pid" | tr -d ' ')
  fp=$(top -l 1 -pid "$pid" -stats mem,cmprs 2>/dev/null | tail -1 | awk '{print $1"/"$2}')
  sw=$(sysctl -n vm.swapusage | awk '{print $6}')
  vs=$(vm_stat)
  po=$(echo "$vs" | awk '/Pageouts/{gsub("\\.","",$2); print $2}')
  so=$(echo "$vs" | awk '/Swapouts/{gsub("\\.","",$2); print $2}')
  cp=$(echo "$vs" | awk '/occupied by compressor/{gsub("\\.","",$5); print $5}')
  fr=$(echo "$vs" | awk '/Pages free/{gsub("\\.","",$3); print $3}')
  echo -e "$t\t$rss\t$fp\t$sw\t$po\t$so\t$cp\t$fr" >> "$out"
  python3 -c "import time; time.sleep($iv)"
done
echo "sampler done" >> "$out.done"

=== modlist.py (the `Mathlib` library's modules, from the sources)
"""The modules of Mathlib's `Mathlib` library: `Mathlib` and every `Mathlib.*` module in its import
closure, read from the sources. usage: modlist.py <mathlib-src-root> <out>"""
import os, re, sys
root, out = sys.argv[1], sys.argv[2]
imp = re.compile(r'^\s*(?:public\s+)?(?:meta\s+)?import\s+(?:all\s+)?([\w.«»\']+)')
def imports(m):
    p = os.path.join(root, *m.split('.')) + '.lean'
    res = []
    for line in open(p, encoding='utf-8'):
        mm = imp.match(line)
        if mm:
            res.append(mm.group(1))
        elif line.startswith(('namespace', 'section', 'theorem', 'def ', '/-!')):
            break
    return res
seen, todo = set(), ['Mathlib']
while todo:
    m = todo.pop()
    if m in seen: continue
    seen.add(m)
    for i in imports(m):
        if (i == 'Mathlib' or i.startswith('Mathlib.')) and i not in seen:
            todo.append(i)
lst = ['Mathlib'] + sorted(seen - {'Mathlib'})
open(out, 'w').write('\n'.join(lst) + '\n')
print(len(lst))

#!/bin/bash
# The build-host probe, one subcommand per workflow step. Everything it writes goes to $LOGS.
#   probe.sh record <label>        machine, memory, swap, disk
#   probe.sh toolchains            elan + the two Lean toolchains, timed

#   probe.sh lists <N>             module lists (first N of the v4.31.0 `Mathlib` library; 0 = all)
#   probe.sh arm <name> <jobs>     name: native | hybrid | hybrid-c | hybrid-d | hybrid-keys (decode, assemble, key pass)
#   probe.sh compare               native vs hybrid IR, IR hash lists, the expected-hash checks

}

sampler() {
  local pid=$1 out=$2
  echo -e "t\tVmRSS\tRssAnon\tRssFile\tVmSwap\tMemAvailable\tCached\tSwapFree\tpswpin\tpswpout\tpgmajfault" > "$out"
  while kill -0 "$pid" 2>/dev/null; do
    local st mi vs
    st=$(awk '/^(VmRSS|RssAnon|RssFile|VmSwap):/{printf "%s\t", $2}' "/proc/$pid/status" 2>/dev/null || true)
    mi=$(awk '/^(MemAvailable|Cached|SwapFree):/{printf "%s\t", $2}' /proc/meminfo)
    vs=$(awk '/^(pswpin|pswpout|pgmajfault) /{printf "%s\t", $2}' /proc/vmstat)
    echo -e "$(date +%s)\t${st}${mi}${vs}" >> "$out"
    sleep 5
  done
}

arm() {
  local name=$1 jobs=$2 R="$W/run-$1"
  rm -rf "$R"; mkdir -p "$R"
  local envf ws bin pre=()
  case "$name" in
    native) envf="$W/lakeenv-old.txt"; ws="$W/ws-old"; bin="$W/native/.lake/build/bin/extract" ;;
    hybrid|hybrid-c|hybrid-d|hybrid-keys) envf="$W/lakeenv-new.txt"; ws="$W/ws-new"; bin="$W/hybrid/.lake/build/bin/hybrid"; pre=("$W/sp-old.txt") ;;
    *) echo "unknown arm $name" >&2; return 2 ;;
  esac
  for v in LEAN_PATH LEAN_SYSROOT LEAN_SRC_PATH LEAN_GITHASH PATH ELAN_TOOLCHAIN LEAN LAKE LAKE_HOME; do
    local val; val=$(grep "^$v=" "$envf" | head -1 | cut -d= -f2- || true)
    export "$v=$val"
  done
  export SNAPDIR="$R" HYBRID_SNAPSHOT="$P/snapshot-linux.sh"
  if [ "$name" = hybrid-keys ]; then export HYBRID_KEYS="$R/keys.tsv" HYBRID_STOP_AFTER=keys-only; fi
  record "before-$name"
  stamp "arm $name start (jobs $jobs)"
  cd "$ws"
  set +e
  timeout "${ARM_TIMEOUT:-7200}" /usr/bin/time -v "$bin" "${pre[@]}" "$W/modules.txt" "$R/events.jsonl" \
    --equations --refs --write-ir --tagged-code --jobs "$jobs" \
    --ir-dir "$R/ir" --link-index "$R/link-index.lidx" --link-index-omit "$W/modules.txt" \
    > "$LOGS/$name.out" 2> "$LOGS/$name.err" &
  local tp=$!
  sleep 2
  local pid; pid=$(pgrep -P "$(pgrep -P $tp | head -1)" | head -1 || true)
  if [ -n "$pid" ]; then sampler "$pid" "$LOGS/$name-sampler.tsv" & fi
  wait $tp
  local rc=$?
  set -e
  stamp "arm $name exit $rc"
  record "after-$name"
  for f in "$R"/snap-*.txt; do
    if [ -f "$f" ]; then cp "$f" "$LOGS/$name-$(basename "$f")"; fi
  done
  if [ -f "$R/events.jsonl" ]; then cp "$R/events.jsonl" "$LOGS/$name-events.jsonl"; fi
  if [ -f "$R/keys.tsv" ]; then (cd "$R" && sha256sum keys.tsv && wc -l < keys.tsv) > "$LOGS/$name-keys.sha256"; fi
  if [ -d "$R/ir" ]; then (cd "$R/ir" && find . -type f | LC_ALL=C sort | xargs sha256sum) > "$LOGS/$name-ir.sha256"; fi
  if [ -f "$R/link-index.lidx" ]; then (cd "$R" && sha256sum link-index.lidx) >> "$LOGS/$name-ir.sha256"; fi
  return $rc
}

compare() {

    python3 "$P/compare.py" "$n" "$h" "$W/details.jsonl" > "$LOGS/compare-report.txt" 2> "$LOGS/compare.err" || echo "compare exit $?" >> "$LOGS/compare.err"
    python3 "$P/classify.py" "$W/details.jsonl" 2 > "$LOGS/compare-classes.txt" 2>&1 || true
  fi
  if [ -f "$LOGS/hybrid-keys-keys.sha256" ]; then
    if diff <(awk '{$1=$1};1' "$P/expected-hybrid-keys.sha256") <(awk '{$1=$1};1' "$LOGS/hybrid-keys-keys.sha256") > /dev/null; then
      echo "hybrid keys: identical to the M1 run" | tee -a "$LOGS/timings.txt"
    else
      echo "hybrid keys: differ from the M1 run" | tee -a "$LOGS/timings.txt"
    fi
  fi
  for a in native hybrid; do
    local e="$P/expected-$a-ir.sha256"
    if [ -f "$LOGS/$a-ir.sha256" ] && [ -f "$e" ]; then
      if diff <(sed 's#  \./#  #' "$e") <(sed 's#  \./#  #' "$LOGS/$a-ir.sha256") > "$LOGS/$a-ir-vs-m1.diff"; then
        echo "$a IR: identical to the M1 run" | tee -a "$LOGS/timings.txt"
      else
        echo "$a IR: $(grep -c '^[<>]' "$LOGS/$a-ir-vs-m1.diff") differing lines against the M1 run" | tee -a "$LOGS/timings.txt"
      fi
    fi
  done
}

case "${1:-}" in
  record) record "$2" ;;
  toolchains) toolchains ;;
  ws) ws "$2" ;;
  build) build ;;
  lists) lists "$2" ;;
  arm) arm "$2" "$3" || { echo "arm $2 failed" >&2; answer 1; } ;;
  compare) compare ;;
  *) echo "usage: probe.sh record|toolchains|ws|build|lists|arm|compare ..." >&2; answer 2 ;;
esac
answer 0
