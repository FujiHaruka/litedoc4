THE CHANGES (uncommitted when measured; the measured binary is the tree's)
--------------------------------------------------------------------------
keys    the reuse keys (PrintKey.ownKey over every candidate, plus the name's string) are computed
        in --jobs tasks that take candidates by stride; the results are put back in candidate order,
        so the keys file is the same bytes at any --jobs. One job spawns no task, as before.
load    the neighbour's keys file is parsed line by line in --jobs tasks. Each IR module file is read
        as bytes and scanned in --jobs tasks (each task takes files by stride) by a small JSON scanner
        that finds each declaration's byte range and its "name" value, without building a Json tree.
        A declaration whose key is equal is kept as a copy of its bytes (exact size) behind a Thunk.
        The thunk is forced when extraction asks for that name, in the extraction's worker. Forcing it
        parses the bytes as JSON, reads the printed parts as before (printedOfJson?), and replaces
        every name with the environment's own Name object for that constant, if there is one. So the
        parsed neighbour output is never resident as a whole, and the reused declarations share names
        with the environment, as printed ones do. A declaration whose bytes do not read back is
        printed, and counted as "not read back", as before.
count   the reuse-from line's classification of each produced declaration is computed in --jobs
        tasks. It runs inside the "write keys" phase, in both the old and the new reader.
write   the keys file's text is built in --jobs blocks, then written.
Given up: the load no longer parses every module file as JSON, so a malformed IR file is now refused
only where the scanner cannot find the structure ("is not JSON: <what was expected at byte n>"). A
malformed declaration whose structure scans is printed instead of reused.
One new compile-time guard, scanFindsEveryDeclaration (the scanner, on a pretty-printed file with
escaped quotes, brackets inside strings and nested "name" keys, finds every declaration, its name,
and bytes that parse to the same JSON) failed once on a scanner that ignored backslash escapes.
The reader's identity moves (reader=fnv1a64:5a1f6474c0e65cbe -> 7e586b1b9f42b5e5), so a keys file
written by the old reader is refused by the new one as "printing identity differs", and each arm
needs its own head.
