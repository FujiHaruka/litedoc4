What the bytes of a Mathlib documentation site are — litedoc4 against doc-gen4's live site
==========================================================================================
2026-10-04

What this answers
-----------------
1. Is a Mathlib site over 1 GB something litedoc4 does, or does doc-gen4's live site do it too?
2. Which parts of a module page carry the size?

Answers (measured):
1. Both. doc-gen4's deployed site is 2,555,490,819 B in 11,672 files; its Mathlib module pages
   alone are 1,069,790,161 B (8,595 pages). litedoc4's Mathlib module pages are 1,074,699,047 B
   (8,170 pages). On the 5,877 modules with the same declaration count on both sites, litedoc4 is
   1.051x doc-gen4 (574,423,383 B against 546,296,514 B).
   doc-gen4's site is deployed to GitHub Pages and the deploy step succeeded (run 37166778803,
   2026-10-04, conclusion success), although GitHub's documented limit for a published site is 1 GB.
2. Signatures: 63.92% (litedoc4) / 65.28% (doc-gen4) of module page bytes. Tags are 89.88% /
   89.41% of all page bytes; text is 9.99% / 10.52%.

Summary of the levers (upper bounds, each as if that item went to zero; they overlap)
--------------------------------------------------------------------------------------
  signature wrappers <span class="fn">…</span>   10,285,239 x 24 B = 246,845,736 B (22.97%);
                                                  doc-gen4 has the same density
  Lean core source links on GitHub               835,214 links, ≈ 100.3 MB with quoting,
                                                  1,733 distinct URLs; litedoc4 only (doc-gen4
                                                  hosts Init/Lean/Std and links ≈ 36 B internally)
  same-page links spelled as a full path          841,091 links, path part 46,590,145 B
  `../` prefixes of relative links               40,318,819 B
  "Used by" placeholder                          40,098,305 B; litedoc4 only

doc-gen4's declarations/header-data.bmp (1,176,299,892 B) is JSON with 427,844 entries, one per
declaration of every package on the site, each with its header HTML (996,148,588 B in total). It
is an export for embedding in other pages; doc-gen4's own page scripts do not read it. litedoc4
has no equivalent.
