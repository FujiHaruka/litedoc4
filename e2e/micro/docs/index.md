# A litedoc4 sample

Every page here was written by `litedoc4 build` from a ten-module Lean package
with no Mathlib under it, and rebuilt from `main` on every push. The point is
the shapes a page can take, not the scale — the site next to this one,
[422 modules on Mathlib](https://fujiharuka.github.io/information-theory/), is
the scale.

Read a page beside the source it links to. The modules, and what each shows:

* [`Micro.Basic`](Micro/Basic.html) and [`Micro.Shapes`](Micro/Shapes.html) —
  the kinds a declaration comes in
* [`Micro.Math`](Micro/Math.html) — LaTeX in a docstring, converted while the
  site is built
* [`Micro.Sorry`](Micro/Sorry.html) — the two marks an incomplete proof leaves
  on a page
* [`Micro.Gen`](Micro/Gen.html) — declarations Lean realized from an attribute,
  and the ones that only look realized
* [`Micro.Attrs`](Micro/Attrs.html) — how an attribute's name and value are
  printed
* [`Micro.Notation`](Micro/Notation.html) — a signature printed with the
  package's own notation
* [`Micro.Unicode`](Micro/Unicode.html) — an identifier above U+FFFF, and
  Markdown in a docstring
* [`Micro.Dep`](Micro/Dep.html) — a reference into a dependency that has no page
  here
