Question
--------
  Does the largest module page settle faster drawn from data (the `litedoc4 store render` site)
  than as today's static page (`litedoc4 build` output)? Both arms re-measured in one session, on
  one module, at one Mathlib tag. U7's 361 ms (hosting-and-client-render-2026-10-05.txt, v4.31.0,
  387 declarations, Chrome 154.0.8037.93) is context only and is not compared with anything here.

Answer
------
  Yes. On Mathlib.CategoryTheory.Comma.StructuredArrow.Basic at v4.33.1 (400 declarations), served
  from loopback by one server, Chrome 154 headless (measured, 11 runs per arm, arms alternating):

                                     static (build)          drawn (store render)
    identity (headline)
      settled, warm median of 10     322 ms                  217 ms
      settled, first run             350 ms                  217 ms
      first contentful paint, med.   196 ms                  228 ms
    Content-Encoding: gzip
      settled, warm median of 10     320 ms                  217 ms
      settled, first run             333 ms                  222 ms
      first contentful paint, med.   180 ms                  228 ms

  The drawn page settles 105 ms earlier (0.67x) with identity serving and 103 ms earlier (0.68x)
  with gzip (measured). It paints first 32-48 ms LATER than the static page (measured): the static
  page paints while the parser is still running, the drawn page paints nothing until it has drawn.
  Every run of both arms had the same 400 declaration ids; the declarations' visible text
  (130,998 non-space characters) and their links (8,756) are identical between the arms (measured,
  see "Same page?").

  What the loopback number does not carry: the drawn page needs the shell, then site.js, then three
  data files before it draws (the version file, the page file and the content), while the static
  page needs one HTML file. On a real network each extra round trip adds to the drawn arm and not to
  the static arm. That is not measured here (theoretical, unverified).

Definition of "settled" (U7's, applied to both arms)
------------------------------------------------------
  U7: "two animation frames after the content exists", clocked from navigation start
  (performance.now()). For the static page the content exists at the load event, so settled =
  the second requestAnimationFrame callback after load (U7's variant A, unchanged here).
  For the drawn page the content exists when the page sets body[data-drawn="1"]. web/src/store-page.ts
  sets it after body.replaceChildren(drawn nodes) and the initialisers that run in the same task
  (theme, drawer, search box, fills, tree, arrival notices), so it is a few ms later than U7's "DOM
  built" mark for its hand-written data page; it is the page's own "done" signal. Settled = the
  second requestAnimationFrame callback after BOTH that attribute and the load event. In every run
  load (10-16 ms) came before data-drawn (55-74 ms), so the load term never decided it. Requiring
  data-drawn is not optional: in 5 of 11 gzip-pass drawn runs, two frames after load came at 11-67 ms,
  at or before the draw (55-74 ms), which would have timed an empty or half-initialised page.
  The second rAF callback runs before that frame's paint, so FCP can land a few ms after "settled"
  (drawn: FCP 228 against settled 217).

// usage: deno run -A settle.ts <static site dir> <drawn site dir> <static page rel> <drawn page rel> <runs> <out.json> [gz]
import puppeteer from "npm:puppeteer-core@24";

const [STATIC, DRAWN, SREL, DREL, RUNS_S, OUT, GZ] = Deno.args;
const RUNS = Number(RUNS_S ?? "5");
const PORT = 8931;
const CHROME = "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome";
const ENCODE = GZ === "gz";

const types: Record<string, string> = {
  ".html": "text/html; charset=utf-8",
  ".css": "text/css; charset=utf-8",
  ".js": "text/javascript; charset=utf-8",
  ".json": "application/json; charset=utf-8",
  ".svg": "image/svg+xml",
  ".gz": "application/gzip",
};
const typeOf = (p: string) => types[p.slice(p.lastIndexOf("."))] ?? "application/octet-stream";
const gzCache = new Map<string, Uint8Array>();
async function gzipOf(file: string, raw: Uint8Array): Promise<Uint8Array> {
  let gz = gzCache.get(file);
  if (!gz) {
    gz = new Uint8Array(await new Response(new Blob([raw]).stream().pipeThrough(new CompressionStream("gzip"))).arrayBuffer());
    gzCache.set(file, gz);
  }
  return gz;
}

Deno.serve({ port: PORT, hostname: "127.0.0.1", onListen: () => {} }, async (req) => {
  const path = decodeURIComponent(new URL(req.url).pathname);
  const root = path.startsWith("/static/") ? STATIC : path.startsWith("/drawn/") ? DRAWN : null;
  if (root) {
    const file = root + path.slice(path.indexOf("/", 1));
    try {
      const raw = await Deno.readFile(file);
      if (ENCODE && !file.endsWith(".gz")) {
        return new Response(await gzipOf(file, raw), {
          headers: { "content-type": typeOf(file), "content-encoding": "gzip" },
        });
      }
      return new Response(raw, { headers: { "content-type": typeOf(file) } });
    } catch {
      // fall through
    }
  }
  return new Response("not found", { status: 404 });
});

const base = `http://127.0.0.1:${PORT}`;
const arms: [string, string][] = [
  ["static", `${base}/static/${SREL}`],
  ["drawn", `${base}/drawn/${DREL}`],
];

const browser = await puppeteer.launch({ executablePath: CHROME, headless: true });
console.log("browser", await browser.version(), ENCODE ? "(Content-Encoding gzip)" : "(identity)");

async function once(url: string) {
  const ctx = await browser.createBrowserContext();
  const page = await ctx.newPage();
  await page.setCacheEnabled(false);
  await page.setViewport({ width: 1280, height: 800 });
  await page.evaluateOnNewDocument(() => {
    const w = window as any;
    const twoFrames = (k: string) => requestAnimationFrame(() => requestAnimationFrame(() => { w[k] = performance.now(); }));
    const both = () => {
      if (w.__loadAt !== undefined && w.__drawnAt !== undefined && w.__bothAt === undefined) {
        w.__bothAt = performance.now();
        twoFrames("__drawn2f");
      }
    };
    addEventListener("load", () => {
      w.__loadAt = performance.now();
      twoFrames("__load2f");
      both();
    });
    new MutationObserver(() => {
      if (document.body?.dataset.drawn === "1" && w.__drawnAt === undefined) {
        w.__drawnAt = performance.now();
        both();
      }
    }).observe(document, { subtree: true, attributes: true, attributeFilter: ["data-drawn"] });
  });
  const errors: string[] = [];

      drawnAt: w.__drawnAt ?? null,

      reqs: 1 + res.length,

      encoded: n.encodedBodySize + res.reduce((s, e) => s + e.encodedBodySize, 0),
      decoded: n.decodedBodySize + res.reduce((s, e) => s + e.decodedBodySize, 0),
      files: [n.name, ...res.map((e) => e.name)].map((u) => u.replace(location.origin, "")),
      decls: document.querySelectorAll("section.decl").length,
      elements: document.getElementsByTagName("*").length,
      drawnFlag: document.body?.dataset.drawn ?? null,
    };
  });
  await page.waitForNetworkIdle({ idleTime: 500, timeout: 30000 }).catch(() => {});
  const idle = await page.evaluate(() => {
    const n = performance.getEntriesByType("navigation")[0] as PerformanceNavigationTiming;
    const res = performance.getEntriesByType("resource") as PerformanceResourceTiming[];
    return {
      fcp: performance.getEntriesByName("first-contentful-paint")[0]?.startTime ?? null,
      reqs: 1 + res.length,
      transfer: n.transferSize + res.reduce((s, e) => s + e.transferSize, 0),
      files: res.map((e) => e.name.replace(location.origin, "")),
    };
  });
  await ctx.close();
  return {
    ...atSettle,
    fcp: idle.fcp,
    idle,
    taskMs: m.TaskDuration! * 1000,
    scriptMs: m.ScriptDuration! * 1000,
    layoutMs: m.LayoutDuration! * 1000,
    styleMs: m.RecalcStyleDuration! * 1000,
    heapKB: m.JSHeapUsedSize! / 1024,
    layouts: m.LayoutCount,
    errors,
    statuses,
  };
}

const median = (xs: number[]) => {
  const s = [...xs].sort((a, b) => a - b);
  return s.length % 2 ? s[(s.length - 1) / 2] : (s[s.length / 2 - 1] + s[s.length / 2]) / 2;
};
