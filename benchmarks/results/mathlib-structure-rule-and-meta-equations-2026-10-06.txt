THE META-CODE RULE (what was applied)
------------------------------------
- In `withEquations`, after the --equations guard: a definition whose name, with any private prefix removed
  (`privateToUserName`), lies strictly under `Mathlib.Tactic` or `Mathlib.Meta` gets no equations and is counted
  (`eqSkipped`). It applies to every `.defnInfo` the extractor documents, instances included; its signature, docstring
  and source range are unchanged. The prefixes are a fixed list in the extractor for this prototype; how the product
  spells it for packages other than Mathlib is open (D8), and the case above (meta code inside `Nat.`) is one input to
  that.
- Equation failures and empty equation sets are written to stderr by name with their time and the first line of the
  message (EQFAIL / EQEMPTY); no IR field was added.
- The same edit applied to the native build (Lean v4.31.0, the full-extraction log's seamed source); it builds and, on the
  meta sample, skips the same 257 definitions and produces the same 85 lemmas as the hybrid (measured).
- metacheck.py: no meta-code definition with equations in an IR. Made to fail once (measured): one equation inserted into
  Mathlib.Tactic.Abel.NormalExpr.zero' in a copy of the meta-sample IR -> "meta-code definitions with equations: 1",
  exit 1.

THE KEY VARIANT (what was implemented)
-------------------------------------
- Two new components per declaration, computed in the same loop over the shown constants as every other one:
  SSTRN: for a shown constant that is a member of the declaration, its STR record value (field names, parent structures);
  for a shown constant that is a constructor of a structure, the same data of that structure. SCX: for a shown
  constructor of a structure, the structure's anonymous-constructor attribute and, for every field at every level, the
  effective default-value function's name, type and value.
- N1 = G7 with SSTR replaced by SSTRN; N1X = N1 + SCX; "+ own" = the declaration's own record over the patch log's ten
  fields. In the patch process, PRINTKEY_VARIANT=nown (N1 + own) or nownx (N1X + own) chooses the second key; unset, it is
  G7 + own as before.
- The key file written by the from-scratch runs gained SSTRN, SCX and OWN columns. keycmp4.py = keycmp3.py with the new
  variants and the lost-reuse analysis for a chosen variant.
- Cross-checks (measured): the comparator's F7, G7 and G7 + own counts equal the consecutive and patch logs' (263,918 /
  260,835 / 260,544); on the meta sample, the patch process reused 532 / 599 / 597 under G7 / N1 + own / N1X + own,
  the comparator's counts. Made to fail once (measured, standard sample): SSTRN of AddConstEquiv and OWN of
  AddConstEquiv.Simps.symm_apply set to 1 in a copy of the v4.32.0 key file -> N1 1,114 -> 1,113, N1 + own 1,114 ->
  1,112, G7 + own 976 -> 975, G7 unchanged.
