Consecutive releases: how much of a declaration's print can be reused from the previous release, how many modules are unchanged, and the key pass's 182 panics
====================================================================================================================================================
Date: 2026-10-05. Context: docs/multiversion/plan.md U3 (what consecutive releases share), U5 / U9 (the hybrid and its
cost), D5 (content-addressed declarations), D7 (how a new release gets in), D10 (one reader, every version printed by
the newest Lean and Mathlib). The proposed redesign processes versions in order in one process and handles only the
difference from the previous version: it reuses the print of every declaration whose print key is unchanged and patches
the environment with the changed modules only. This log measures what that difference is between consecutive releases.
The programs are those of benchmarks/results/mathlib-build-host-levers-2026-10-05.txt (the "levers log": the hybrid,
the seamed extractor, the print-key pass G7, the comparators) with the changes listed under CODE. A measurement in
scratch Lake projects on this M1; nothing in src/ or extractor/ was changed.

QUESTIONS
---------
(1) Content floor: of the declarations present in both Mathlib v4.31.0 and v4.32.0 (by name), how many have the same
    content (type; type and value)? How many are added, removed, renamed-looking?
(2) Module level: of the modules in both closures, how many are unchanged by decoded content (not by file bytes)? How
    many constants do the changed modules hold, and how many of those changed? This is what an environment patch has to
    touch.
(3) The G7 print key on the consecutive pair: key-equal / output-equal cells, every hole, and lost reuse by key
    component, next to the 3-apart numbers (v4.31.0 vs v4.34.1: 71.89% of 308,089, 6 holes).
(4) The 182 panics of the key pass ("PANIC at Lean.getStructureInfo Lean.Structure:139:4: structure expected"): which
    declarations, which component, a fix, and whether the fix changes the 3-apart result.
(5) Where lost reuse comes from, what a finer key could recover, and the cost of the key pass and of the content check.

    The one hole: MeasureTheory.VectorMeasure.measureOf', equation `↑self = self.1` in v4.31.0, `self.measureOf' =
    self.1` in v4.32.0 (its refs gain measureOf'). v4.31.0's source has `attribute [coe]
    VectorMeasure.measureOf'`, v4.32.0's does not: the declaration's OWN coercion attribute changed. The key covers the
    coercion data of referenced constants only, and the declaration's own name is not among them because its equation
    is generated at extraction time, not stored (class: own printing attribute). The six 3-apart holes (H1 instance
    synthesis inside `⊔`/`max` 2, H3 parent-projection path 2, H5 equation generation failing on old meta code 2) do not
    occur here. Other variants on the consecutive pair: F0 72.26% / 1 hole, G2 83.42% / 1, F7 84.89% / 2 (+ the matcher
    value of Mathlib.Tactic.Abel.isAtom), F8 94.17% / 7, F9 94.42% / 20 (full table under THE KEY ON THE CONSECUTIVE
    PAIR).
(4) The panics (measured). All 182 come from one place: the projection-structure layout (component SPSTR, added to the
    key in the levers log's fourth key iteration) looked the structure up as the projection's constructor name minus
    its last component. For a private constructor that prefix is `_private.<module>.0.<S>` (81 of the 91 projections:
    AlgCat.carrier, ModuleCat.carrier, the *.Hom.hom' projections of 30 concrete categories, TopRep, Rep, ...), and for
    a macro-scoped constructor the prefix drops the scopes (10: RpcEncodablePacket.* in two Mathlib widget files);
    neither is a registered structure, so getStructureFieldsFlattened and getStructureParentInfo panicked once each:
    91 x 2 = 182 in the hybrid (v4.31.0 and v4.32.0 alike), 21 x 2 = 42 natively in v4.34.1. The stderr of the levers
    runs dates it: 0 panics through the passes before SPSTR (nk2/nk3, hk/hk2), 42 / 182 from the first pass with it
    (nk4, hk3) on - which answers the runner log's "what changed between them is not established".
    The fix: the structure is the constructor's inductive type, read off the constructor; a name that is still not a
    registered structure becomes an explicit component value (marker 92 or 93) and is reported by name, never a panic's
    default. After the fix: 0 panics in every pass; all 91 / 21 projections resolve through the inductive (the marker
    branches never fired). The fix changed the key value: 3,452 of the 557,366 v4.31.0 component rows differ, all in
    SPSTR (row diff against the unfixed pass, whose file hashed exactly to the levers log's a9437240...).
    Effect on the 3-apart result: none in the counts. With v4.34.1's native IR and keys regenerated, every cell of all 11
    variants equals the levers log's table and the six G7 holes are the same six names. What is compared is counts and
    hole names; whether the key-equal SET is identical was not compared (the unfixed native key file no longer existed).
    The panic default had been the same on both sides of each pair for the same projections, which is why the counts did
    not move (inferred).

    SSTR is one upstream change: 32 referenced structures changed fields or parents, and 30,677 of the lost declarations
    name one of them (IR refs as the proxy for the shown set): Ring 8,730, Field 8,551, Monoid 5,126, AddMonoid 3,755,
    DivisionRing 1,230, GroupWithZero 722, LinearOrderedCommGroupWithZero 619, OpenPartialHomeomorph 506, AffineSubspace
    474, Semifield 463, ... In v4.32.0 the data fields `npow` / `nsmul` / `zpow` / `zsmul` became parent classes
    (`toNPow` / `toNSMul` / `toZPow` / `toZSMul`, parents NPow / NSMul / ZPow / ZSMul) in Monoid, AddMonoid,
    DivInvMonoid, SubNegMonoid and everything above them (read from both versions' structure info, STRUCTURES below). A
    declaration that mentions `[Ring R]` prints none of Ring's fields.
    What a finer key would recover (bounded by measured points; the estimate between them is theoretical):
      G7 as is                                        260,835  83.90%  1 hole
      F7 (G7 without SAUX, SPSTR)                     263,918  84.89%  2 holes
      F8 (F7 without SSTR: structure data dropped)    292,766  94.17%  7 holes
      F9 (own content as shown + shown names only)    293,552  94.42%  20 holes
    F8's 5 extra holes are printed structure instances whose field was renamed (AffineSubspace.comap / map / mk',
    affineSpan, Submodule.toAffineSubspace: `smul_vsub_vadd_mem` -> `smul_vsub_vadd_mem'`). A key that keeps SSTR only
    for structures whose constructor is shown (structure-instance notation) or whose fields are the declaration's own
    members would still catch those and would recover most of the 28,039 SSTR-only declarations: about 92-94% key-equal
    (theoretical; not implemented). At 3 apart the same component is again the largest (SSTR alone 26,202 of 56,026;
    Ring 8,221, Field 7,908, Monoid 4,759, AddMonoid 3,448), followed by own type as shown (TS alone 14,053).
    Adding the declaration's own referenced-constant record to its key would catch the one consecutive hole at a cost of
    at least 286 reuses (all through PSTR), counted only on the 51,995 key-equal declarations that some declaration shows
    (208,840 others have no own record in the dump; unmeasured).
    Costs (measured, M1): the key pass 100.4 s (v4.31.0, 557,366 candidates) and 103.9 s (v4.32.0, 566,246), single
    threaded, after decode + assembly (whole keys-only process 242.6 / 247.9 s wall, peak footprint 4.32 / 4.31 GB);
    natively on v4.34.1 101.5 s (580,218). The content check: 77.1 s (v4.31.0, 6.998 GB read) and 73.0 s (v4.32.0, 6.937
    GB) per version, one module at a time, peak RSS 108 / 133 MB; the comparison of two content files 55.6 s, 1.9 GB.

What this means for the redesign's premise (c) (theoretical; premises: G7 as measured, decode and assembly unchanged):
    between consecutive minors, 83.90% of shared declarations reuse their print by count (the time share is not measured
    here; at 3 apart it was 60.6% of analysis time for 71.89% by count), and 95.99% is the most any rule could reuse. An
    environment patch by module would rebuild 69% of Mathlib's modules (constants differ in 5,647 of 8,150) and 89% if
    every extension entry has to match; by constant it is ~13% of the closure.

CONTENT HASHES (how (1) and (2) were measured)
----------------------------------------------
contenthash reads each module of the `Mathlib` closure (one at a time, all parts, the reader's loader and version
check) and hashes the stored object graph from the root of ModuleData: an object's hash is its tag, its object fields'
hashes and its scalar bytes (arrays: size and elements; strings, scalar arrays and bignums: their payload), so equal
content hashes equal whatever its addresses and the header (which carries the writer's githash) is not read. A
constructor's tail padding is part of its scalar bytes; Lean's allocator zeroes the last word of a constructor whose
size is rounded up, for exactly this purpose (lean_alloc_ctor_memory in lean.h: "we make sure the sharing maximizer
procedures at maxsharing.cpp and compact.cpp are not affected by uninitialized data"). Per constant: kind, universe
names, type, value (definitions, theorems, opaques; a theorem's value is its proof), whole ConstantInfo; per module the
header arrays and each extension's entry array. 64-bit hashes (mixHash); a collision would count a changed item as
unchanged (not checked; ~10^6 items per file). Proofs are read: the reader's proofs-omitted mode is not used here, so
"value equal" for a theorem compares the proofs.
contentcmp.py pairs modules and constants by name (a constant by the first closure module that lists it), and the
documented set by the IR names. Made to fail once (measured, 20 modules): one constant's type hash and one module's
entries changed in a copy -> "type" 5,167 -> 5,166, the rec kind row 209 -> 208, "constants + decoded entries equal" 15
-> 14, auxRecExt listed as differing.

  let rec go : Name → Array Json → Array Json
    | .anonymous, acc => acc
    | .str p s, acc => go p (acc.push (Json.str s))
    | .num p k, acc => go p (acc.push (toJson k))
  Json.arr (go n #[]).reverse

def jsonToName (j : Json) : Except String Name := do
  let cs ← j.getArr?
  cs.foldlM (init := Name.anonymous) fun acc c =>
    match c with
    | .str s => pure (Name.mkStr acc s)
    | .num _ => do pure (Name.mkNum acc (← c.getNat?))
    | _ => throw "bad name component"

def biCode : BinderInfo → String
  | .default => "d" | .implicit => "i" | .strictImplicit => "s" | .instImplicit => "c"

def codeBi : String → BinderInfo
  | "i" => .implicit | "s" => .strictImplicit | "c" => .instImplicit | _ => .default

partial def serL (l : Level) : StateM SState Nat := do
  if let some i := (← get).lmap[l]? then return i
  let j ← match l with
    | .zero => pure (Json.arr #["z"])
    | .succ a => do let i ← serL a; pure (Json.arr #["s", toJson i])
    | .max a b => do let i ← serL a; let k ← serL b; pure (Json.arr #["m", toJson i, toJson k])
    | .imax a b => do let i ← serL a; let k ← serL b; pure (Json.arr #["i", toJson i, toJson k])
    | .param n => pure (Json.arr #["p", nameToJson n])
    | .mvar m => do
      modify fun s => { s with lmvars := s.lmvars + 1 }
      pure (Json.arr #["v", nameToJson m.name])
  let s ← get
  let idx := s.levels.size
  set { s with levels := s.levels.push j, lmap := s.lmap.insert l idx }
  return idx

partial def serE (e : Expr) : StateM SState Nat := do
  if let .mdata _ b := e then
    modify fun s => { s with mdata := s.mdata + 1 }
    return (← serE b)
  if let some i := (← get).emap[StrictE.mk e]? then return i
  let j ← match e with
    | .bvar i => pure (Json.arr #["b", toJson i])
    | .fvar id => do
      modify fun s => { s with fvars := s.fvars + 1 }
      pure (Json.arr #["F", nameToJson id.name])
    | .mvar id => do
      modify fun s => { s with mvars := s.mvars + 1 }
      pure (Json.arr #["M", nameToJson id.name])
    | .sort l => do pure (Json.arr #["S", toJson (← serL l)])
    | .const n ls => do
      let is ← ls.mapM serL
      pure (Json.arr #["C", nameToJson n, Json.arr (is.toArray.map toJson)])
    | .app f a => do let i ← serE f; let k ← serE a; pure (Json.arr #["A", toJson i, toJson k])
    | .lam n t b bi => do
      let i ← serE t; let k ← serE b
      pure (Json.arr #["L", nameToJson n, Json.str (biCode bi), toJson i, toJson k])
    | .forallE n t b bi => do
      let i ← serE t; let k ← serE b
      pure (Json.arr #["P", nameToJson n, Json.str (biCode bi), toJson i, toJson k])
    | .letE n t v b nd => do
      let i ← serE t; let k ← serE v; let m ← serE b
      pure (Json.arr #["E", nameToJson n, toJson i, toJson k, toJson m, toJson nd])
    | .lit (.natVal n) => pure (Json.arr #["N", Json.str (toString n)])
    | .lit (.strVal s) => pure (Json.arr #["T", Json.str s])
    | .proj s i b => do let k ← serE b; pure (Json.arr #["J", nameToJson s, toJson i, toJson k])
    | .mdata _ _ => unreachable!
  let s ← get
  let idx := s.nodes.size
  set { s with nodes := s.nodes.push j, emap := s.emap.insert (StrictE.mk e) idx }
  return idx

def serialize (e : Expr) : Json × SState :=
  let (root, s) := (serE e).run {}
  (Json.mkObj [("levels", Json.arr s.levels), ("nodes", Json.arr s.nodes), ("root", toJson root)], s)

/-- `oracle <searchpath-file> <limit|all> <oracle.jsonl> <out-types.jsonl|->`: reads every module
of `Mathlib`'s closure once, entries decoded, proofs omitted unless `ORACLE_KEEP_PROOFS=1`, and compares the serialized type of
every oracle record. -/
def oracleMain (spFile limitS oracle outTypes : String) : IO UInt32 := do
  let sp ← readSearchPath spFile
  let t0 ← IO.monoMsNow
  let mods ← closure sp #[`Mathlib]
  let mods := if limitS == "all" then mods else mods.extract 0 limitS.toNat!
  let mut wanted : Std.HashSet Name := {}
  let mut oracleRecs : Array (Name × String) := #[]
  for line in ← IO.FS.lines oracle do
    if line.isEmpty then continue
    let j ← IO.ofExcept (Json.parse line)
    let nameS ← IO.ofExcept (j.getObjValAs? String "nameStr")
    let ty ← IO.ofExcept (j.getObjVal? "type")
    let nj ← IO.ofExcept (j.getObjVal? "name")
    let n := (← IO.ofExcept nj.getArr?).foldl (init := Name.anonymous) fun acc c =>
      match c with
      | .str s => Name.mkStr acc s
      | .num k => Name.mkNum acc k.mantissa.toNat
      | _ => acc
    unless n.toString == nameS do throw <| IO.userError s!"name decode mismatch {n} vs {nameS}"
    wanted := wanted.insert n
    oracleRecs := oracleRecs.push (n, ty.compress)
  let omitProofs := (← IO.getEnv "ORACLE_KEEP_PROOFS") != some "1"
  let stats ← IO.mkRef ({} : ReadStats)
  let mut found : Std.HashMap Name String := {}
  let mut bytes := 0
  let mut objects := 0
  for m in mods do
    let parts ← loadModule sp m
    let ((md, _), st) ← runDM parts (decModuleData omitProofs true parts.back!.root stats)
    bytes := bytes + parts.foldl (· + ·.bytes.size) 0
    objects := objects + st.objects
    for ci in md.constants do
      if wanted.contains ci.name && !found.contains ci.name then
        found := found.insert ci.name (serialize ci.type).1.compress
  let t1 ← IO.monoMsNow
  let s ← stats.get
  let w ← writerOfClosure.get
  IO.eprintln s!"writer of every part read: Lean {w}"
  IO.eprintln s!"modules {mods.size}, bytes {bytes}, objects visited {objects}, constants {s.constants}, entries decoded {s.entriesDecoded}, entries not decoded {s.entriesSkipped} in {s.skippedExts.size} extensions; {t1 - t0} ms"
  IO.eprintln s!"checked against the stored computed field: Name hashes {s.names}, Level data {s.levels}, Expr data {s.exprs}"
  for (e, k) in s.decodedExts.toArray.qsort (fun a b => a.1.toString < b.1.toString) do
    IO.eprintln s!"  decoded ext {e} {k}"
  for (e, k) in s.skippedExts.toArray.qsort (fun a b => a.2 > b.2) do
    IO.eprintln s!"  not decoded ext {e} {k}"
  let mut same := 0
  let mut missing := 0
  let mut diff := #[]
  for (n, ty) in oracleRecs do
    match found[n]? with
    | none => missing := missing + 1
    | some t => if t == ty then same := same + 1 else diff := diff.push n
  IO.println s!"oracle: identical {same} of {oracleRecs.size}; not found {missing}; different {diff.size}"
  for n in diff.extract 0 10 do IO.println s!"  different: {n}"
  if outTypes != "-" then
    let h ← IO.FS.Handle.mk outTypes .write
    for (n, _) in oracleRecs do
      if let some t := found[n]? then h.putStrLn t
  return if same == oracleRecs.size then 0 else 1

def main (args : List String) : IO UInt32 := do
  match args with
  | [sp, limit, oracle, out] => oracleMain sp limit oracle out
  | _ => IO.eprintln "usage: oracle <searchpath-file> <limit|all> <oracle.jsonl> <out-types.jsonl|->"; return 2

/-! Content hashes of every module of `Mathlib`'s closure, from the stored object graph rather than
the file bytes (the header carries the writer's githash): a 64-bit hash per module part, per
constant (its type, its value, the whole `ConstantInfo`) and per extension's entries. Every object
is hashed from its tag, its object fields' hashes and its scalar bytes, so two graphs with the same
content hash the same whatever their addresses. The scalar bytes include a constructor's tail
padding, which Lean's allocator zeroes for this purpose (`lean_alloc_ctor_memory`, lean.h). -/

def readSearchPath (f : System.FilePath) : IO (Array System.FilePath) := do
  return (← IO.FS.lines f).filter (!·.isEmpty) |>.map System.FilePath.mk

def bytesHash (b : ByteArray) (start stop : Nat) (h : UInt64) : UInt64 := Id.run do
  let mut h := h
  let mut i := start
  while i + 8 ≤ stop do
    h := mixHash h (u64 b i); i := i + 8
  while i < stop do
    h := mixHash h (u8 b i).toUInt64; i := i + 1
  return mixHash h (stop - start).toUInt64

partial def rawHash (memo : IO.Ref (Std.HashMap UInt64 UInt64)) (v : UInt64) : DM UInt64 := do
  if isScalar v then return mixHash 1 v
  if let some h := (← memo.get)[v]? then return h
  let x ← obj "object" v
  let h ← if x.tag ≤ 244 then do
      let mut h := mixHash 2 (mixHash x.tag.toUInt64 x.other.toUInt64)
      for i in [0:x.other] do h := mixHash h (← rawHash memo (x.field i))
      pure (bytesHash x.b (x.o + 8 + 8*x.other) (x.o + x.csSz) h)
    else if x.tag == 246 then do
      let n := (u64 x.b (x.o + 8)).toNat
      let mut h := mixHash 3 n.toUInt64
      for i in [0:n] do h := mixHash h (← rawHash memo (u64 x.b (x.o + 24 + 8*i)))
      pure h
    else if x.tag == 248 then
      let n := (u64 x.b (x.o + 8)).toNat
      pure (bytesHash x.b (x.o + 24) (x.o + 24 + n * x.other) (mixHash 4 x.other.toUInt64))
    else if x.tag == 249 then
      let n := (u64 x.b (x.o + 8)).toNat
      pure (bytesHash x.b (x.o + 32) (x.o + 32 + n) 5)
    else if x.tag == 250 then
      let sz := u32 x.b (x.o + 12)
      let limbs := if sz ≥ 0x80000000 then (0 - sz).toNat else sz.toNat
      pure (bytesHash x.b (x.o + 24) (x.o + 24 + 8 * limbs) (mixHash 6 sz.toUInt64))
    else fail "object" v s!"tag {x.tag} is not expected in a compacted module"
  memo.modify (·.insert v h)
  return h

def kindName : Nat → String
  | 0 => "axiom" | 1 => "defn" | 2 => "thm" | 3 => "opaque" | 4 => "quot" | 5 => "induct"
  | 6 => "ctor" | 7 => "rec" | _ => "?"

/-- One module's lines (the file starts with a `D` line per extension the hybrid decodes): `M` module, isModule, parts, hashes of imports / constNames /
extraConstNames, constant count; `C` per constant: name, kind, level params, type, value (`0` if
the kind has none), whole `ConstantInfo`; `E` per extension: name, entry count, entries. -/
def moduleLines (m : Name) (root : UInt64) (nparts : Nat) : DM (Array String) := do
  let memo ← IO.mkRef ({} : Std.HashMap UInt64 UInt64)
  let x ← ctor "ModuleData" root 0 5 1
  let consts ← obj "Array ConstantInfo" (x.field 2)
  let n := (u64 consts.b (consts.o + 8)).toNat
  let mut out := #[s!"M\t{m}\t{x.sc8 0}\t{nparts}\t{← rawHash memo (x.field 0)}\t{← rawHash memo (x.field 1)}\t{← rawHash memo (x.field 3)}\t{n}"]
  for i in [0:n] do
    let cv := u64 consts.b (consts.o + 24 + 8*i)
    let c ← obj "ConstantInfo" cv
    let w ← obj "XVal" (c.field 0)
    let k ← ctor "ConstantVal" (w.field 0) 0 3 0
    let name ← decName (k.field 0)
    let value ← if c.tag == 1 || c.tag == 2 || c.tag == 3 then rawHash memo (w.field 1) else pure 0
    out := out.push s!"C\t{m}\t{name}\t{kindName c.tag}\t{← rawHash memo (k.field 1)}\t{← rawHash memo (k.field 2)}\t{value}\t{← rawHash memo cv}"
  let es ← obj "entries" (x.field 4)
  let ne := (u64 es.b (es.o + 8)).toNat
  for i in [0:ne] do
    let p ← ctor "Name × Array EnvExtensionEntry" (u64 es.b (es.o + 24 + 8*i)) 0 2 0
    let e ← decName (p.field 0)
    let arr ← obj "Array EnvExtensionEntry" (p.field 1)
    out := out.push s!"E\t{m}\t{e}\t{u64 arr.b (arr.o + 8)}\t{← rawHash memo (p.field 1)}"
  return out

def main (args : List String) : IO UInt32 := do
  let [spFile, outPath, limitS] := args
    | IO.eprintln "usage: contenthash <searchpath-file> <out.tsv> <limit|all>"; return 2
  let sp ← readSearchPath spFile
  let t0 ← IO.monoMsNow
  let mods ← closure sp #[`Mathlib]
  let mods := if limitS == "all" then mods else mods.extract 0 limitS.toNat!
  let h ← IO.FS.Handle.mk outPath .write
  for (e, _, _) in entryDecoders do h.putStrLn s!"D\t{e}"
  let mut bytes := 0
  let mut objects := 0
  for m in mods do
    let parts ← loadModule sp m
    let (lines, st) ← runDM parts (moduleLines m parts.back!.root parts.size)
    bytes := bytes + parts.foldl (· + ·.bytes.size) 0
    objects := objects + st.objects
    h.putStr ("\n".intercalate lines.toList ++ "\n")
  h.flush
  let t1 ← IO.monoMsNow
  IO.eprintln s!"writer: Lean {← writerOfClosure.get}; modules {mods.size}, bytes {bytes}, objects visited {objects}; {t1 - t0} ms"
  return 0

constant), modules by decoded content, renamed-looking declarations.

usage: contentcmp.py <content-A.tsv> <content-B.tsv> <ir-A> <ir-B> [--limit N]
A is the earlier version. <ir-*> are extractor IR directories (their declaration names are the

args = sys.argv[1:]

if '--limit' in args:
    i = args.index('--limit')

def load(path):
    decoded, mods, consts, exts = [], {}, {}, defaultdict(dict)
    order = []
    for line in open(path, encoding='utf-8'):
        p = line.rstrip('\n').split('\t')
        if p[0] == 'D':
            decoded.append(p[1])
        elif p[0] == 'M':
            if limit is not None and len(order) >= limit:
                break
            m = p[1]
            order.append(m)
            mods[m] = {'isModule': p[2], 'parts': p[3], 'imports': p[4], 'constNames': p[5], 'extra': p[6],
                       'n': int(p[7]), 'consts': []}
        elif p[0] == 'C':
            m, n = p[1], p[2]
            rec = {'module': m, 'kind': p[3], 'lps': p[4], 'type': p[5], 'value': p[6], 'full': p[7]}
            mods[m]['consts'].append(n)
            if n not in consts:
                consts[n] = rec
        elif p[0] == 'E':
            exts[p[1]][p[2]] = (int(p[3]), p[4])
        else:
            raise SystemExit(f'unknown line kind {p[0]!r} in {path}')
    for m, d in mods.items():
        if len(d['consts']) != d['n']:
            raise SystemExit(f'{path}: module {m} lists {len(d["consts"])} constants, header says {d["n"]}')
    return decoded, order, mods, consts, exts


def ir_names(ir):
    if ir == '-':
        return None
    out = set()
    for f in os.listdir(os.path.join(ir, 'modules')):
        for d in json.load(open(os.path.join(ir, 'modules', f), encoding='utf-8'))['declarations']:
            out.add(d['name'])
    return out

def floor(names, label):
    names = sorted(names)
    c = Counter()
    for n in names:
        a, b = CA[n], CB[n]
        c['type'] += a['type'] == b['type']
        c['type + lps'] += a['type'] == b['type'] and a['lps'] == b['lps']
        same_v = a['value'] == b['value']
        c['type + value'] += a['type'] == b['type'] and a['lps'] == b['lps'] and same_v and a['kind'] == b['kind']
        nonthm = same_v or (a['kind'] == 'thm' and b['kind'] == 'thm')
        c['type + value, theorem proofs ignored'] += (a['type'] == b['type'] and a['lps'] == b['lps'] and nonthm
                                                       and a['kind'] == b['kind'])
        c['whole constant'] += a['full'] == b['full']
        c['kind ' + b['kind']] += 1
        c['kind ' + b['kind'] + ' type+value(no proofs) equal'] += (a['type'] == b['type'] and a['lps'] == b['lps']
                                                                      and nonthm and a['kind'] == b['kind'])
    print(f'content floor, {label}: {len(names)} declarations in both')
    for k in ['type', 'type + lps', 'type + value', 'type + value, theorem proofs ignored', 'whole constant']:
        print(f'  {k:40s} {c[k]:7d}  {pct(c[k], len(names))}')
    for k in sorted(x for x in c if x.startswith('kind ') and not x.endswith('equal')):
        e = c[k + ' type+value(no proofs) equal']
        print(f'    {k:30s} {c[k]:7d}, type+value (no proofs) equal {e} ({pct(e, c[k])})')


def renames(removed, added, label):
    key = lambda r: (r['kind'], r['lps'], r['type'], r['value'] if r['kind'] != 'thm' else '')
    idx = defaultdict(list)
    for n in added:
        idx[key(CB[n])].append(n)
    uniq = amb = 0
    ex = []
    for n in sorted(removed):
        hits = idx.get(key(CA[n]), [])
        if len(hits) == 1:
            uniq += 1
            if len(ex) < 12:
                ex.append(f'{n} -> {hits[0]}')
        elif hits:
            amb += 1
    print(f'{label}: removed {len(removed)}, added {len(added)}; renamed-looking (same kind, universe names, type, '
          f'and value unless a theorem) unique {uniq}, ambiguous {amb}')
    for e in ex:
        print('    ' + e)


allboth = [n for n in CA if n in CB]
floor(allboth, 'every constant of the closure')
renames([n for n in CA if n not in CB], [n for n in CB if n not in CA], 'closure constants')
if DA is not None and DB is not None:
    for n in DA | DB:
        if (n in DA and n not in CA) or (n in DB and n not in CB):
            raise SystemExit(f'documented declaration {n} has no constant in its content file')
    docboth = DA & DB
    floor(docboth, 'documented declarations (IR names) in both')
    renames(DA - DB, DB - DA, 'documented declarations')

"""Content equality (contenthash) x G7 key equality x printed-output equality for the declarations two
IRs share, and how many key-equal declarations a key that also covered the declaration's own
referenced-constant record would lose or catch.

usage: crosstab.py <content-A.tsv> <content-B.tsv> <ir-A> <comps-A> <recs-A> <ir-B> <comps-B> <recs-B> [--limit N]
"""
import sys
from collections import Counter
args = sys.argv[1:]
limit = None
if '--limit' in args:
    i = args.index('--limit'); limit = int(args[i + 1]); args = args[:i] + args[i + 2:]
ca, cb, ira, ka, ra, irb, kb, rb = args
import keycmp_lib as K
from keycmp2_variants import VARIANTS, load_comps
G7 = VARIANTS['G7 = F7 + opaque/matcher values + projection structure layout']
OWNREC = ['SH', 'AUX', 'PSTR', 'PROJ', 'CLS', 'STR', 'COE', 'PP', 'MAT', 'PROT']


def content(p):
    out = {}
    for line in open(p, encoding='utf-8'):
        q = line.rstrip('\n').split('\t')
        if q[0] == 'C' and q[2] not in out:
            out[q[2]] = (q[3], q[4], q[5], q[6] if q[3] != 'thm' else '')
    return out


def recs(p):
    f = open(p, encoding='utf-8')
    h = f.readline().rstrip('\n').split('\t')
    return {l.split('\t')[0]: dict(zip(h[1:], l.rstrip('\n').split('\t')[1:])) for l in f}


A, B = K.load(ira, limit), K.load(irb, limit)
_, CA = load_comps(ka)
_, CB = load_comps(kb)
TA, TB = content(ca), content(cb)
RA, RB = recs(ra), recs(rb)
both = [n for n in A if n in B]
c = Counter()
own = Counter()
for n in both:
    ce = TA[n] == TB[n]
    ke = all(CA[n][x] == CB[n][x] for x in G7)
    oe = A[n][1] == B[n][1]
    c[('content=' if ce else 'content!', 'key=' if ke else 'key!', 'out=' if oe else 'out!')] += 1
    if ke:
        if n in RA and n in RB:
            d = [x for x in OWNREC if RA[n][x] != RB[n][x]]
            own['key-equal, own record on both sides'] += 1
            if d:
                own['... own record differs' + (' (output equal: reuse lost)' if oe else ' (output different: hole caught)')] += 1
                for x in d:
                    own['    component ' + x] += 1
        else:
            own['key-equal, own record missing on a side (not shown by any declaration)'] += 1
print(f'declarations in both: {len(both)}')
for k in sorted(c):
    print(f'  {" ".join(k):28s} {c[k]:7d}  {100 * c[k] / len(both):.2f}%')
ce = sum(v for k, v in c.items() if k[0] == 'content=')
print(f'content equal (type, universe names, value unless a theorem): {ce}; of them key-equal '
      f'{sum(v for k, v in c.items() if k[:2] == ("content=", "key="))}, output-equal '
      f'{sum(v for k, v in c.items() if k[0] == "content=" and k[2] == "out=")}')
for k, v in own.items():
    print(f'  {k}: {v}')

=== holedetail.py
"""Every hole of one key variant, printed with the differing fields of both IRs side by side.

usage: holedetail.py <holes.jsonl> <variant-prefix> <ir-A> <ir-B>
"""
import json, os, sys

holes_path, prefix, ir_a, ir_b = sys.argv[1:]
holes = [h for h in map(json.loads, open(holes_path, encoding='utf-8')) if h['variant'].startswith(prefix)]


def decl(ir, module, name):
    fn = os.path.join(ir, 'modules', module + '.json')
    for d in json.load(open(fn, encoding='utf-8'))['declarations']:
        if d['name'] == name:
            return d
    raise SystemExit(f'{name} not in {fn}')


def field(d, f):
    if f == 'refnames':
        return [r[1] for r in d.get('refs', [])]
    if f == 'members':
        return [{k: x for k, x in m.items() if k != 'doc'} for m in d.get('members', [])]
    return d.get(f, '<absent>')


print(f'{len(holes)} holes of variant {prefix}')
for h in holes:
    a = decl(ir_a, h['moduleA'], h['name'])
    b = decl(ir_b, h['moduleB'], h['name'])
    print(f'== {h["name"]} ({h["moduleA"]} / {h["moduleB"]}): {", ".join(h["fields"])}')
    for f in h['fields']:
        va, vb = field(a, f), field(b, f)
        if f == 'refnames':
            print(f'   refs only A: {sorted(set(va) - set(vb))}; only B: {sorted(set(vb) - set(va))}')
        else:
            print(f'   {f} A: {json.dumps(va, ensure_ascii=False)[:600]}')
            print(f'   {f} B: {json.dumps(vb, ensure_ascii=False)[:600]}')
