# A litedoc4 sample

Every page here was written by `litedoc4 build` from an eleven-module Lean
package with no Mathlib under it, and rebuilt from `main` on every push. The
point is the shapes a page can take, not the scale — the site next to this one,
[422 modules on Mathlib](https://fujiharuka.github.io/information-theory/), is
the scale.

Read a page beside the source it links to. Each module below is listed with the
heading its own docstring opens with, which is where the one-line descriptions
on this page come from.
