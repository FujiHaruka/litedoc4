      The two marks an incomplete proof leaves on a page #

      Three declarations: one with a hole of its own, one that depends on it, and one with neither.

      A declaration whose own statement or proof uses sorry is marked uses sorry. One whose own proof is complete but which depends on such a declaration is marked depends on sorry. Those are different claims and the page keeps them apart. The answer comes from the compiled environment — the declaration's axiom set — so it holds through any depth of dependency, and a declaration marked neither has no hole anywhere under it.

      source
      uses sorry
      (n : Nat) :
      double n = n + n

      A theorem proved by sorry: its own proof term is the hole, so the page marks it uses sorry. This is the declaration the other two are defined against.
