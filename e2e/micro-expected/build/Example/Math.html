      LaTeX in a docstring, converted while the site is built #

      It reaches the page as MathML. Nothing is loaded in the browser to draw it — no MathJax, no KaTeX, no math web font — because every current browser lays MathML out itself.

      The four declarations below are the four answers, and the last one is the one to look at: a formula the converter cannot read is written back as its own source, so a page is never worse than one that never tried. The build says how many were kept that way, because a page whose formulas silently stayed unconverted is still a valid page.
