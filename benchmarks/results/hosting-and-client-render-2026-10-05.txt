Where the multi-version Mathlib site can be hosted, and what a data-driven page costs the reader
(plan U6 and U7)
=============================================================================================
2026-10-05

Questions
---------
  U6  Where can the multi-version Mathlib site be hosted, with numbers: size and file count for
      11 versions today and about 51 in two years (D2), per D4 row, against each host's documented
      limits and price.
  U7  What does a page drawn in the browser from data cost the reader, against the static HTML
      page of today, on the largest Mathlib module page.

Answer
------
  1. File count is the binding limit, not bytes, and sharing content does not reduce it.
     D6 gives every page of every version its own URL. On a static host without path rewrites, each
     URL is a file, so the page count is 8,170 x N in every D4 row. That is 89,870 files at 11
     versions and 416,670 at 51, before any data file is counted (theoretical, below).
     The count goes down only if the host returns one shell file with status 200 for any path.
     Cloudflare Pages, Workers static assets and Netlify document this. CloudFront Functions can
     rewrite URLs (documented), and R2 can use a Cloudflare zone rewrite. Neither of those two
     rewrites was measured. GitHub Pages cannot: its fallback is the 404 page, served with 404.
  2. Stored compression already does most of the shrinking, for HTML as well as for data. The 8,170
     module pages gzip to 54.8 MB, each page compressed on its own. The same content in the data
     scheme below gzips to 28.6 MB, which is 0.52x of that, and brotli gives 23.9 MB (measured).
     Carrying content as data instead of HTML saves 1.9x after compression, not 5x.
     So a host that serves a stored .gz file with Content-Encoding: gzip can hold static HTML for
     every version: 0.77 GB at 11 versions and 3.6 GB at 51 (extrapolated), with no-JS reading kept.
     S3 + CloudFront documents this. R2 behind a Cloudflare domain does it when the object carries
     Content-Encoding and Cache-Control: no-transform (documented in parts, not measured). GitHub Pages, Cloudflare
     Pages, Workers, Netlify and Vercel do not document it.
  3. Once declarations are shared, the per-version layer is most of the bytes, and Used by is most
     of the per-version layer. Thin HTML + shared data comes to 0.32 GB at 11 versions and 1.38 GB
     at 51. Of the 1.38 GB, 780 MB is the global files that every version carries (Used by is
     10.3 MB of the 15.3 MB per version, gzip) and 553 MB is the page shells. The shared declaration
     content is only 50 MB (all theoretical, premises in the sizing section).
  4. The used-by.json of one version is 78,162,880 B (74.5 MiB) as the site writes it today. That is
     3x Cloudflare's 25 MiB per-file limit (Pages and Workers alike). The current single-version site
     cannot be put on Cloudflare unchanged. Gzipped, the file is 10.3 MB and fits.
  5. Verdict, in short (the table and the reasons are in "U6 verdict"):
       - Static HTML per version, stored precompressed: S3 + CloudFront, or R2 behind a Cloudflare
         domain. Fits 11 and 51 versions; $0 to $15 a month at the assumed traffic.
       - Thin HTML + shared data with a 200 rewrite: Cloudflare Workers static assets or Cloudflare
         Pages. With the packing assumed here (33,000 files), 11 versions fit only on the $5 paid
         plan; the free plan needs packing coarser than one file per module per version. 51 versions
         need the paid plan and coarser packing (133,000 files as assumed). Without a rewrite, the
         page files alone pass the 100,000-file cap at 51 versions.
       - GitHub Pages fits nothing at 51 versions, by its documented 1 GB, even with Used by cut to
         the latest version.
  6. U7: on the largest page (387 declarations, 1.99 MB of HTML) the data-driven page is not slower
     than the static one, when both run on loopback with no network cost (measured, medians of 5
     runs, Chrome 154 headless):
       static as published         first paint 188 ms, DOMContentLoaded 263 ms, settled 361 ms
       static, no CSS and no JS    first paint 160 ms, settled 240 ms
       static, no CSS and no JS,
         wrappers removed          first paint 160 ms, settled 189 ms
       data, no CSS                fetch 10, decompress 10, parse 12, DOM built 32,
                                   settled 153 ms, first paint 164 ms
       data with the site's CSS    DOM built 32, settled 160 ms, first paint 172 ms
     ("settled" = two animation frames after the content exists; for static, after the load event.)
     Layout and paint take about 120 ms of every variant, and the element count decides it. The
     wrappers that D4 rule 3 drops are 21,378 of the static page's 42,200 elements. Static HTML
     without them settles at 189 ms, against 153 ms for the data page and 240 ms with the wrappers.
     Most of the gain comes from dropping the wrappers, not from the data format.
  7. Two facts that bind a plan decision:
     - Chrome 154 has no DecompressionStream("brotli"); the constructor throws (measured). Content
       stored as brotli can be read only when the host sends Content-Encoding: br. Without host
       support, D4 rule 1 means gzip, which is 1.20x the brotli bytes (measured).
     - A #name link from outside does not scroll on a page drawn by script (measured: scrollY 0, and
       :target null). Per the HTML standard, the browser stops retrying the fragment scroll when the
       parser stops, and script draws the content after that. The page must scroll for itself.
       location.replace(location.href) after drawing scrolls and also sets :target (measured);
       scrollIntoView() scrolls but leaves :target null.
     - Google reads an instant meta refresh as a permanent redirect (cited below). A site root that
       uses one to point at the newest version tells Google that the root moved permanently to a URL
       that changes at the next release. A 302 from the host, or a script redirect, says
       "temporary". This bears on D6.

U7 — data scheme (defined for this measurement)
-----------------------------------------------
  One JSON file per module page, compact separators, UTF-8:
    m    module name
    i    imports, as indexes into L
    md   module docstrings as HTML strings, in page order, interleaved with integers (the number of
         declarations drawn before that docstring)
    d    declarations, each an object:
           n  name (also the anchor id)       k  kind
           s  own source line range as "#L33-L40", appended to S (or an index into L when the
              source is not in the module's own file)
           t  signature: [binders, type, parents?]; binders = [[0|1, tokens]...] with
              0 = explicit and 1 = any bracketed binder (the page's two classes);
              type = tokens; parents (structures) = [[anchor id, tokens]...]
           a  attribute line as text           f  flags
           d  docstring as HTML, kept as a string (links in it not re-encoded)
           e  equations, a list of token lists
           fl structure fields: [[constructor id, [[field id, inherited 0|1, name, tokens, doc HTML]...]]]
    L    the page's link table: every distinct link target once. A Mathlib target is written
         "Mathlib/A/B#Name" (no root prefix, no .html). A GitHub source target is written
         "@owner/repo/path#Lx-Ly", and its revision is kept once per page in R.
    R    {owner/repo: revision}            S    the module's own source URL
  tokens = a list of text strings and [index into L, link text] pairs.
  Dropped: every <span class="fn"> wrapper (D4 rule 3), the "On this page" sidebar (the client
  rebuilds it from d), the page chrome, and the empty Used by / Instances placeholders (filled on
  the client today as well).
  Not separated: the per-version layer (own line ranges, the Lean core revision) still sits in
  each page's file. That matches a single-version site; a multi-version store moves it out.

U7 — desk findings
------------------
  JavaScript off. The data page draws nothing; with no <noscript> text the reader sees a blank page.
    D4 accepts this (decided 2026-10-04). The static row and the precompressed-static option in U6
    keep reading without JavaScript.
  In-page anchors and links from outside. HTML Standard, "try to scroll to the fragment" and
    "scroll to the fragment", https://html.spec.whatwg.org/multipage/browsing-the-web.html,
    read 2026-10-05:
      "If document has no parser, or its parser has stopped parsing, or the user agent has reason to
       believe the user is no longer interested in scrolling to the fragment, then abort these
       steps. Scroll to the fragment given document. If document's indicated part is still null,
       then try to scroll to the fragment for document."
    The browser retries only while the parser runs. Content added by script after parsing is never
    found by that loop, which agrees with the measurement above. "Scroll to the fragment" also sets
    the document's target element (:target). A page drawn by script therefore needs to run a
    fragment navigation itself after drawing. Navigating to the same URL with location.replace
    restores both the scroll and :target (measured above). A later in-page click on #name is an
    ordinary fragment navigation and works without help, because the content then exists.
    The D9 replacement check ("every anchor reached after the browser has drawn the page —
    including a #name link arriving from outside") is exactly this case.
  Search engines. Google, "Understand the JavaScript SEO basics",
    https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics
    (last updated 2026-03-04; read 2026-10-05): Googlebot crawls, queues the page for rendering, and
    a headless Chromium "renders the page and executes the JavaScript"; "The page may stay on this
    queue for a few seconds, but it can take longer than that"; "server-side or pre-rendering is
    still a great idea because it makes your website faster for users and crawlers, and not all bots
    can run JavaScript"; links are discovered only from "<a> HTML elements with an href attribute".
    So Google indexes client-drawn content after a delay. Crawlers that do not run JavaScript see an
    empty shell. Links that the client draws are found only after rendering.
  Canonical URL (one page exists once per version, D6). Google, "How to specify a canonical URL",
    https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls
    (last updated 2026-07-10; read 2026-10-05): redirects and rel="canonical" are "strong" signals,
    a sitemap is "weak"; a canonical link injected by JavaScript is supported, but "The best way to
    do this is to specify the canonical URL in the HTML source code". A thin shell can carry its
    rel="canonical" in its HTML, so this does not need the data.
  Root redirect (D6). Google, "Redirects and Google Search",
    https://developers.google.com/search/docs/crawling-indexing/301-redirects
    (last updated 2026-04-14; read 2026-10-05): 301/308 make the target canonical; 302/307 do not;
    "Google Search interprets instant meta refresh redirects as permanent redirects"; delayed
    meta refresh as temporary; JavaScript redirects are seen only if rendering succeeds.

  From U3 (mathlib-release-sharing-2026-10-04.txt), at level (d):
    minor pair: 308,449 of 317,834 declarations reuse an earlier entry, so 2.95% of a version is new
    content; 3,448 of 8,261 common modules have an identical IR contentHash, so 58.3% of modules
    changed; patch pair: 2 of 317,834 new (measured, one pair each).
  Release mix (assumed): of today's 10 consecutive pairs, 5 are minor (x.y -> x.y+1) and 5 are patch.
    The ~40 releases of the next two years (D2) are assumed to follow the same mix: 20 minor, 20 patch.
    So 5 minor transitions at 11 versions and 25 at 51. Patch transitions are taken as adding nothing.
    That holds for the one patch pair measured, a single toolchain-bump commit. Patch releases that
    carry Mathlib changes would add more.

  Sharing factor for declaration content (extrapolated, from one minor pair and the mix above):
    11 versions  1 + 5 x 2.95% = 1.148     51 versions  1 + 25 x 2.95% = 1.738
  The same, if the unit of sharing is a whole module page (a page is shared only when no declaration
  on it changed; changed-module share from contentHash as proxy, theoretical):
    11 versions  1 + 5 x 58.3% = 3.91      51 versions  1 + 25 x 58.3% = 15.6

    canonical, one stylesheet and one script tag) plus the per-version layer that only this version
    knows: for each declaration a content key and its own line range, about 24 B each.
    298,656 x 24 + 8,170 x 450 = 10.9 MB per version, uncompressed. Not measured — no shell was built.

  Row 3 with a host that returns one shell for any path with status 200 (theoretical): the page
    shells collapse to one file. The per-version layer then has to be fetched as data. Packed as
    about 100 chunks per version (assumed chunking), the total is about 33,000 files at 11 versions
    and about 133,000 at 51. At 51 the module packs are still 127,144 files. Getting under 100,000
    then needs packing by namespace rather than by module, which is a D5 choice.

  What the numbers say
  - The page files dominate the file count in every row that keeps D6's per-version URLs as real
    files. Rows 2 and 3 do not reduce that count, they only make each file small.
  - Bytes: once content is shared it is small (33-50 MB). What remains is the per-version layer:
    global files (Used by alone is 10.3 MB gzip per version) and shells.
  - Per-file: the largest single file is used-by.json, 78,162,880 B (74.5 MiB) raw and 10.3 MB gzip.
    name-map.json is 24,335,490 B (23.2 MiB), just under 25 MiB. The largest module data file is
    319,496 B raw. The largest module page is 1,993,587 B.

#!/usr/bin/env python3
"""Convert a litedoc4 module page into the compact data scheme, report counts.

usage: page2json.py <site dir> <out dir> <page path>...
"""
import collections
import json
import re
import sys
from html.parser import HTMLParser

VOID = {"br", "img", "meta", "link", "input", "hr", "wbr"}


class Node:
    __slots__ = ("tag", "attrs", "kids", "parent")

    def __init__(self, tag, attrs, parent):
        self.tag, self.attrs, self.kids, self.parent = tag, dict(attrs), [], parent

    def cls(self):
        return self.attrs.get("class") or ""


class Tree(HTMLParser):
    def __init__(self):
        super().__init__(convert_charrefs=True)
        self.root = Node("#root", [], None)
        self.cur = self.root

    def handle_starttag(self, tag, attrs):
        n = Node(tag, attrs, self.cur)
        self.cur.kids.append(n)
        if tag not in VOID:
            self.cur = n

    def handle_startendtag(self, tag, attrs):
        self.cur.kids.append(Node(tag, attrs, self.cur))

    def handle_endtag(self, tag):
        n = self.cur
        while n is not None and n.tag != tag:
            n = n.parent
        if n is not None and n.parent is not None:
            self.cur = n.parent

    def handle_data(self, data):
        self.cur.kids.append(data)


def find_all(n, pred, out=None):
    out = [] if out is None else out
    for k in n.kids:
        if isinstance(k, Node):
            if pred(k):
                out.append(k)
            find_all(k, pred, out)
    return out


def first(n, pred):
    r = find_all(n, pred)
    return r[0] if r else None


def text(n):
    return "".join(k if isinstance(k, str) else text(k) for k in n.kids)


def esc(s):
    return s.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;")


def inner_html(n):
    out = []
    for k in n.kids:
        if isinstance(k, str):
            out.append(esc(k))
        else:
            a = "".join(f' {key}="{esc(v or "")}"' for key, v in k.attrs.items())
            out.append(f"<{k.tag}{a}>")
            if k.tag not in VOID:
                out.append(inner_html(k))
                out.append(f"</{k.tag}>")
    return "".join(out)


class Links:
    """Page-level link table. Revisions of GitHub source URLs are stored once per page."""

    GH = re.compile(r"^https://github\.com/([^/]+/[^/]+)/blob/([0-9a-f]{40})/(.*)$")

    def __init__(self, root_prefix):
        self.root_prefix = root_prefix
        self.table, self.index, self.revs = [], {}, {}

    def ref(self, href):
        if href.startswith(self.root_prefix):
            key = href[len(self.root_prefix):].replace(".html#", "#")
            if key.endswith(".html"):
                key = key[:-5]
        else:
            m = self.GH.match(href)
            if m:
                repo, rev, path = m.groups()
                self.revs[repo] = rev
                key = f"@{repo}/{path}"
            else:
                key = href
        if key not in self.index:
            self.index[key] = len(self.table)
            self.table.append(key)
        return self.index[key]


def tokens(n, links, stats):
    """Text and links only; every wrapper span is dropped (D4 rule 3)."""
    out = []

    def push_text(s):
        if out and isinstance(out[-1], str):
            out[-1] += s
        else:
            out.append(s)

    def walk(x):
        for k in x.kids:
            if isinstance(k, str):
                push_text(k)
            elif k.tag == "span" and k.cls() == "field-name":
                continue
            elif k.tag == "a" and "href" in k.attrs:
                stats["links"] += 1
                out.append([links.ref(k.attrs["href"]), text(k)])
            else:
                if k.tag != "span" or k.cls() not in ("fn", "name", "colon", "binder", "binder implicit"):
                    stats["other_in_sig:" + k.tag + "." + k.cls()] += 1
                walk(k)

    walk(n)
    return out


BINDER = {"binder": 0, "binder implicit": 1}


def sig(n, links, stats):
    binders, typ, parents = [], None, []
    for k in n.kids:
        if isinstance(k, str):
            if k.strip() and k.strip() != ",":
                stats["loose_sig_text:" + k.strip()[:10]] += 1
            continue
        c = k.cls()
        if c == "extends":
            continue
        if k.tag == "span" and "id" in k.attrs:
            stats["extends_parent"] += 1
            parents.append([k.attrs["id"], tokens(k, links, stats)])
        elif c.startswith("binder"):
            code = BINDER.get(c)
            if code is None:
                stats["binder_class:" + c] += 1
                code = c
            binders.append([code, tokens(k, links, stats)])
        elif c == "sig-type":
            typ = tokens(k, links, stats)
        elif c == "colon":
            pass
        else:
            stats["sig_child:" + k.tag + "." + c] += 1
    return [binders, typ, parents] if parents else [binders, typ]


def decl(sec, links, stats, mod_src):
    d = {"n": sec.attrs["id"], "k": sec.attrs.get("data-kind")}
    for k in sec.kids:
        if isinstance(k, str):
            continue
        c = k.cls()
        if k.tag == "header":
            src = first(k, lambda x: x.tag == "a" and x.cls() == "src")
            if src is not None:
                href = src.attrs["href"]
                d["s"] = href[len(mod_src):] if href.startswith(mod_src) else links.ref(href)
        elif c == "sig":
            stats["sig"] += 1
            d["t"] = sig(k, links, stats)
        elif c == "doc":
            d["d"] = inner_html(k)
        elif c == "attrs":
            d["a"] = text(k)
        elif c == "flags":
            d["f"] = [x.attrs.get("data-flag") for x in find_all(k, lambda x: x.cls() == "flag")]
        elif k.tag == "details" and c == "extra":
            fill = k.attrs.get("data-fill")
            if fill:
                stats["fill:" + fill] += 1
                continue
            eqs = first(k, lambda x: x.cls() == "equations")
            if eqs is not None:
                d["e"] = [tokens(li, links, stats) for li in eqs.kids if isinstance(li, Node)]
                stats["equations"] += len(d["e"])
            else:
                stats["extra_other:" + text(first(k, lambda x: x.tag == "summary") or k)[:20]] += 1
        elif c == "fields" or k.tag == "ul":
            fs = []
            for li in k.kids:
                if not isinstance(li, Node):
                    continue
                fn = first(li, lambda x: x.cls() == "field-name")
                fsig = first(li, lambda x: x.cls() == "field-sig")
                fdoc = first(li, lambda x: x.cls() == "field-doc")
                stats["field_sig"] += fsig is not None
                fs.append([li.attrs.get("id"), 1 if "inherited" in li.cls() else 0,
                           text(fn) if fn else "", tokens(fsig, links, stats) if fsig else None,
                           inner_html(fdoc) if fdoc else None])
            d.setdefault("fl", []).append([k.attrs.get("id"), fs])
        else:
            stats["decl_child:" + k.tag + "." + c] += 1
            d.setdefault("x", []).append(inner_html(k))
    return d


def convert(site, rel):
    raw = open(f"{site}/{rel}", encoding="utf-8").read()
    t = Tree()
    t.feed(raw)
    body = first(t.root, lambda x: x.tag == "body")
    root_prefix = body.attrs["data-root"]
    module = body.attrs["data-module"]
    main = first(t.root, lambda x: x.tag == "main")
    stats = collections.Counter()
    links = Links(root_prefix)
    modsrc_a = first(main, lambda x: x.tag == "p" and x.cls() == "modactions")
    mod_src = first(modsrc_a, lambda x: x.tag == "a").attrs["href"] if modsrc_a else ""
    page = {"m": module}
    imports = first(main, lambda x: x.tag == "details" and x.cls() == "imports")
    if imports is not None:
        page["i"] = [links.ref(a.attrs["href"]) for a in find_all(imports, lambda x: x.tag == "a")]
    moddoc = [inner_html(x) for x in main.kids if isinstance(x, Node) and x.cls() == "moddoc"]
    decls = []
    for k in main.kids:
        if not isinstance(k, Node):
            continue
        if k.tag == "section" and k.cls() == "decl":
            stats["decl"] += 1
            decls.append(decl(k, links, stats, mod_src))
            moddoc.append(len(decls))
        elif k.cls() == "moddoc":
            pass
        elif k.cls() not in ("modhead", "modmeta"):
            stats["main_child:" + k.tag + "." + k.cls()] += 1
    page["md"] = moddoc
    page["d"] = decls
    page["L"] = links.table
    page["R"] = links.revs
    page["S"] = mod_src
    return raw, page, stats


def main():
    site, out = sys.argv[1], sys.argv[2]
    for rel in sys.argv[3:]:
        raw, page, stats = convert(site, rel)
        js = json.dumps(page, ensure_ascii=False, separators=(",", ":"))
        name = rel.replace("/", ".")[:-5]
        with open(f"{out}/{name}.json", "w", encoding="utf-8") as f:
            f.write(js)
        with open(f"{out}/{name}.html", "w", encoding="utf-8") as f:
            f.write(raw)
        print(rel, len(raw.encode()), len(js.encode()), dict(stats.most_common()))


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""Every module page -> data scheme; per-page sizes as TSV.

usage: allpages.py <site dir> <out tsv> [limit]
"""
import json
import os
import subprocess
import sys
import zlib

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from page2json import convert  # noqa: E402


def pages(site):
    for d, _, fs in os.walk(os.path.join(site, "Mathlib")):
        for f in sorted(fs):
            if f.endswith(".html"):
                yield os.path.relpath(os.path.join(d, f), site)


def main():
    site, out = sys.argv[1], sys.argv[2]
    limit = int(sys.argv[3]) if len(sys.argv) > 3 else None
    rels = sorted(pages(site))[:limit]
    with open(out, "w") as o:
        o.write("page\tdecls\tsigs\thtml\thtml_gz6\tjson\tjson_gz6\tjson_gz9\tjson_br11\n")
        for i, rel in enumerate(rels):
            raw, page, stats = convert(site, rel)
            h = raw.encode()
            j = json.dumps(page, ensure_ascii=False, separators=(",", ":")).encode()
            br = subprocess.run(["brotli", "-q", "11", "-c"], input=j, capture_output=True, check=True).stdout
            o.write(f"{rel}\t{stats['decl']}\t{stats['sig']}\t{len(h)}\t{len(zlib.compress(h, 6))}\t"
                    f"{len(j)}\t{len(zlib.compress(j, 6))}\t{len(zlib.compress(j, 9))}\t{len(br)}\n")
            if i % 500 == 0:
                print(i, rel, file=sys.stderr, flush=True)


if __name__ == "__main__":
    main()
