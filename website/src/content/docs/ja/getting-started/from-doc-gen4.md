---
title: doc-gen4 から移る
description: doc-gen4 と同じところと違うところ。
---

litedoc4 は doc-gen4 のページパス、宣言のアンカー、docstring の Markdown、参考文献の形式をそのまま保っています。doc-gen4 のサイト向けに書いたリンクや docstring は変更なしで動きます。

ページパスは先頭にバージョンが付いた `<version>/Foo/Bar.html` で、その後ろは doc-gen4 と同じ形です。宣言のアンカーは `#Foo.bar` です。バージョンを含まない doc-gen4 形式のリンクは、存在しないパスにサイトの `404.html` を返すホストであれば、最新バージョンの同じページに移動します。GitHub Pages はそのように動きます。

## 違うところ

| | doc-gen4 | litedoc4 |
|---|---|---|
| 依存先 | import の閉包全体のページ | あなたのパッケージだけ。依存先の名前はそのソースにリンク |
| 検索 | import するすべての宣言 | あなたのパッケージの宣言 |
| 数式 | ブラウザ上の MathJax | サイトのビルド時に MathML へ変換 |
| ページ | 静的 HTML | スクリプトで描画。HTTP で配信する |
| litedoc4 にないもの | | タクティクのページ、`find/?pattern=` リンク、宣言データの JSON、ローカルファイルと VS Code へのソースリンク |

依存先の名前は、固定したリビジョンのソースにリンクします。ほかのドキュメントサイトにはリンクしません。
