doc-gen4 and litedoc4 documenting Batteries v4.35.0: speed and memory, same runner, same scope
================================================================================================
Date: 2026-10-17 (UTC). One job on a GitHub-hosted ubuntu-latest runner (run 39048621516, branch
probe/batteries-bench, commit 953f56918a57c98f18104727df46733230540ab2, deleted afterwards; workflow, driver and
summarizer under CODE). Both tools ran on the same machine, rounds alternating doc-gen4 / litedoc4.
Why Batteries: no dependency but Lean core, so both tools document the same modules. The Mathlib comparison
(benchmarks/results/docgen4-runner-2026-10-17.txt) is what a user pays, with different scopes; this one is the
same-scope comparison.

- doc-gen4's 80.5 s includes its final HTML job (lake-printed 37-39 s per round), which writes every module in its
  database: Batteries' 194 pages AND Lean core's 2,505 (Init 652, Std 493, Lean 1,226, Lake 134). The same job
  over core alone (an empty library) took 35 s (lake-printed 33 s) in setup. That cost is not subtracted above; a
  doc-gen4 user cannot avoid it. Subtracting it would be an estimate (the two runs are separate), not a
  measurement: roughly 80.5 - 33 = ~47 s (extrapolated).
- "peak anon, process tree" = the maximum over 1-s samples of the sum of RssAnon over every process under the
  measured command. It is what the machine must hold. doc-gen4 peaks with 4 concurrent per-module processes, each
  loading its own import closure; litedoc4 holds one long-lived extractor. "Largest process RSS" is GNU time's
  maximum resident set size of the single largest process, file-backed (mmapped .olean) pages included, which is
  why it is ~1 GiB for both and is not the number to compare.
- The machine's view (MemTotal - MemAvailable, peak minus the value just before the round), per round:
  litedoc4 216 MiB (157-237); doc-gen4 3,377 MiB (3,243-3,451) - doc-gen4's figure covers docs + docsHeader.
- Swap: 0 pages out in every round of both tools.
- Scope check, every round: doc-gen4 built exactly the 195 declared Batteries docInfo jobs (Batteries.lean +
  194 under Batteries/; glob and import closure agree), no core docInfo, no coreDocs rebuild, no Batteries
  compilation; litedoc4 extracted 195 of 195 and rendered 194 module pages under Batteries/ plus the root.
  Rounds passing / declared: every cell 5 of 5 (1 of 1 for cold and warm-up).

CONDITIONS
----------
- Runner: GitHub-hosted ubuntu-latest, 4 vCPU = AMD EPYC 7763, 2 cores x 2 threads; MemTotal 16,373,452 kB;
  swap 3,145,724 kB. Public repository, free tier.
- Lean v4.35.0; Batteries v4.35.0 66e469188fe07963e5cf666c7d4433f45b8131c5 (built in the job, 73.0 s, not
  measured); doc-gen4 tag v4.35.0; litedoc4 at the probe commit (= main 2026-10-17 plus the probe files), binary
  sha256 ad1d2698ae686e513c677420f720ab4238e5c4c20ca066dd927ea26ce31857eb.
- litedoc4: `build --root <batteries> --lib Batteries --out <out> --jobs <n> --lake <lake>`, no --config: the
  defaults, equations, refs and tagged code on for every declaration (no no_equations_under). doc-gen4 computes
  equations for every definition too, so the equations asymmetry of the Mathlib log does not apply here.
- Excluded from both, symmetrically: building doc-gen4 (67.6 s) and doc-gen4's core database (coreDocs, 417 s,
  plus core's HTML 35 s), made once in setup and restored before every doc-gen4 round (rsync of a snapshot of
  .lake/build); litedoc4's extractor compile (~10 s), made once in a discarded prime round and reused.
- Each round starts from no Batteries output: doc-gen4 from the snapshot (0 Batteries markers checked), litedoc4
  from an out dir holding only the extractor and its build marker; litedoc4 reports "extract everything".
- Warm: wall vs CPU is not a warmth test with 4 jobs; rounds after the first per tool had ~0 major faults.
- Memory sampler: 1-s interval over /proc/<pid>/status of the measured tree and /proc/meminfo, /proc/vmstat. A
  doc-gen4 per-module process lives a few seconds, so a peak between samples can be missed; the tree-sum peak is
  a lower bound for doc-gen4.

WHAT IS NOT MEASURED
--------------------
- Variation between runners (one job); other hardware.
- doc-gen4 at 1 job (no flag; above).
- doc-gen4 without core's HTML pass (not separable in one run).
- Larger libraries at the same scope (Mathlib's comparison has different scopes).

#!/bin/bash
# doc-gen4 and litedoc4 documenting Batteries on one runner, in alternating rounds that each
# start from the same state. One subcommand per workflow step; everything it writes goes to $LOGS.
#   probe.sh start            timings header, the machine at the start, lake's CLI, the repository's HEAD
#   probe.sh free-disk        the runner's preinstalled toolchains this run does not use
#   probe.sh elan             elan with no default toolchain
#   probe.sh litedoc4-bin     litedoc4 built as tools/mathlib-site.sh setup builds it
#   probe.sh batteries        Batteries $BATTERIES_TAG (--depth 1), `lake build Batteries`, its
#                             declared libraries and modules
#   probe.sh docgen-ws        the workaround workspace: doc-gen4 $DOCGEN_REV and ../batteries
#   probe.sh docgen-build     `lake build doc-gen4`
#   probe.sh docgen-core      core's docInfo (@doc-gen4/coreDocs) and HTML (Workaround:docs), then
#                             the snapshot of .lake/build every doc-gen4 round is reset to
#   probe.sh litedoc4-prime   one litedoc4 round that builds the extractor the later rounds reuse
#   probe.sh rounds-minutes   the rounds step's timeout-minutes into $GITHUB_OUTPUT
#   probe.sh rounds           cold, warm-up and $ROUNDS warm rounds at $JOBS_HI, then up to $ROUNDS at
#                             $JOBS_LO; arms alternate, and a round starts only with 1.5x the
#                             longest round of its arm left before the deadline
#   probe.sh summarize        summary.tsv and cells.tsv from rounds.tsv
#   probe.sh end              the machine at the end
# Environment: JOB_START (epoch seconds, set by the workflow's first step), PROBE_WORK, LOGS,
# BATTERIES_TAG, DOCGEN_REV, ROUNDS, JOBS_HI, JOBS_LO, DOCGEN_JOBS1 (skip | lean-num-threads),
# JOB_MINUTES, RESERVE_MINUTES, STEP_RESERVE_MINUTES, ROUND_TIMEOUT_S, DOCGEN4_FIRST_ESTIMATE_S,
# LITEDOC4_FIRST_ESTIMATE_S, BATTERIES_BUILD_TIMEOUT, LITEDOC4_BIN, GNU_TIME, TIMEOUT_BIN.

BATTERIES_BUILD_TIMEOUT=${BATTERIES_BUILD_TIMEOUT:-3600}

utc() { date -u +%Y-%m-%dT%H:%M:%SZ; }

timing_line() {
  printf '%s\t%s\t%s\t%s\t%s\n' "$1" "$2" "$3" "$4" "$5" | tee -a "$LOGS/timings.txt"
}

timed() {
  local name=$1; shift
  local s0 t0 t1 rc
  s0=$(utc); t0=$(date +%s.%N)
  if "$@"; then rc=0; else rc=$?; fi
  t1=$(date +%s.%N)
  timing_line "$name" "$s0" "$(utc)" "$(awk -v a="$t0" -v b="$t1" 'BEGIN{printf "%.1f", b-a}')" "$rc"
  return "$rc"
}

remaining() {
  : "${JOB_START:?JOB_START comes from the first workflow step}"
  echo $(( JOB_START + (JOB_MINUTES - RESERVE_MINUTES) * 60 - $(date +%s) ))
}

record() {
  {
    echo "## date"; utc
    echo "## image"; echo "ImageOS=${ImageOS:-?} ImageVersion=${ImageVersion:-?} RUNNER_OS=${RUNNER_OS:-?}"
    echo "## kernel"; uname -a
    echo "## nproc"; getconf _NPROCESSORS_ONLN || true
    echo "## lscpu"; lscpu || true
    echo "## meminfo"; cat /proc/meminfo || true
    echo "## swap"; swapon --show || true; free -b || true
    echo "## vmstat"; grep -E '^(pswpin|pswpout|pgmajfault|oom_kill) ' /proc/vmstat || true
    echo "## df"; df -h || true
    echo "## vm sysctl"; sysctl vm.swappiness vm.overcommit_memory 2>/dev/null || true
    echo "## oom"; sudo -n dmesg 2>/dev/null | grep -iE 'out of memory|oom-kill|killed process' || echo "(none)"
  } > "$LOGS/machine-$1.txt" 2>&1
}

mem_line() {
  awk -v when="$1" '
    /^MemTotal:/ { mt = $2 } /^MemAvailable:/ { ma = $2 }
    /^pswpin / { si = $2 } /^pswpout / { so = $2 } /^pgmajfault / { mf = $2 }
    END { printf "%s\t%s\t%s\t%s\t%s\t%s\n", when, mt, ma, si, so, mf }' \
    /proc/meminfo /proc/vmstat 2>/dev/null || printf '%s\t\t\t\t\t\n' "$1"
}

tree_pids() {
  ps -e -o pid=,ppid= | awk -v root="$1" '
    { parent[$1] = $2 }
    END {
      inside[root] = 1
      grew = 1
      while (grew) {
        grew = 0
        for (p in parent) if (!(p in inside) && (parent[p] in inside)) { inside[p] = 1; grew = 1 }
      }
      for (p in inside) print p
    }'
}

sample() {
  local root=$1 out=$2 top=$3 tick=0
  printf 't\tVmRSS\tRssAnon\tRssFile\tVmSwap\tnprocs\tMemTotal\tMemAvailable\tCached\tSwapFree\tpswpin\tpswpout\tpgmajfault\tRootAvailKB\n' > "$out"
  : > "$top"
  while kill -0 "$root" 2>/dev/null; do
    local files tree sys disk
    files=$(tree_pids "$root" | sed 's#.*#/proc/&/status#')
    tree=$({ cat $files 2>/dev/null || true; } | awk '
      /^VmRSS:/ { a += $2 } /^RssAnon:/ { b += $2 } /^RssFile:/ { c += $2 } /^VmSwap:/ { d += $2 }
      /^Pid:/ { n++ }
      END { printf "%d\t%d\t%d\t%d\t%d", a, b, c, d, n }')
    sys=$(awk '
      /^MemTotal:/ { mt = $2 } /^MemAvailable:/ { ma = $2 } /^Cached:/ { ca = $2 } /^SwapFree:/ { sf = $2 }
      /^pswpin / { si = $2 } /^pswpout / { so = $2 } /^pgmajfault / { mf = $2 }
      END { printf "%s\t%s\t%s\t%s\t%s\t%s\t%s", mt, ma, ca, sf, si, so, mf }' \
      /proc/meminfo /proc/vmstat 2>/dev/null || printf '\t\t\t\t\t\t')
    disk=$(df -k --output=avail / 2>/dev/null | tail -1 | tr -d ' ' || true)
    printf '%s\t%s\t%s\t%s\n' "$(date +%s)" "$tree" "$sys" "$disk" >> "$out"
    if [ $((tick % 10)) -eq 0 ]; then
      { echo "== $(utc)"; ps -eo pid,ppid,rss,etimes,args --sort=-rss 2>/dev/null | head -8 | cut -c1-240; } >> "$top" || true
    fi
    tick=$((tick + 1))
    sleep 1
  done
}

measure() {
  local name=$1 budget=$2 log=$3; shift 3
  local s0 t0 t1 rc root sp wall outcome progress
  if [ "$budget" -lt 60 ]; then
    timing_line "$name" "$(utc)" "$(utc)" 0 124
    printf 'outcome\tnot started: %s s left before the deadline\nexit\t124\nwall_s\t0\n' "$budget" | tee "$LOGS/$name-outcome.txt"
    return 124
  fi
  record "before-$name"
  printf 'when\tMemTotal\tMemAvailable\tpswpin\tpswpout\tpgmajfault\n' > "$LOGS/$name-mem.tsv"
  mem_line before >> "$LOGS/$name-mem.tsv"
  echo "$name: budget $budget s, $*"
  s0=$(utc); t0=$(date +%s)
  "$GNU_TIME" -v -o "$LOGS/$name.time" "$TIMEOUT_BIN" -k 120 "$budget" "$@" > "$log" 2>&1 &
  root=$!
  sample "$root" "$LOGS/$name-sampler.tsv" "$LOGS/$name-top.txt" &
  sp=$!
  if wait "$root"; then rc=0; else rc=$?; fi
  t1=$(date +%s)
  wait "$sp" || true
  mem_line after >> "$LOGS/$name-mem.tsv"
  wall=$((t1 - t0))
  timing_line "$name" "$s0" "$(utc)" "$wall" "$rc"
  record "after-$name"
  if [ "$rc" -eq 0 ]; then outcome=finished
  elif { [ "$rc" -eq 124 ] || [ "$rc" -eq 137 ]; } && [ "$wall" -ge $((budget - 1)) ]; then outcome=timeout
  else outcome=failed
  fi
  progress=$(grep -oE '\[[0-9]+/[0-9]+\]' "$log" | tail -1 || true)
  {
    printf 'outcome\t%s\n' "$outcome"
    printf 'exit\t%s\n' "$rc"
    printf 'wall_s\t%s\n' "$wall"
    printf 'budget_s\t%s\n' "$budget"
    printf 'command\t%s\n' "$*"
    printf 'last_progress\t%s\n' "${progress:-(none)}"
    printf 'last_line\t%s\n' "$(tail -1 "$log" | cut -c1-400)"
  } | tee "$LOGS/$name-outcome.txt"
  return "$rc"
}

drop_caches() {
  sync
  echo 3 | sudo tee /proc/sys/vm/drop_caches > /dev/null
}

reset_docgen4() {
  rsync -a --delete "$SNAP/" "$WS/.lake/build/"
  printf 'batteries markers after reset\t%s\n' \
    "$(find "$WS/.lake/build/doc-data" -maxdepth 1 -name 'Batteries*' | wc -l | tr -d ' ')"
}

reset_litedoc4() {
  mkdir -p "$LD4OUT"
  find "$LD4OUT" -mindepth 1 -maxdepth 1 ! -name extractors ! -name litedoc4-build.json -exec rm -rf {} +
  printf 'litedoc4 out after reset\t%s\n' "$(ls "$LD4OUT" | tr '\n' ' ')"
}

longest_get() {
  if [ -f "$LONGEST" ]; then
    awk -F'\t' -v k="$1" '$1 == k && $2 > m { m = $2 } END { printf "%d\n", m }' "$LONGEST"
  else
    echo 0
  fi
}

needed_for() {
  local arm=$1 jobs=$2 est any
  est=$(longest_get "$arm-$jobs")
  if [ "$est" -eq 0 ]; then
    any=$(longest_get "$arm-$JOBS_HI")
    if [ "$any" -gt 0 ] && [ "$jobs" -lt "$JOBS_HI" ]; then
      est=$(( any * ((JOBS_HI + jobs - 1) / jobs) ))
    elif [ "$any" -gt 0 ]; then
      est=$any
    elif [ "$arm" = docgen4 ]; then
      est=$DOCGEN4_FIRST_ESTIMATE_S
    else
      est=$LITEDOC4_FIRST_ESTIMATE_S
    fi
  fi
  echo $(( est * 3 / 2 ))
}

SEQ_FILE=$LOGS/round-seq.txt

  printf 'r%02d-%s-j%s-%s' "$n" "$1" "$2" "$3"

docgen4_round() {
  local id=$1 jobs=$2 budget=$3 rc=0 left
  local envs
  if [ "$jobs" = "$JOBS_HI" ]; then envs=(env); else envs=(env "LEAN_NUM_THREADS=$jobs"); fi
  cd "$WS"
  measure "$id-docs" "$budget" "$LOGS/$id-docs.log" "${envs[@]}" lake build Batteries:docs || rc=$?
  if [ "$rc" -eq 0 ]; then
    left=$(remaining)
    if [ "$left" -gt "$ROUND_TIMEOUT_S" ]; then left=$ROUND_TIMEOUT_S; fi
    measure "$id-header" "$left" "$LOGS/$id-header.log" "${envs[@]}" lake build Batteries:docsHeader || rc=$?
  fi
  $BENCH html-count "$WS/.lake/build/doc" 1 > "$LOGS/$id-html.tsv" || true
  cd "$W"
  return "$rc"
}

litedoc4_round() {
  local id=$1 jobs=$2 budget=$3 rc=0
  measure "$id" "$budget" "$LOGS/$id.log" \
    "$LITEDOC4" build --root "$BATT" --lib Batteries --out "$LD4OUT" --jobs "$jobs" \
    --lake "$(command -v lake)" --timings "$LOGS/$id-timings.jsonl" || rc=$?
  $BENCH html-count "$LD4OUT/site" 2 > "$LOGS/$id-html.tsv" || true
  if [ -f "$LD4OUT/litedoc4-build.json" ]; then cp "$LD4OUT/litedoc4-build.json" "$LOGS/$id-build.json"; fi
  if [ -f "$LD4OUT/work/modules.txt" ]; then cp "$LD4OUT/work/modules.txt" "$LOGS/$id-modules.txt"; fi
  return "$rc"
}

round() {
  local arm=$1 jobs=$2 kind=$3 id need rem budget rc=0 parts result wall
  id=$(next_id "$arm" "$jobs" "$kind")
  need=$(needed_for "$arm" "$jobs")
  rem=$(remaining)
  if [ "$rem" -lt "$need" ]; then
    echo "$id: not started, $rem s left and $need s needed (1.5x the longest $arm round)"
    $BENCH skip --rows "$ROWS" --id "$id" --arm "$arm" --jobs "$jobs" --kind "$kind" \
      --reason "deadline: $rem s left, $need s needed"
    return 3
  fi
  budget=$rem
  if [ "$budget" -gt "$ROUND_TIMEOUT_S" ]; then budget=$ROUND_TIMEOUT_S; fi
  echo "== $id: $(utc), $rem s left"
  if ! "reset_$arm" > "$LOGS/$id-reset.txt" 2>&1; then
    cat "$LOGS/$id-reset.txt"
    $BENCH skip --rows "$ROWS" --id "$id" --arm "$arm" --jobs "$jobs" --kind "$kind" \
      --status reset-failed --reason "reset_$arm failed: $(tail -1 "$LOGS/$id-reset.txt" | cut -c1-200)"
    return 3
  fi
  if [ "$kind" = cold ]; then
    if ! drop_caches; then
      $BENCH skip --rows "$ROWS" --id "$id" --arm "$arm" --jobs "$jobs" --kind "$kind" \
        --status reset-failed --reason "drop_caches failed"
      return 3
    fi
    echo "page cache dropped" >> "$LOGS/$id-reset.txt"
  fi
  cat "$LOGS/$id-reset.txt"
  if [ "$arm" = docgen4 ]; then
    docgen4_round "$id" "$jobs" "$budget" || rc=$?
    parts="$id-docs,$id-header"
  else
    litedoc4_round "$id" "$jobs" "$budget" || rc=$?
    parts=$id
  fi
  if ! result=$($BENCH round --logs "$LOGS" --rows "$ROWS" --id "$id" --arm "$arm" --jobs "$jobs" \
      --kind "$kind" --parts "$parts" --declared "$LOGS/declared-closure.txt" \
      --declared-glob "$LOGS/declared-glob.txt"); then
    printf '%s\t%s\t%s\t%s\tbench-failed\n' "$id" "$arm" "$jobs" "$kind" >> "$ROWS"
    result="status bench-failed"
  fi
  printf '%s\n' "$result" | tee "$LOGS/$id-scope.txt"
  wall=$(printf '%s\n' "$result" | awk '$1 == "wall" { printf "%d", $2 }')
  if [ -n "$wall" ] && [ "$wall" -gt 0 ]; then printf '%s\t%s\n' "$arm-$jobs" "$wall" >> "$LONGEST"; fi
  return 0
}

def read_text(path):
    try:
        with open(path, encoding="utf-8", errors="replace") as f:
            return f.read()
    except OSError:
        return None


def cmd_libs(args):
    text = read_text(args.lakefile) or ""
    if args.lakefile.endswith(".toml"):
        names = []
        for block in re.split(r"^\[\[", text, flags=re.M)[1:]:
            if block.startswith("lean_lib]]"):
                m = re.search(r'^\s*name\s*=\s*"([^"]+)"', block, re.M)
                names.append(m.group(1) if m else "?")
    else:

def module_glob(root, lib):
    found = set()
    if os.path.isfile(os.path.join(root, lib + ".lean")):
        found.add(lib)
    base = os.path.join(root, lib)
    for d, _, files in os.walk(base):
        for f in files:
            if f.endswith(".lean"):
                rel = os.path.relpath(os.path.join(d, f), root)[:-len(".lean")]
                found.add(rel.replace(os.sep, "."))
    return found


def import_closure(root, lib):
    seen, stack = set(), [lib]
    while stack:
        mod = stack.pop()
        if mod in seen:
            continue
        seen.add(mod)
        text = read_text(os.path.join(root, *mod.split(".")) + ".lean")
        if text is None:
            continue
        stack.extend(i for i in IMPORT.findall(text) if i == lib or i.startswith(lib + "."))
    return seen


def cmd_declared(args):
    glob = module_glob(args.root, args.lib)
    closure = import_closure(args.root, args.lib)
    for name, mods in (("declared-glob.txt", glob), ("declared-closure.txt", closure)):
        with open(os.path.join(args.out, name), "w") as f:
            f.write("".join(m + "\n" for m in sorted(mods)))
    print("declared %s: %d by glob (%s.lean and %s/, what litedoc4 --lib reads), "
          "%d by import closure of %s (what doc-gen4's docInfo walks)"
          % (args.lib, len(glob), args.lib, args.lib, len(closure), args.lib))
    print("glob-not-closure\t%s" % " ".join(sorted(glob - closure)))
    print("closure-not-glob\t%s" % " ".join(sorted(closure - glob)))


def lake_jobs(text):
    jobs = []
    for line in (text or "").splitlines():
        m = JOB.match(line)
        if not m:
            continue
        name = m.group(4)
        base, _, facet = name.rpartition(":") if ":" in name else (name, "", "")
        pkg, _, target = base.partition("/") if "/" in base else ("", "", base)
        secs = None
        if m.group(5) is not None:
            secs = float(m.group(5)) / (1000.0 if m.group(6) == "ms" else 1.0)
        jobs.append({"verb": m.group(3), "name": name, "pkg": pkg, "target": target,
                     "facet": facet, "secs": secs})
    return jobs


def cmd_lakejobs(args):
    for j in lake_jobs(read_text(args.log)):
        print("\t".join([j["verb"], j["pkg"], j["target"], j["facet"],
                         "" if j["secs"] is None else "%.3f" % j["secs"], j["name"]]))


def cmd_html_count(args):
    counts = {}
    total = 0
    for d, _, files in os.walk(args.dir):
        rel = os.path.relpath(d, args.dir)
        parts = [] if rel == "." else rel.split(os.sep)
        key = "/".join(parts[:args.depth]) if len(parts) >= args.depth else "(above depth %d)" % args.depth
        n = sum(1 for f in files if f.endswith(".html"))
        if n:
            counts[key] = counts.get(key, 0) + n
            total += n
    print("dir\t%s" % args.dir)
    for key in sorted(counts):
        print("%s\t%d" % (key, counts[key]))
    print("total\t%d" % total)


def read_kv(path):
    out = {}
    for line in (read_text(path) or "").splitlines():
        k, sep, v = line.partition("\t")
        if sep:
            out[k] = v
    return out


def gnu_time(path):
    text = read_text(path)
    if text is None:
        return None
    vals = {}
    for line in text.splitlines():
        k, sep, v = line.strip().rpartition(": ")
        if sep:
            vals[k] = v.strip()
    def num(key):
        try:
            return float(vals[key])
        except (KeyError, ValueError):
            return None
    wall = None
    raw = vals.get("Elapsed (wall clock) time (h:mm:ss or m:ss)")
    if raw:
        try:
            wall = 0.0
            for piece in raw.split(":"):
                wall = wall * 60 + float(piece)
        except ValueError:
            wall = None
    return {"user": num("User time (seconds)"), "sys": num("System time (seconds)"), "wall": wall,
            "maxrss": num("Maximum resident set size (kbytes)"),
            "majflt": num("Major (requiring I/O) page faults")}


def read_tsv(path):
    text = read_text(path)
    if text is None:
        return []
    return list(csv.DictReader(text.splitlines(), delimiter="\t"))


def to_int(value):
    try:
        return int(float(value))
    except (TypeError, ValueError):
        return None


def peak(rows, key):
    vals = [to_int(r.get(key)) for r in rows]
    vals = [v for v in vals if v is not None]
    return max(vals) if vals else None


def part_measure(logs, part):
    outcome = read_kv(os.path.join(logs, part + "-outcome.txt"))
    t = gnu_time(os.path.join(logs, part + ".time"))
    samples = read_tsv(os.path.join(logs, part + "-sampler.tsv"))
    mem = {r.get("when"): r for r in read_tsv(os.path.join(logs, part + "-mem.tsv"))}
    before, after = mem.get("before", {}), mem.get("after", {})
    used_before = None
    if to_int(before.get("MemTotal")) is not None and to_int(before.get("MemAvailable")) is not None:
        used_before = to_int(before["MemTotal"]) - to_int(before["MemAvailable"])
    used = [to_int(r.get("MemTotal")) - to_int(r.get("MemAvailable")) for r in samples
            if to_int(r.get("MemTotal")) is not None and to_int(r.get("MemAvailable")) is not None]
    def delta(key):
        a, b = to_int(after.get(key)), to_int(before.get(key))
        return None if a is None or b is None else a - b
    return {
        "present": bool(outcome),
        "outcome": outcome.get("outcome", "missing"),
        "exit": to_int(outcome.get("exit")),
        "wall": (t or {}).get("wall") if (t or {}).get("wall") is not None else to_int(outcome.get("wall_s")),
        "user": (t or {}).get("user"), "sys": (t or {}).get("sys"), "maxrss": (t or {}).get("maxrss"),
        "anon": peak(samples, "RssAnon"), "vmrss": peak(samples, "VmRSS"),
        "rssfile": peak(samples, "RssFile"), "vmswap": peak(samples, "VmSwap"),
        "nprocs": peak(samples, "nprocs"), "samples": len(samples),
        "used_delta": (max(used) - used_before) if used and used_before is not None else None,
        "swapout": delta("pswpout"), "swapin": delta("pswpin"), "majflt": delta("pgmajfault"),
    }

    got = set(ours)
    row["docinfo_n"] = len(got)
    row["docinfo_job_sum_s"] = total(j["secs"] for j in docinfo if j["pkg"] == "batteries")
    if got != declared:
        missing, extra = sorted(declared - got), sorted(got - declared)
        problems.append("docInfo built for %d of %d declared modules (missing %d: %s; extra %d: %s)"
                        % (len(got & declared), len(declared), len(missing), " ".join(missing[:5]),
                           len(extra), " ".join(extra[:5])))
    if len(ours) != len(got):
        problems.append("docInfo built twice for %d module(s)" % (len(ours) - len(got)))
    if others:
        problems.append("docInfo built outside batteries: %d (%s)" % (len(others), " ".join(others[:5])))
    for label, jobs in (("docs", docs), ("docsHeader", header)):
        core = [j["name"] for j in jobs if j["verb"] == "Built" and j["target"] == "coreDocs"]
        if core:
            problems.append("%s rebuilt core: %s" % (label, " ".join(core)))
        compiled = [j["name"] for j in jobs if j["verb"] == "Built" and j["pkg"] == ""
                    and (j["target"] == "Batteries" or j["target"].startswith("Batteries."))
                    and j["facet"] != "docs"]
        if compiled:
            problems.append("%s compiled Batteries modules: %d (%s)" % (label, len(compiled), " ".join(compiled[:5])))
    lib_fromdb = [j for j in built if j["name"] == "batteries/Batteries:docs"]
    if not lib_fromdb:
        problems.append("no `Built batteries/Batteries:docs` (the library's fromDb) in the docs log")
    row["fromdb_lib_s"] = total(j["secs"] for j in lib_fromdb)
    hbuilt = [j for j in header if j["verb"] == "Built"]
    pkg_fromdb = [j for j in hbuilt if j["name"] == "batteries:docs"]
    header_data = [j for j in hbuilt if j["name"] == "batteries/Batteries:docsHeader"]
    hdocinfo = [j for j in hbuilt if j["facet"] == "docInfo"]
    row["fromdb_pkg_s"] = total(j["secs"] for j in pkg_fromdb)
    row["headerdata_s"] = total(j["secs"] for j in header_data)
    if read_text(os.path.join(logs, rid + "-header.log")) is not None:
        if not header_data:
            problems.append("no `Built batteries/Batteries:docsHeader` in the header log")
        if hdocinfo:
            problems.append("docsHeader built docInfo again: %d" % len(hdocinfo))
        if not pkg_fromdb:
            warnings.append("no `Built batteries:docs` (the package's fromDb) in the header log")
    known = {"batteries/Batteries:docs", "batteries:docs", "batteries/Batteries:docsHeader"}
    rest = sorted(set(j["name"] for j in docs + header
                      if j["verb"] == "Built" and j["facet"] != "docInfo" and j["name"] not in known
                      and j["target"] != "coreDocs" and not j["facet"].startswith("srcUri")))
    if rest:
        warnings.append("other built jobs: %s" % " ".join(rest[:10]))
    return problems, warnings


def litedoc4_scope(logs, rid, kind, declared, row):
    problems, warnings = [], []
    log = read_text(os.path.join(logs, rid + ".log")) or ""
    def line(prefix):
        for l in log.splitlines():
            if l.startswith(prefix):
                return l
        return None
    if line("lib     Batteries (--lib)") is None:
        problems.append("no `lib     Batteries (--lib)` line")
    mods = line("modules ")
    n = to_int(mods.split()[1]) if mods and len(mods.split()) > 1 else None
    row["ld4_modules"] = n
    if n != len(declared):
        problems.append("modules %s, declared %d" % (n, len(declared)))
    plan = line("plan    ")
    row["ld4_plan"] = (plan or "").replace("plan    ", "", 1)
    if not plan or not plan.startswith("plan    extract everything ("):
        problems.append("plan is not `extract everything`: %s" % plan)
    ext = line("extract ")
    m = re.match(r"extract\s+(\d+) module\(s\)", ext or "")
    extracted = int(m.group(1)) if m else None
    row["ld4_extracted"] = extracted
    if extracted != len(declared):
        problems.append("extracted %s, declared %d" % (extracted, len(declared)))
    extractor = line("extractor ")
    row["ld4_extractor"] = extractor or ""
    if kind != "prime" and (extractor is None or "(cached)" not in extractor):
        problems.append("extractor not reused: %s" % extractor)
    if line("versions rendered: 1 of 1") is None:
        problems.append("no `versions rendered: 1 of 1` line")
    listed = read_declared(os.path.join(logs, rid + "-modules.txt"))
    if listed and listed != declared:
        problems.append("work/modules.txt differs from the declared glob: missing %d, extra %d"
                        % (len(declared - listed), len(listed - declared)))
    if not listed:
        warnings.append("no copy of work/modules.txt")
    timings = None
    for l in (read_text(os.path.join(logs, rid + "-timings.jsonl")) or "").splitlines():
        try:
            obj = json.loads(l)
        except ValueError:
            continue
        if obj.get("command") == "build":
            timings = obj
    if timings is None:
        problems.append("no build line in the timings file")
    else:
        row["ld4_extract_s"] = timings.get("extractSeconds")
        row["ld4_put_s"] = timings.get("putSeconds")
        row["ld4_render_s"] = timings.get("renderSeconds")
        row["ld4_total_s"] = timings.get("totalSeconds")
        if timings.get("extracted") != len(declared) or timings.get("modules") != len(declared):
            problems.append("timings say modules %s extracted %s, declared %d"
                            % (timings.get("modules"), timings.get("extracted"), len(declared)))
    return problems, warnings


def fmt(value):
    if value is None:
        return ""
    if isinstance(value, float):
        return "%.1f" % value
    return str(value).replace("\t", " ").replace("\n", " ")


def append_row(path, row):
    header = "\t".join(COLUMNS) + "\n"
    existing = read_text(path) or ""
    if not existing.startswith(header):
        with open(path, "w") as f:
            f.write(header + existing)
    with open(path, "a") as f:
        f.write("\t".join(fmt(row.get(c)) for c in COLUMNS) + "\n")


def cmd_round(args):
    parts = [p for p in args.parts.split(",") if p]
    measured = [part_measure(args.logs, p) for p in parts]
    row = {"id": args.id, "arm": args.arm, "jobs": args.jobs, "kind": args.kind}
    ran = [m for m in measured if m["present"]]
    exits = [m["exit"] for m in ran]
    row["exit"] = ",".join("" if e is None else str(e) for e in exits)
    row["wall_s"] = total(m["wall"] for m in ran)
    row["user_s"] = total(m["user"] for m in ran)
    row["sys_s"] = total(m["sys"] for m in ran)
    if row["user_s"] is not None and row["sys_s"] is not None:
        row["cpu_s"] = row["user_s"] + row["sys_s"]
        if row["wall_s"]:
            row["cpu_pct"] = 100.0 * row["cpu_s"] / row["wall_s"]
    row["gnu_maxrss_kib"] = biggest(m["maxrss"] for m in ran)
    row["peak_tree_anon_kib"] = biggest(m["anon"] for m in ran)
    row["peak_machine_used_delta_kib"] = biggest(m["used_delta"] for m in ran)
    row["swapout_pages"] = total(m["swapout"] for m in ran)
    row["swapin_pages"] = total(m["swapin"] for m in ran)
    row["majflt_delta"] = total(m["majflt"] for m in ran)
    row["peak_nprocs"] = biggest(m["nprocs"] for m in ran)
    row["samples"] = total(m["samples"] for m in ran)
    row["peak_tree_vmrss_kib"] = biggest(m["vmrss"] for m in ran)
    row["peak_tree_rssfile_kib"] = biggest(m["rssfile"] for m in ran)
    row["peak_tree_vmswap_kib"] = biggest(m["vmswap"] for m in ran)
    if args.arm == "docgen4":
        row["docs_wall_s"] = measured[0]["wall"] if measured and measured[0]["present"] else None
        if len(measured) > 1 and measured[1]["present"]:
            row["header_wall_s"] = measured[1]["wall"]
        problems, warnings = docgen_scope(args.logs, args.id, read_declared(args.declared), row)
    else:
        problems, warnings = litedoc4_scope(args.logs, args.id, args.kind,
                                            read_declared(args.declared_glob), row)
    if len(ran) < len(parts):
        status = "incomplete"
        problems.insert(0, "%d of %d commands ran" % (len(ran), len(parts)))
    elif any(m["outcome"] == "timeout" for m in ran):
        status = "timeout"
    elif any(e != 0 for e in exits):
        status = "exit-fail"
    elif problems:
        status = "scope-fail"
    else:
        status = "ok"
    row["status"] = status
    row["note"] = "; ".join(problems + ["warning: " + w for w in warnings])
    append_row(args.rows, row)
    print("status %s" % status)
    for p in problems:
        print("FAIL %s" % p)
    for w in warnings:
        print("warning %s" % w)
    print("wall %s" % fmt(row["wall_s"]))


def cmd_skip(args):
    append_row(args.rows, {"id": args.id, "arm": args.arm, "jobs": args.jobs, "kind": args.kind,
                           "status": args.status, "note": args.reason})
    print("status %s" % args.status)


def stats(values):
    vals = [v for v in values if v is not None]
    if not vals:
        return ["", "", ""]
    return [fmt(float(statistics.median(vals))), fmt(float(min(vals))), fmt(float(max(vals)))]


def number(value):
    try:
        return float(value)
    except (TypeError, ValueError):
        return None


def mib(value):
    v = number(value)
    return None if v is None else v / 1024.0


def cmd_summarize(args):
    rows = read_tsv(args.rows)
    cells = []
    for line in (read_text(args.cells) or "").splitlines():
        f = line.split("\t")
        if len(f) >= 4 and f[3].isdigit():
            cells.append((f[0], f[1], f[2], int(f[3]), f[4] if len(f) > 4 else ""))
    groups = {}
    for r in rows:
        if r.get("status") == "ok" and r.get("kind") in SUMMARY_KINDS:
            groups.setdefault((r["arm"], r["jobs"], r["kind"]), []).append(r)
    header = ["arm", "jobs", "kind", "n",
              "wall_median_s", "wall_min_s", "wall_max_s",
              "cpu_median_s", "cpu_min_s", "cpu_max_s",
              "tree_anon_peak_median_mib", "tree_anon_peak_min_mib", "tree_anon_peak_max_mib",
              "machine_used_delta_median_mib", "machine_used_delta_min_mib", "machine_used_delta_max_mib",
              "largest_process_maxrss_median_mib", "swapout_pages_max", "peak_nprocs_max",
              "fromdb_lib_median_s", "fromdb_pkg_median_s"]
    lines = ["\t".join(header)]
    keys = sorted(set(list(groups) + [(c[0], c[1], c[2]) for c in cells if c[2] in SUMMARY_KINDS]),
                  key=lambda k: (k[0], -int(k[1]) if k[1].isdigit() else 0, k[2]))
    for key in keys:
        rs = groups.get(key, [])
        swap = [number(r.get("swapout_pages")) for r in rs]
        swap = [v for v in swap if v is not None]
        procs = [number(r.get("peak_nprocs")) for r in rs]
        procs = [v for v in procs if v is not None]
        lines.append("\t".join(
            list(key) + [str(len(rs))]
            + stats(number(r.get("wall_s")) for r in rs)
            + stats(number(r.get("cpu_s")) for r in rs)
            + stats(mib(r.get("peak_tree_anon_kib")) for r in rs)
            + stats(mib(r.get("peak_machine_used_delta_kib")) for r in rs)
            + stats(mib(r.get("gnu_maxrss_kib")) for r in rs)[:1]
            + [fmt(max(swap)) if swap else "", fmt(int(max(procs))) if procs else ""]
            + stats(number(r.get("fromdb_lib_s")) for r in rs)[:1]
            + stats(number(r.get("fromdb_pkg_s")) for r in rs)[:1]))
    with open(os.path.join(args.out, "summary.tsv"), "w") as f:
        f.write("\n".join(lines) + "\n")
    cell_lines = ["arm\tjobs\tkind\tdeclared\tran\tpassed\tnote"]
    report = []
    for arm, jobs, kind, declared, note in cells:
        mine = [r for r in rows if (r.get("arm"), r.get("jobs"), r.get("kind")) == (arm, jobs, kind)]
        ran = [r for r in mine if r.get("status") not in ("skipped", "reset-failed")]
        passed = [r for r in mine if r.get("status") == "ok"]
        cell_lines.append("\t".join([arm, jobs, kind, str(declared), str(len(ran)), str(len(passed)), note]))
        report.append("%s jobs=%s %s: %d of %d passed (%d ran)%s"
                      % (arm, jobs, kind, len(passed), declared, len(ran), (" - " + note) if note else ""))
    with open(os.path.join(args.out, "cells.tsv"), "w") as f:
        f.write("\n".join(cell_lines) + "\n")
    print("\n".join(lines))
    print()
    print("\n".join(report))
    failed = [r for r in rows if r.get("status") not in ("ok",)]
    for r in failed:
        print("not counted: %s %s %s" % (r.get("id"), r.get("status"), (r.get("note") or "")[:300]))


def main(argv):
    ap = argparse.ArgumentParser(usage=__doc__)
    sub = ap.add_subparsers(dest="cmd")
    p = sub.add_parser("libs"); p.add_argument("lakefile"); p.set_defaults(fn=cmd_libs)
    p = sub.add_parser("declared"); p.add_argument("root"); p.add_argument("lib"); p.add_argument("out")
    p.set_defaults(fn=cmd_declared)
    p = sub.add_parser("lakejobs"); p.add_argument("log"); p.set_defaults(fn=cmd_lakejobs)
    p = sub.add_parser("html-count"); p.add_argument("dir"); p.add_argument("depth", type=int)
    p.set_defaults(fn=cmd_html_count)
    p = sub.add_parser("round")
    for name in ("--logs", "--rows", "--id", "--arm", "--jobs", "--kind", "--parts", "--declared",
                 "--declared-glob"):
        p.add_argument(name, required=True)
    p.set_defaults(fn=cmd_round)
    p = sub.add_parser("skip")
    for name in ("--rows", "--id", "--arm", "--jobs", "--kind", "--reason"):
        p.add_argument(name, required=True)
    p.add_argument("--status", default="skipped")
    p.set_defaults(fn=cmd_skip)
    p = sub.add_parser("summarize")
    for name in ("--rows", "--cells", "--out"):
        p.add_argument(name, required=True)
    p.set_defaults(fn=cmd_summarize)
    args = ap.parse_args(argv)
    if not getattr(args, "fn", None):
        ap.print_usage()
        return 2
    args.fn(args)
    return 0
