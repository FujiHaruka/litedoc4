An own .olean reader in the newest Lean: reading Mathlib v4.31.0 in Lean v4.34.1, and a hybrid environment for printing
==================================================================================================================
Date: 2026-10-04. Context: docs/multiversion/plan.md D10 (an own .olean reader in one Lean), U8 ("Answered": every
name-keyed lookup asked of an environment holding the newest Mathlib answers about the newest declaration) and U9
(how fast is the reader, does printing fit the build budget). A prototype, not product code: it lives in a scratch
Lake project and nothing in src/ was changed.

QUESTIONS
---------
(a) Can an own .olean reader running in Lean v4.34.1 read Mathlib v4.31.0 (all its packages and Lean core v4.31.0),
    correctly, and how fast? Correct = byte-identical to v4.31.0's own serialization of the drift log's seeded 5,000
    declaration types (benchmarks/results/mathlib-printer-drift-2026-10-04.txt, its script 1, old side).
(b) Can the decoded v4.31.0 data be assembled into an Environment of v4.34.1, so that name-keyed lookups answer about
    v4.31.0, and printed with the newest Mathlib's printer (delaborators, unexpanders, notation) while constant
    lookups resolve against the old constants? Step 1: assembly and lookups. Step 2: the 5,000 prints, compared with
    v4.31.0's own print exactly as the drift log compares them (97.56% identical there).

HEADLINE
--------
(a) Oracle: identical 5000 of 5000 (measured). Not found 0, different 0.
    Reading the whole closure (10,583 modules, 6,998,484,208 bytes in 3 files per module, 767,828 constants, every
    Name / Level / Expr decoded and checked) takes 48.3 s wall median (0.80 min) with proofs decoded, 24.6 s
    (0.41 min) with theorem proofs skipped (measured, 5 and 3 runs). Peak RSS 206 MB / 104 MB: one module is held at a
    time. Runs made after reading ~20 GB of unrelated files to evict the closure take the same time (48.7 s median,
    3 runs) - see CONDITIONS for what that does and does not show.
    -> Reading is ~0.4-0.8 min of the ~10 min per version that 11 versions in 2 h allow. It is not the bottleneck;
       printing is (~6.7 min per version, extrapolated; TIMING). No fallback to C is needed for reading at this
       speed; the place C would go is csrc/, which the tree already builds, and it is not built here.
(b) Assembly works. In the hybrid (newest import, old constants replaced in place, old data-extension entries, newest
    code), 4930 of 5000 print the same text as v4.31.0 printed: 98.60% [98.24%, 98.89%] against the drift log's
    97.56% (measured, same 5,000, same comparison, the drift log's agg.py run verbatim).
      - the explicit-@ class (F4, 28 of 111 in the drift log) is 0;
      - the 11 "failed to pretty print" are 0, and so are C (2) and E (2);
      - what is left is notation the newest Mathlib prints differently for the same term: set-builder via the
        setOf -> Set.ofPred rename 45 (unchanged), the new ↧ notation 16 (unchanged), 2 `Finset.HasAntidiagonal.`
        qualifications, 7 other (4 manifold notations, 1 binder notation, 1 match not reconstructed, 1 other).
    The 16 name-keyed lookups (type, kind, universe params, structure fields flattened, declaration ranges,
    isInstance, isClass, isStructure, reducibility, projection info, coercion info, protected, stored equations
    `f.eq_N`, `f.eq_def`, module) on all 5,000 sampled declarations:
      - in the old environment assembled alone in v4.34.1: 80,000 of 80,000 answers equal v4.31.0's own (measured);
      - in the hybrid: 14 lookups equal on all 5,000; `module` differs on 136 (the hybrid answers the newest module)
        and the stored equations on 6 (a `f.eq_1` the newest Mathlib stored and v4.31.0 did not is visible).
    -> The design this points to is the hybrid, not ~30 lookups re-implemented over decoded data: the running Lean's
       own lookup code answered every lookup correctly once the data was the old data. Two rules make it work, and
       both were found by failing first (WHAT FAILED): newest code needs the newest data about the newest code's own
       vocabulary, and anything asked about "does this name exist / where does it live" must be answered from the
       decoded old data, not the hybrid environment.

CONDITIONS
----------
- Hardware: Apple M1 (machdep.cpu.brand_string), hw.memsize 17179869184 (16 GiB), macOS 26.6.2. One heavy process at a
  time throughout.
- Old side: Lean 4.31.0 (68218e876d2a38b1985b8590fff244a83c321783), Mathlib v4.31.0
  (fabf563a7c95a166b8d7b6efca11c8b4dc9d911f), workspace <old-workspace> (the measurement target, read-only), all its
  packages (aesop, batteries, Cli, importGraph, LeanSearchClient, loogle, mathlib, plausible, proofwidgets, Qq) and
  Lean core from <toolchain v4.31.0>/lib/lean. Every .olean header read says "4.31.0" and that githash.
- New side: Lean 4.34.1 (5045d0056413), Mathlib v4.34.1 (d13f23b723b8a846827a245b89c10fc7d3f11612), workspace
  <new-workspace> (Mathlib oleans from the cache). The prototype is a compiled executable (lean_exe, -O3,
  supportInterpreter) built by Lean v4.34.1 in <scratch>; it imports only `Lean`. For (b) it runs under
  `lake env` of <new-workspace> so the newest Mathlib is on the search path.
- Which files: all three parts of every module (.olean, .olean.server, .olean.private; 6 Mathlib modules and the
  non-`module` packages have a single .olean, read alone). Reading .olean only does not answer (b): declaration
  ranges have no entries in .olean (layout log), the private-level constants the sampled types reference (the
  `_proof_N` auxiliaries) exist only in .olean.private, and v4.31.0's importer takes a module's constants from the
  private part - whose pointers reach into the other two parts, so it cannot be read without them. The reader
  decodes the private part's ModuleData and resolves each pointer by the base address in each part's header.
- The reader is single-threaded: one module after another on one core (user ~36 s of the 48 s wall).
- The reader reads files with IO.FS.readBinFile (one module's three parts into memory, then dropped) and walks the
  bytes in Lean; it does not mmap.
- Warm / cold: `purge` is refused without root on this machine ("Operation not permitted"). Eviction was attempted by
  reading ~20 GB of unrelated files (the newest workspace's packages, another workspace, four other toolchains' lib
  directories; script evict.sh below) before each "after eviction" run. Those runs take the same time as the
  back-to-back runs (48.7 vs 48.3 s median). In every run, back-to-back or not, wall exceeds user+sys by ~8 s, and
  the reader's own "file reads" phase takes 8.2-9.3 s for 7.0 GB in every run. So by this repository's criterion
  (warm if wall ~= user+sys) none of the runs is warm, and the eviction did not produce a measurably different state.
  Whether a true cold cache (after reboot) is slower is NOT measured; the reading phase is at most ~9 s of the 48 s
  in the runs measured here.
- Run counts: (a) timing 1 priming run + 5 back-to-back runs, 3 runs each after an eviction, all with proofs decoded;
  1 run after eviction + 3 back-to-back runs with proofs skipped. Oracle and lookups are deterministic answers: one
  run each, after a 20-record (or 20-module / 300-module) sample run.
- Sampling: every program ran on a sample first (20 oracle records; 20, then 1,500 modules for the reader; 300
  modules for the old-environment assembly; 20 records for the hybrid) before the full run, as CLAUDE.md requires.

THE ORACLE (a)
--------------
The drift log's script 1 (Drift.lean), unchanged, old side, regenerated in <old-workspace>:
  lake env lean --run Drift.lean old old.jsonl 20261004 5000
  -> N = 311,415 (the drift log's N), sampled 5,000, seed 20261004; 92.03 s wall, 15.46 user, 11.48 sys, peak RSS
     3,832,266,752 B; import 58.1 s, enumerate 14.8 s, ppExpr total 5.7 s. Its first 20 records equal the 20-record
     sample run's (timing field aside).
The reader, in v4.34.1, reads the whole closure, takes the decoded `ConstantInfo` of each of the 5,000 names (first
module in import order that lists it, as the importer does), serializes its type with the same serializer (copied
verbatim from Drift.lean) and compares the compressed JSON string with the record's `type`:
  oracle: identical 5000 of 5000; not found 0; different 0                                   (measured)
Beyond the 5,000, every object the reader decodes is checked against what v4.31.0 stored beside it:
  Name hashes recomputed by v4.34.1 and compared with the stored hash        11,436,168 of 11,436,168 equal
  Level data words recomputed and compared                                       280,258 of    280,258 equal
  Expr data words (hash, loose bvar range, depth, flags) recomputed and compared
                                                                             131,149,368 of 131,149,368 equal
  (counts are per module - a Name shared by two modules is decoded and checked in each; any mismatch is a hard
  error naming the address, and the run completed.) Every constructor object's tag, object-field count and byte
  size is checked against the layout the reader expects; every name in `constNames` equals the name of the
  `ConstantInfo` beside it (767,828 of 767,828).
Reducibility meaning table (layout log, v4.32.2 -> v4.33.0): v4.31.0 writes 0 reducible, 1 semireducible,
2 irreducible, 3 "unfolded at .instances or above"; the reader maps 3 to v4.34.1's `instanceReducible` (4). Values
read as 3: 9,105 in core modules of the closure, 21,332 in the rest. The layout log counts 9,726 [implicit_reducible]
entries over v4.31.0's whole `import Lean` environment (8,163 + 1,524 + 39); the closure here holds core modules
reached from Mathlib, a subset, so 9,105 <= 9,726 is consistent but is not an equality check. The lookup comparison
below is the check: 258 of the 5,000 are [implicit_reducible] in v4.31.0 and all 258 come out instanceReducible.

ASSEMBLY AND LOOKUPS (b, step 1)
--------------------------------
How: `ImportState`, its `ImportedModule`s and `CompactedRegion` have private fields; the prototype mirrors their
layouts field for field and casts (unsafeCast). Each decoded module becomes an `ImportedModule` with one part
(`isModule := false`, so the importer takes part 0), a region that nothing points into, no IR parts; then
`finalizeImport ... (loadExts := true)` of v4.34.1 builds the environment. Checked: moduleNameMap.size ==
moduleNames.size. The decoded extensions (11, listed below with entry counts) get their old entries; every other
extension gets none. Theorem proofs are replaced by a constant no environment defines, so a use fails by name.
  old environment alone: decode 67.2 s (proofs skipped, everything kept), finalizeImport 2.1 s, 766,828 constants
  (767,828 listed; 1,000 duplicates across modules merged by the importer's rule), 70.52 s wall, peak RSS
  2,844,000,256 B (measured, 1 run).

- `module` in the hybrid: the importer gives a name the module index of the first newest module listing it, so the
  newest module is answered (e.g. ENNReal.iInter_Ioi_coe_nat: v4.31.0 Mathlib.Data.ENNReal.Basic, hybrid

  the hybrid keeps newest-only constants (the newest code needs them), so probing a name the old version lacks finds
  the newest one. Any "does this name exist" question must be asked of the decoded old name set.
- "constants only" is the hybrid with every extension state the newest one: declaration ranges are the newest
  (3,102 differ), and so are structure, instance, projection, reducibility and protected answers for the declarations
  that changed. It is shown to measure what the old data extensions buy.

PRINTING (b, step 2)
--------------------
Construction ("hybrid"): run v4.34.1's own `importModulesCore` for Mathlib in <new-workspace>; before
`finalizeImport`, rewrite each newest module's private-level ModuleData:
  - every constant the old version also has is replaced in place by the decoded old ConstantInfo (same module
    index, so the newest IR, parser descriptions and delaborator code stay addressable through const2ModIdx):
    739,744 replaced; 993 later duplicates of a replaced name dropped (the importer would reject a definition listed
    twice with different bodies); 27,084 old-only constants go into one extra module appended at the end;
  - for the 11 decoded extensions, an entry of the newest Mathlib is dropped when its key (the declaration name it is
    about) is a name the old version has or has an entry for (641,685 dropped), and kept otherwise (36,101 kept);
    the old entries are added, regrouped by the module index their key gets, and sorted by Name.quickLt (the
    per-module binary searches of MapDeclarationExtension, TagDeclarationExtension, structureExt and reducibility
    need it);
  - every other extension (delaborators, unexpanders, parser tables, formatters, IR, initializers, Mathlib's own
    extensions) keeps the newest entries. finalizeImport then runs the newest initializers and attribute handlers as
    a normal import does.
Printing: the drift log's new side (Drift.lean `newSide`, unchanged apart from taking the environment as an argument):
the old Expr rebuilt from the oracle record, `Meta.ppExpr`, width 1,000,000, maxHeartbeats 5,000,000, then the drift
log's agg.py verbatim.

WHAT FAILED, AND WHY
--------------------
1. First hybrid attempt, old entries only for the decoded extensions (newest entries of those 11 extensions removed
   wholesale): 7 of the first 20 records printed "failed to pretty print". The diagnosis (delab, then ppTerm, errors
   caught separately) was the same for all 7: "type class instance expected  UsesSetNotationForOrder X". That class
   exists only in v4.34.1 Mathlib; its delaborator for ≤ / ⊆ synthesizes it; removing the newest class entries made it
   not a class. Fix: keep newest entries whose key the old version does not have (rule 1 in the headline). After it,
   20 of 20 identical.
2. `withImporting` resets the initializer-execution flag in its `finally`; calling `importModulesCore` inside one
   `withImporting` and `finalizeImport` inside another failed with "`enableInitializersExecution` must be run before
   calling `importModules (loadExts := true)`". Fix: enable again before the second.
3. Constants-only hybrid: 8 print failures, all "`AddMonoidAlgebra` is not an inductive type" (also MonoidAlgebra,
   PolynomialModule): in v4.34.1 those are structures, in v4.31.0 definitions; the newest structure info about a name
   whose old constant is a definition. This is the U8 failure inside the printer, and the reason the data
   extensions have to be old.
4. The reader itself: no layout check fired on the closure. Single-field structures (KVMap, String.Pos.Raw, FVarId)
   are represented as their field, as the compiler's trivial-structure rule says, and are decoded that way; a wrong
   guess there would have stopped the run at the first such object with the type's name.
5. The checks were made to fail once (measured): three copies of Init.Prelude's three parts in <scratch>, each with
   one change in .olean.private, put first on the reader's search path (never given to Lean's importer; the v4.31.0
   files were not touched). Each run stopped with exit 1 at the changed object, naming it:
     one bit of a stored Name hash   -> "olean reader: Name at 0x31fc9d8a0060: stored hash differs from the
                                         recomputed one for _private.Init.Prelude.0.Lean.extractMainModule._sunfold"
     one bit of an Expr data word    -> "olean reader: Expr at 0x31fc9d8d0ee0: stored data differs from the
                                         recomputed one (tag 5)"
     a Name object's tag set to 7    -> "olean reader: Name at 0x31fc9d8a0060: tag 7 objs 2 size 32"
Nothing was skipped silently: an extension outside the decoded set is not read, and is listed with its entry count.

WHAT IS NOT MEASURED
--------------------
- One old version (v4.31.0) against one new (v4.34.1). The reader knows exactly v4.31.0's header (version string and
  githash) and refuses every other by name; v4.29 / v4.30 / v4.32 / v4.33 layouts are not implemented here.
- True cold cache (after reboot): purge needs root; see CONDITIONS.
- The extractor's own signature printer, docstrings, Verso, equations generation, instances lists, structure-field
  printing, and the per-page work in the hybrid: only `ppExpr` of the type and 16 lookups were asked. Printing all
  311,415 declarations was not run; the per-version total above is theoretical.
- 212 extensions are not decoded (list below), among them the matcher extension (one print differs because of it),
  docstrings, simp, the parser extension and IR. A product reader needs a decoder for each one the extractor reads.
- D10 mechanism 3 (.ilean agreement, "every constant a type mentions exists") was not implemented; mechanism 2 was
  done as the oracle plus the computed-field checks above.
- Memory of the hybrid at the extractor's full workload; the 5.07 GB peak here is newest import + old constants
  without proofs.
- The duplicate rule (later occurrences of a replaced name dropped) and the 27,084 old-only constants in one extra
  module change which module a name reports; correctness of anything module-keyed in the hybrid is not established
  beyond the `module` lookup above (which is wrong in the hybrid by construction).

=== OleanReader.lean (the decoding core)
import Lean
open Lean

/-!
An `.olean` reader that walks the bytes of a module written by Lean v4.31.0 and rebuilds its
`ModuleData` as values of the Lean that runs it. It knows exactly one writer version; anything
else is refused by name. Every object it meets is checked against the layout it expects (tag,
object-field count, byte size) and every computed field it can recompute (Name hash, Level and
Expr data) is compared with the stored one; a mismatch is an error, never a skip.
-/

namespace OleanReader

def knownLeanVersion := "4.31.0"
def knownGithash := "68218e876d2a38b1985b8590fff244a83c321783"
def headerSize : Nat := 88

structure Part where
  path  : System.FilePath
  bytes : ByteArray
  base  : UInt64
  root  : UInt64

instance : Inhabited Part := ⟨⟨"", .empty, 0, 0⟩⟩

@[inline] def u8 (b : ByteArray) (o : Nat) : UInt8 := b.get! o
@[inline] def u16 (b : ByteArray) (o : Nat) : UInt16 :=
  (b.get! o).toUInt16 ||| ((b.get! (o+1)).toUInt16 <<< 8)
@[inline] def u32 (b : ByteArray) (o : Nat) : UInt32 :=
  (b.get! o).toUInt32 ||| ((b.get! (o+1)).toUInt32 <<< 8) |||
  ((b.get! (o+2)).toUInt32 <<< 16) ||| ((b.get! (o+3)).toUInt32 <<< 24)
@[inline] def u64 (b : ByteArray) (o : Nat) : UInt64 :=
  (u32 b o).toUInt64 ||| ((u32 b (o+4)).toUInt64 <<< 32)

def cstr (b : ByteArray) (o n : Nat) : String := Id.run do
  let mut s := ""
  for i in [0:n] do
    let c := b.get! (o+i)
    if c == 0 then break
    s := s.push (Char.ofNat c.toNat)
  return s

def loadPart (path : System.FilePath) : IO Part := do
  let bytes ← IO.FS.readBinFile path
  if bytes.size < headerSize + 8 then throw <| IO.userError s!"{path}: shorter than an .olean header"
  unless cstr bytes 0 5 == "olean" do throw <| IO.userError s!"{path}: no olean marker"
  let version := u8 bytes 5
  let flags := u8 bytes 6
  let lv := cstr bytes 7 33
  let gh := cstr bytes 40 40
  unless version == 2 && flags == 1 do
    throw <| IO.userError s!"{path}: header version {version} flags {flags}, known: 2 / 1"
  unless lv == knownLeanVersion && gh == knownGithash do
    throw <| IO.userError s!"{path}: written by Lean {lv} ({gh}); this reader knows only {knownLeanVersion} ({knownGithash})"
  let base := u64 bytes 80
  let root := u64 bytes headerSize
  return { path, bytes, base, root }

structure DState where
  names   : Std.HashMap UInt64 Name := {}
  levels  : Std.HashMap UInt64 Level := {}
  exprs   : Std.HashMap UInt64 Expr := {}
  objects : Nat := 0

abbrev DM := ReaderT (Array Part) (StateRefT DState IO)

def fail (what : String) (addr : UInt64) (msg : String) : DM α :=
  throw <| IO.userError s!"olean reader: {what} at 0x{String.ofList (Nat.toDigits 16 addr.toNat)}: {msg}"

@[inline] def isScalar (v : UInt64) : Bool := v &&& 1 == 1
@[inline] def unbox (v : UInt64) : Nat := (v >>> 1).toNat

structure Obj where
  b     : ByteArray
  o     : Nat
  tag   : Nat
  other : Nat
  csSz  : Nat

@[inline] def obj (what : String) (addr : UInt64) : DM Obj := do
  if isScalar addr then fail what addr "expected an object, found a scalar"
  let ps ← read
  for p in ps do
    if addr ≥ p.base && addr < p.base + p.bytes.size.toUInt64 then
      let o := (addr - p.base).toNat
      modify fun s => { s with objects := s.objects + 1 }
      return { b := p.bytes, o, tag := (u8 p.bytes (o+7)).toNat, other := (u8 p.bytes (o+6)).toNat,
               csSz := (u16 p.bytes (o+4)).toNat }
  fail what addr "address outside every part of this module"

@[inline] def align8 (n : Nat) : Nat := (n + 7) / 8 * 8

/-- A constructor object with the expected tag, object-field count and scalar size. -/
@[inline] def ctor (what : String) (addr : UInt64) (tag objs ssz : Nat) : DM Obj := do
  let x ← obj what addr
  unless x.tag == tag && x.other == objs && x.csSz == align8 (8 + 8*objs + ssz) do
    fail what addr s!"expected ctor tag {tag} objs {objs} size {align8 (8 + 8*objs + ssz)}, found tag {x.tag} objs {x.other} size {x.csSz}"
  return x

@[inline] def Obj.field (x : Obj) (i : Nat) : UInt64 := u64 x.b (x.o + 8 + 8*i)
@[inline] def Obj.sc8 (x : Obj) (off : Nat) : UInt8 := u8 x.b (x.o + 8 + 8*x.other + off)
@[inline] def Obj.sc32 (x : Obj) (off : Nat) : UInt32 := u32 x.b (x.o + 8 + 8*x.other + off)
@[inline] def Obj.sc64 (x : Obj) (off : Nat) : UInt64 := u64 x.b (x.o + 8 + 8*x.other + off)

def decBool (what : String) (addr : UInt64) (v : UInt8) : DM Bool :=
  match v with
  | 0 => pure false
  | 1 => pure true
  | _ => fail what addr s!"Bool byte {v}"

def decBoxedBool (v : UInt64) : DM Bool := do
  unless isScalar v && unbox v ≤ 1 do fail "Bool" v "expected a boxed Bool"
  return unbox v == 1

/-- `Nat`: a boxed scalar or a GMP bignum (header flag bit 0 = 1 was checked). -/
def decNat (v : UInt64) : DM Nat := do
  if isScalar v then return unbox v
  let x ← obj "Nat" v
  unless x.tag == 250 do fail "Nat" v s!"expected an MPZ object (tag 250), found tag {x.tag}"
  let sz := (u32 x.b (x.o + 12)).toNat
  if sz ≥ 2^31 then fail "Nat" v "negative bignum"
  let limbs := u64 x.b (x.o + 16)
  unless limbs == v + 24 do fail "Nat" v "limb pointer does not follow the object"
  let mut n := 0
  for i in [0:sz] do
    n := n + (u64 x.b (x.o + 24 + 8*i)).toNat * 2^(64*i)
  return n

def decInt (v : UInt64) : DM Int := do
  if isScalar v then
    let w := (v >>> 1).toUInt32
    return if w ≥ 0x80000000 then Int.negSucc (0xFFFFFFFF - w).toNat else Int.ofNat w.toNat
  let x ← obj "Int" v
  unless x.tag == 250 do fail "Int" v s!"expected an MPZ object, found tag {x.tag}"
  let szRaw := u32 x.b (x.o + 12)
  let neg := szRaw ≥ 0x80000000
  let sz := if neg then (0 - szRaw).toNat else szRaw.toNat
  let mut n := 0
  for i in [0:sz] do
    n := n + (u64 x.b (x.o + 24 + 8*i)).toNat * 2^(64*i)
  return if neg then -(n : Int) else n

def decString (v : UInt64) : DM String := do
  let x ← obj "String" v
  unless x.tag == 249 do fail "String" v s!"expected a String object (tag 249), found tag {x.tag}"
  let size := (u64 x.b (x.o + 8)).toNat
  if size == 0 then fail "String" v "size 0 (no terminator)"
  let bs := x.b.extract (x.o + 32) (x.o + 32 + size - 1)
  match String.fromUTF8? bs with
  | some s =>
    unless s.length == (u64 x.b (x.o + 24)).toNat do fail "String" v "stored length differs"
    return s
  | none => fail "String" v "invalid UTF-8"

@[specialize] def decArray (what : String) (v : UInt64) (f : UInt64 → DM α) : DM (Array α) := do
  let x ← obj what v
  unless x.tag == 246 do fail what v s!"expected an Array object (tag 246), found tag {x.tag}"
  let n := (u64 x.b (x.o + 8)).toNat
  let mut out := Array.mkEmpty n
  for i in [0:n] do
    out := out.push (← f (u64 x.b (x.o + 24 + 8*i)))
  return out

def decNatArray (v : UInt64) : DM (Array Nat) := decArray "Array Nat" v decNat

@[specialize] def decList (what : String) (v : UInt64) (f : UInt64 → DM α) : DM (List α) := do
  let mut acc : Array α := #[]
  let mut cur := v
  while true do
    if isScalar cur then
      unless unbox cur == 0 do fail what cur s!"List: scalar {unbox cur}"
      break
    let x ← ctor what cur 1 2 0
    acc := acc.push (← f (x.field 0))
    cur := x.field 1
  return acc.toList

@[specialize] def decOption (what : String) (v : UInt64) (f : UInt64 → DM α) : DM (Option α) := do
  if isScalar v then
    unless unbox v == 0 do fail what v s!"Option: scalar {unbox v}"
    return none
  let x ← ctor what v 1 1 0
  return some (← f (x.field 0))

@[specialize] def decPair (what : String) (v : UInt64) (f : UInt64 → DM α) (g : UInt64 → DM β) : DM (α × β) := do
  let x ← ctor what v 0 2 0
  return (← f (x.field 0), ← g (x.field 1))

partial def decName (v : UInt64) : DM Name := do
  if isScalar v then
    unless unbox v == 0 do fail "Name" v s!"scalar {unbox v}"
    return .anonymous
  if let some n := (← get).names[v]? then return n
  let x ← obj "Name" v
  unless x.other == 2 && x.csSz == 32 && (x.tag == 1 || x.tag == 2) do
    fail "Name" v s!"tag {x.tag} objs {x.other} size {x.csSz}"
  let pre ← decName (x.field 0)
  let n ← if x.tag == 1 then pure (Name.str pre (← decString (x.field 1)))
    else pure (Name.num pre (← decNat (x.field 1)))
  unless n.hash == x.sc64 0 do fail "Name" v s!"stored hash differs from the recomputed one for {n}"
  modify fun s => { s with names := s.names.insert v n }
  return n

partial def decLevel (v : UInt64) : DM Level := do
  if isScalar v then
    unless unbox v == 0 do fail "Level" v s!"scalar {unbox v}"
    return .zero
  if let some l := (← get).levels[v]? then return l
  let x ← obj "Level" v
  let l ← match x.tag, x.other with
    | 1, 1 => pure (Level.succ (← decLevel (x.field 0)))
    | 2, 2 => pure (Level.max (← decLevel (x.field 0)) (← decLevel (x.field 1)))
    | 3, 2 => pure (Level.imax (← decLevel (x.field 0)) (← decLevel (x.field 1)))
    | 4, 1 => pure (Level.param (← decName (x.field 0)))
    | 5, 1 => pure (Level.mvar ⟨← decName (x.field 0)⟩)
    | t, k => fail "Level" v s!"unknown ctor tag {t} objs {k}"
  unless x.csSz == align8 (8 + 8*x.other + 8) do fail "Level" v s!"size {x.csSz}"
  unless (l.data : UInt64) == x.sc64 0 do fail "Level" v "stored data differs from the recomputed one"
  modify fun s => { s with levels := s.levels.insert v l }
  return l

def decBinderInfo (addr : UInt64) (b : UInt8) : DM BinderInfo :=
  match b with
  | 0 => pure .default | 1 => pure .implicit | 2 => pure .strictImplicit | 3 => pure .instImplicit
  | _ => fail "BinderInfo" addr s!"value {b}"

def decLiteral (v : UInt64) : DM Literal := do
  let x ← obj "Literal" v
  match x.tag with
  | 0 => let _ ← ctor "Literal.natVal" v 0 1 0; return .natVal (← decNat (x.field 0))
  | 1 => let _ ← ctor "Literal.strVal" v 1 1 0; return .strVal (← decString (x.field 0))
  | t => fail "Literal" v s!"tag {t}"

/-- `String.Pos.Raw` is a single-field structure and is represented as its `Nat`. -/
def decPos (v : UInt64) : DM String.Pos.Raw := return ⟨← decNat v⟩

def decSubstring (v : UInt64) : DM Substring.Raw := do
  let x ← ctor "Substring.Raw" v 0 3 0
  return ⟨← decString (x.field 0), ← decPos (x.field 1), ← decPos (x.field 2)⟩

def decSourceInfo (v : UInt64) : DM SourceInfo := do
  if isScalar v then
    unless unbox v == 2 do fail "SourceInfo" v s!"scalar {unbox v}"
    return .none
  let x ← obj "SourceInfo" v
  match x.tag with
  | 0 =>
    let x ← ctor "SourceInfo.original" v 0 4 0
    return .original (← decSubstring (x.field 0)) (← decPos (x.field 1)) (← decSubstring (x.field 2)) (← decPos (x.field 3))
  | 1 =>
    let x ← ctor "SourceInfo.synthetic" v 1 2 1
    return .synthetic (← decPos (x.field 0)) (← decPos (x.field 1)) (← decBool "SourceInfo.canonical" v (x.sc8 0))
  | t => fail "SourceInfo" v s!"tag {t}"

def decPreresolved (v : UInt64) : DM Syntax.Preresolved := do
  let x ← obj "Syntax.Preresolved" v
  match x.tag with
  | 0 => let x ← ctor "Preresolved.namespace" v 0 1 0; return .namespace (← decName (x.field 0))
  | 1 =>
    let x ← ctor "Preresolved.decl" v 1 2 0
    return .decl (← decName (x.field 0)) (← decList "List String" (x.field 1) decString)
  | t => fail "Syntax.Preresolved" v s!"tag {t}"

partial def decSyntax (v : UInt64) : DM Syntax := do
  if isScalar v then
    unless unbox v == 0 do fail "Syntax" v s!"scalar {unbox v}"
    return .missing
  let x ← obj "Syntax" v
  match x.tag with
  | 1 =>
    let x ← ctor "Syntax.node" v 1 3 0
    return .node (← decSourceInfo (x.field 0)) (← decName (x.field 1)) (← decArray "Array Syntax" (x.field 2) decSyntax)
  | 2 =>
    let x ← ctor "Syntax.atom" v 2 2 0
    return .atom (← decSourceInfo (x.field 0)) (← decString (x.field 1))
  | 3 =>
    let x ← ctor "Syntax.ident" v 3 4 0
    return .ident (← decSourceInfo (x.field 0)) (← decSubstring (x.field 1)) (← decName (x.field 2))
      (← decList "List Preresolved" (x.field 3) decPreresolved)
  | t => fail "Syntax" v s!"tag {t}"

def decDataValue (v : UInt64) : DM DataValue := do
  let x ← obj "DataValue" v
  match x.tag with
  | 0 => let x ← ctor "DataValue.ofString" v 0 1 0; return .ofString (← decString (x.field 0))
  | 1 => let x ← ctor "DataValue.ofBool" v 1 0 1; return .ofBool (← decBool "DataValue.ofBool" v (x.sc8 0))
  | 2 => let x ← ctor "DataValue.ofName" v 2 1 0; return .ofName (← decName (x.field 0))
  | 3 => let x ← ctor "DataValue.ofNat" v 3 1 0; return .ofNat (← decNat (x.field 0))
  | 4 => let x ← ctor "DataValue.ofInt" v 4 1 0; return .ofInt (← decInt (x.field 0))
  | 5 => let x ← ctor "DataValue.ofSyntax" v 5 1 0; return .ofSyntax (← decSyntax (x.field 0))
  | t => fail "DataValue" v s!"tag {t}"

/-- `KVMap` is a single-field structure and is represented as its `List`. -/
def decMData (v : UInt64) : DM MData := do
  return ⟨← decList "KVMap" v (decPair "Name × DataValue" · decName decDataValue)⟩

partial def decExpr (v : UInt64) : DM Expr := do
  if let some e := (← get).exprs[v]? then return e
  let x ← obj "Expr" v
  let e ← match x.tag, x.other with
    | 0, 1 => pure (Expr.bvar (← decNat (x.field 0)))
    | 1, 1 => pure (Expr.fvar ⟨← decName (x.field 0)⟩)
    | 2, 1 => pure (Expr.mvar ⟨← decName (x.field 0)⟩)
    | 3, 1 => pure (Expr.sort (← decLevel (x.field 0)))
    | 4, 2 => pure (Expr.const (← decName (x.field 0)) (← decList "List Level" (x.field 1) decLevel))
    | 5, 2 => pure (Expr.app (← decExpr (x.field 0)) (← decExpr (x.field 1)))
    | 6, 3 => pure (Expr.lam (← decName (x.field 0)) (← decExpr (x.field 1)) (← decExpr (x.field 2)) (← decBinderInfo v (x.sc8 8)))
    | 7, 3 => pure (Expr.forallE (← decName (x.field 0)) (← decExpr (x.field 1)) (← decExpr (x.field 2)) (← decBinderInfo v (x.sc8 8)))
    | 8, 4 => pure (Expr.letE (← decName (x.field 0)) (← decExpr (x.field 1)) (← decExpr (x.field 2)) (← decExpr (x.field 3)) (← decBool "Expr.letE.nondep" v (x.sc8 8)))
    | 9, 1 => pure (Expr.lit (← decLiteral (x.field 0)))
    | 10, 2 => pure (Expr.mdata (← decMData (x.field 0)) (← decExpr (x.field 1)))
    | 11, 3 => pure (Expr.proj (← decName (x.field 0)) (← decNat (x.field 1)) (← decExpr (x.field 2)))
    | t, k => fail "Expr" v s!"unknown ctor tag {t} objs {k}"
  let ssz := if x.tag == 6 || x.tag == 7 || x.tag == 8 then 9 else 8
  unless x.csSz == align8 (8 + 8*x.other + ssz) do fail "Expr" v s!"size {x.csSz} for tag {x.tag}"
  unless (e.data : UInt64) == x.sc64 0 do fail "Expr" v s!"stored data differs from the recomputed one (tag {x.tag})"
  modify fun s => { s with exprs := s.exprs.insert v e }
  return e

def decNameList (v : UInt64) : DM (List Name) := decList "List Name" v decName

def decConstantVal (v : UInt64) : DM ConstantVal := do
  let x ← ctor "ConstantVal" v 0 3 0
  return { name := ← decName (x.field 0), levelParams := ← decNameList (x.field 1), type := ← decExpr (x.field 2) }

def decHints (v : UInt64) : DM ReducibilityHints := do
  if isScalar v then
    match unbox v with
    | 0 => return .opaque
    | 1 => return .abbrev
    | k => fail "ReducibilityHints" v s!"scalar {k}"
  let x ← ctor "ReducibilityHints.regular" v 2 0 4
  return .regular (x.sc32 0)

def decSafety (addr : UInt64) (b : UInt8) : DM DefinitionSafety :=
  match b with
  | 0 => pure .unsafe | 1 => pure .safe | 2 => pure .partial
  | _ => fail "DefinitionSafety" addr s!"value {b}"

def decQuotKind (addr : UInt64) (b : UInt8) : DM QuotKind :=
  match b with
  | 0 => pure .type | 1 => pure .ctor | 2 => pure .lift | 3 => pure .ind
  | _ => fail "QuotKind" addr s!"value {b}"

/-- What the reader keeps of a theorem's proof. `omitProofs` replaces it by a constant that no
environment defines, so a use of it fails by name instead of answering. -/
def omittedProof : Expr := .const `_olean_reader.proofOmitted []

def decRule (v : UInt64) : DM RecursorRule := do
  let x ← ctor "RecursorRule" v 0 3 0
  return { ctor := ← decName (x.field 0), nfields := ← decNat (x.field 1), rhs := ← decExpr (x.field 2) }

def decConstantInfo (omitProofs : Bool) (v : UInt64) : DM ConstantInfo := do
  let x ← obj "ConstantInfo" v
  unless x.other == 1 && x.csSz == 16 do fail "ConstantInfo" v s!"tag {x.tag} objs {x.other} size {x.csSz}"
  let w := x.field 0
  match x.tag with
  | 0 =>
    let y ← ctor "AxiomVal" w 0 1 1
    return .axiomInfo { toConstantVal := ← decConstantVal (y.field 0), isUnsafe := ← decBool "AxiomVal.isUnsafe" w (y.sc8 0) }
  | 1 =>
    let y ← ctor "DefinitionVal" w 0 4 1
    return .defnInfo {
      toConstantVal := ← decConstantVal (y.field 0), value := ← decExpr (y.field 1),
      hints := ← decHints (y.field 2), safety := ← decSafety w (y.sc8 0), all := ← decNameList (y.field 3) }
  | 2 =>
    let y ← ctor "TheoremVal" w 0 3 0
    let cv ← decConstantVal (y.field 0)
    let value ← if omitProofs then pure omittedProof else decExpr (y.field 1)
    return .thmInfo { toConstantVal := cv, value, all := ← decNameList (y.field 2) }
  | 3 =>
    let y ← ctor "OpaqueVal" w 0 3 1
    return .opaqueInfo {
      toConstantVal := ← decConstantVal (y.field 0), value := ← decExpr (y.field 1),
      isUnsafe := ← decBool "OpaqueVal.isUnsafe" w (y.sc8 0), all := ← decNameList (y.field 2) }
  | 4 =>
    let y ← ctor "QuotVal" w 0 1 1
    return .quotInfo { toConstantVal := ← decConstantVal (y.field 0), kind := ← decQuotKind w (y.sc8 0) }
  | 5 =>
    let y ← ctor "InductiveVal" w 0 6 3
    return .inductInfo {
      toConstantVal := ← decConstantVal (y.field 0), numParams := ← decNat (y.field 1),
      numIndices := ← decNat (y.field 2), all := ← decNameList (y.field 3), ctors := ← decNameList (y.field 4),
      numNested := ← decNat (y.field 5), isRec := ← decBool "InductiveVal.isRec" w (y.sc8 0),
      isUnsafe := ← decBool "InductiveVal.isUnsafe" w (y.sc8 1), isReflexive := ← decBool "InductiveVal.isReflexive" w (y.sc8 2) }
  | 6 =>
    let y ← ctor "ConstructorVal" w 0 5 1
    return .ctorInfo {
      toConstantVal := ← decConstantVal (y.field 0), induct := ← decName (y.field 1),
      cidx := ← decNat (y.field 2), numParams := ← decNat (y.field 3), numFields := ← decNat (y.field 4),
      isUnsafe := ← decBool "ConstructorVal.isUnsafe" w (y.sc8 0) }
  | 7 =>
    let y ← ctor "RecursorVal" w 0 7 2
    return .recInfo {
      toConstantVal := ← decConstantVal (y.field 0), all := ← decNameList (y.field 1),
      numParams := ← decNat (y.field 2), numIndices := ← decNat (y.field 3), numMotives := ← decNat (y.field 4),
      numMinors := ← decNat (y.field 5), rules := ← decList "List RecursorRule" (y.field 6) decRule,
      k := ← decBool "RecursorVal.k" w (y.sc8 0), isUnsafe := ← decBool "RecursorVal.isUnsafe" w (y.sc8 1) }
  | t => fail "ConstantInfo" v s!"unknown tag {t}"

def decImport (v : UInt64) : DM Import := do
  let x ← ctor "Import" v 0 1 3
  return { module := ← decName (x.field 0), importAll := ← decBool "Import.importAll" v (x.sc8 0),
           isExported := ← decBool "Import.isExported" v (x.sc8 1), isMeta := ← decBool "Import.isMeta" v (x.sc8 2) }

/-! Extension entries. Each decoder rebuilds the entry as the running Lean's value of the same
type; `unsafeCast` to `EnvExtensionEntry` is how Lean itself stores them. -/

def decEntry {α} (x : α) : EnvExtensionEntry := unsafe unsafeCast x

def decScopedEntry (what : String) (v : UInt64) (f : UInt64 → DM α) : DM (ScopedEnvExtension.Entry α) := do
  let x ← obj what v
  match x.tag with
  | 0 => let x ← ctor what v 0 1 0; return .global (← f (x.field 0))
  | 1 => let x ← ctor what v 1 2 0; return .scoped (← decName (x.field 0)) (← f (x.field 1))
  | t => fail what v s!"ScopedEnvExtension.Entry tag {t}"

def decStructureFieldInfo (v : UInt64) : DM StructureFieldInfo := do
  let x ← ctor "StructureFieldInfo" v 0 4 1
  return { fieldName := ← decName (x.field 0), projFn := ← decName (x.field 1),
           subobject? := ← decOption "Option Name" (x.field 2) decName,
           binderInfo := ← decBinderInfo v (x.sc8 0), autoParam? := ← decOption "Option Expr" (x.field 3) decExpr }

def decStructureParentInfo (v : UInt64) : DM StructureParentInfo := do
  let x ← ctor "StructureParentInfo" v 0 2 1
  return { structName := ← decName (x.field 0), subobject := ← decBool "StructureParentInfo.subobject" v (x.sc8 0),
           projFn := ← decName (x.field 1) }

def decStructureInfo (v : UInt64) : DM StructureInfo := do
  let x ← ctor "StructureInfo" v 0 4 0
  return { structName := ← decName (x.field 0), fieldNames := ← decArray "Array Name" (x.field 1) decName,
           fieldInfo := ← decArray "Array StructureFieldInfo" (x.field 2) decStructureFieldInfo,
           parentInfo := ← decArray "Array StructureParentInfo" (x.field 3) decStructureParentInfo }

def decPosition (v : UInt64) : DM Position := do
  let x ← ctor "Position" v 0 2 0
  return ⟨← decNat (x.field 0), ← decNat (x.field 1)⟩

def decDeclRange (v : UInt64) : DM DeclarationRange := do
  let x ← ctor "DeclarationRange" v 0 4 0
  return { pos := ← decPosition (x.field 0), charUtf16 := ← decNat (x.field 1),
           endPos := ← decPosition (x.field 2), endCharUtf16 := ← decNat (x.field 3) }

def decDeclRanges (v : UInt64) : DM DeclarationRanges := do
  let x ← ctor "DeclarationRanges" v 0 2 0
  return ⟨← decDeclRange (x.field 0), ← decDeclRange (x.field 1)⟩

def decProjInfo (v : UInt64) : DM ProjectionFunctionInfo := do
  let x ← ctor "ProjectionFunctionInfo" v 0 3 1
  return { ctorName := ← decName (x.field 0), numParams := ← decNat (x.field 1), i := ← decNat (x.field 2),
           fromClass := ← decBool "ProjectionFunctionInfo.fromClass" v (x.sc8 0) }

def decKey (v : UInt64) : DM Meta.DiscrTree.Key := do
  if isScalar v then
    match unbox v with
    | 0 => return .star | 1 => return .other | 5 => return .arrow
    | k => fail "DiscrTree.Key" v s!"scalar {k}"
  let x ← obj "DiscrTree.Key" v
  match x.tag with
  | 2 => let x ← ctor "Key.lit" v 2 1 0; return .lit (← decLiteral (x.field 0))
  | 3 => let x ← ctor "Key.fvar" v 3 2 0; return .fvar ⟨← decName (x.field 0)⟩ (← decNat (x.field 1))
  | 4 => let x ← ctor "Key.const" v 4 2 0; return .const (← decName (x.field 0)) (← decNat (x.field 1))
  | 6 => let x ← ctor "Key.proj" v 6 3 0; return .proj (← decName (x.field 0)) (← decNat (x.field 1)) (← decNat (x.field 2))
  | t => fail "DiscrTree.Key" v s!"tag {t}"

def decAttrKind (addr : UInt64) (b : UInt8) : DM AttributeKind :=
  match b with
  | 0 => pure .global | 1 => pure .local | 2 => pure .scoped
  | _ => fail "AttributeKind" addr s!"value {b}"

def decInstanceEntry (v : UInt64) : DM Meta.InstanceEntry := do
  let x ← ctor "InstanceEntry" v 0 5 1
  return { keys := ← decArray "Array Key" (x.field 0) decKey, val := ← decExpr (x.field 1),
           priority := ← decNat (x.field 2), globalName? := ← decOption "Option Name" (x.field 3) decName,
           synthOrder := ← decNatArray (x.field 4), attrKind := ← decAttrKind v (x.sc8 0) }

def decClassEntry (v : UInt64) : DM ClassEntry := do
  let x ← ctor "ClassEntry" v 0 3 0
  return { name := ← decName (x.field 0), outParams := ← decNatArray (x.field 1),
           outLevelParams := ← decNatArray (x.field 2) }

def decCoeFnInfo (v : UInt64) : DM Meta.CoeFnInfo := do
  let x ← ctor "CoeFnInfo" v 0 2 1
  let type ← match x.sc8 0 with
    | 0 => pure .coe | 1 => pure .coeFun | 2 => pure .coeSort
    | b => fail "CoeFnType" v s!"value {b}"
  return { numArgs := ← decNat (x.field 0), coercee := ← decNat (x.field 1), type }

/-- v4.31.0 writes 0 reducible, 1 semireducible, 2 irreducible, 3 "unfolded at .instances or
above" (what the `instance` command wrote). From v4.33.0 that meaning is constructor 4,
`instanceReducible`, and 3 means something else (layout log, v4.32.2 -> v4.33.0). -/
def decReducibility (v : UInt64) : DM ReducibilityStatus := do
  unless isScalar v do fail "ReducibilityStatus" v "expected a boxed enum"
  match unbox v with
  | 0 => return .reducible | 1 => return .semireducible | 2 => return .irreducible
  | 3 => return .instanceReducible
  | k => fail "ReducibilityStatus" v s!"value {k} unknown to v4.31.0"

/-- An extension entry with the declaration name it is about (used to regroup entries by module). -/
abbrev Keyed := Name × EnvExtensionEntry

def keyed {α} (k : α → Name) (x : α) : Keyed := (k x, decEntry x)

def scopedKey {α} (k : α → Name) : ScopedEnvExtension.Entry α → Name
  | .global a => k a
  | .scoped _ a => k a

/-- The extensions whose entries the reader decodes, by registered name, with the entry decoder.
Every other extension's entries are counted and not decoded. -/
def entryDecoders : List (Name × (UInt64 → DM Keyed)) := [
  (Name.mkNum `_private.Lean.Structure 0 ++ `Lean.structureExt,
    fun v => keyed (·.structName) <$> decStructureInfo v),
  (`Lean.declRangeExt, fun v => keyed (·.1) <$> decPair "Name × DeclarationRanges" v decName decDeclRanges),
  (`Lean.projectionFnInfoExt, fun v => keyed (·.1) <$> decPair "Name × ProjectionFunctionInfo" v decName decProjInfo),
  (`Lean.Meta.instanceExtension,
    fun v => keyed (scopedKey (·.globalName?.getD .anonymous)) <$> decScopedEntry "instance entry" v decInstanceEntry),
  (`Lean.classExtension, fun v => keyed (·.name) <$> decClassEntry v),
  (`Lean.Meta.coeExt,
    fun v => keyed (scopedKey (·.1)) <$> decScopedEntry "coe entry" v (decPair "Name × CoeFnInfo" · decName decCoeFnInfo)),
  (`Lean.protectedExt, fun v => keyed id <$> decName v),
  (`Lean.aliasExtension, fun v => keyed (·.1) <$> decPair "AliasEntry" v decName decName),
  (`reducibilityCore, fun v => keyed (·.1) <$> decPair "Name × ReducibilityStatus" v decName decReducibility),
  (`reducibilityExtra,
    fun v => keyed (scopedKey (·.1)) <$> decScopedEntry "reducibilityExtra entry" v (decPair "Name × ReducibilityStatus" · decName decReducibility)),
  (Name.mkNum `_private.Lean.Namespace 0 ++ `Lean.namespacesExt, fun v => keyed id <$> decName v)
]

def decoderFor (extName : Name) : Option (UInt64 → DM Keyed) :=
  (entryDecoders.find? (·.1 == extName)).map (·.2)

structure ReadStats where
  constants : Nat := 0
  entriesDecoded : Nat := 0
  entriesSkipped : Nat := 0
  skippedExts : Std.HashMap Name Nat := {}
  decodedExts : Std.HashMap Name Nat := {}
  names : Nat := 0
  levels : Nat := 0
  exprs : Nat := 0

/-- Decodes a module's `ModuleData` from the root of its last part, and the decoded entries
with their keys. -/
def decModuleData (omitProofs decodeEntries : Bool) (v : UInt64) (stats : IO.Ref ReadStats) :
    DM (ModuleData × Array (Name × Array Keyed)) := do
  let x ← ctor "ModuleData" v 0 5 1
  let isModule ← decBool "ModuleData.isModule" v (x.sc8 0)
  let imports ← decArray "Array Import" (x.field 0) decImport
  let constNames ← decArray "Array Name" (x.field 1) decName
  let constants ← decArray "Array ConstantInfo" (x.field 2) (decConstantInfo omitProofs)
  let extraConstNames ← decArray "Array Name" (x.field 3) decName
  let entriesObj ← obj "Array (Name × Array EnvExtensionEntry)" (x.field 4)
  unless entriesObj.tag == 246 do fail "ModuleData.entries" (x.field 4) "expected an Array"
  let n := (u64 entriesObj.b (entriesObj.o + 8)).toNat
  let mut keyedEntries := #[]
  for i in [0:n] do
    let pv := u64 entriesObj.b (entriesObj.o + 24 + 8*i)
    let p ← ctor "Name × Array EnvExtensionEntry" pv 0 2 0
    let extName ← decName (p.field 0)
    let arr ← obj "Array EnvExtensionEntry" (p.field 1)
    unless arr.tag == 246 do fail "entries" (p.field 1) "expected an Array"
    let k := (u64 arr.b (arr.o + 8)).toNat
    match decodeEntries, decoderFor extName with
    | true, some f =>
      let es ← decArray "Array EnvExtensionEntry" (p.field 1) f
      keyedEntries := keyedEntries.push (extName, es)
      stats.modify fun s => { s with
        entriesDecoded := s.entriesDecoded + k
        decodedExts := s.decodedExts.insert extName (s.decodedExts.getD extName 0 + k) }
    | _, _ =>
      stats.modify fun s => { s with
        entriesSkipped := s.entriesSkipped + k
        skippedExts := s.skippedExts.insert extName (s.skippedExts.getD extName 0 + k) }
  let entries := keyedEntries.map fun (e, es) => (e, es.map (·.2))
  unless constNames.size == constants.size do fail "ModuleData" v "constNames and constants differ in size"
  for n in constNames, c in constants do
    unless n == c.name do fail "ModuleData" v s!"constNames[i] = {n} but constants[i].name = {c.name}"
  let st ← get
  stats.modify fun s => { s with
    constants := s.constants + constants.size
    names := s.names + st.names.size
    levels := s.levels + st.levels.size
    exprs := s.exprs + st.exprs.size }
  return ({ isModule, imports, constNames, constants, extraConstNames, entries }, keyedEntries)

/-- Where a module's files are: the first search-path directory holding `<dir>/A/B.olean`. -/
def findOlean (sp : Array System.FilePath) (m : Name) : IO System.FilePath := do
  let rel := System.mkFilePath (m.components.map (·.toString (escape := false)))
  for d in sp do
    let p := (d / rel).addExtension "olean"
    if ← p.pathExists then return p
  throw <| IO.userError s!"olean reader: no .olean for module {m} on the search path"

/-- Loads all parts of a module that exist: `.olean`, then `.olean.server` and `.olean.private`. -/
def loadModule (sp : Array System.FilePath) (m : Name) : IO (Array Part) := do
  let f ← findOlean sp m
  let main ← loadPart f
  let s := f.addExtension "server"
  let p := f.addExtension "private"
  if (← s.pathExists) && (← p.pathExists) then
    return #[main, ← loadPart s, ← loadPart p]
  else if (← s.pathExists) || (← p.pathExists) then
    throw <| IO.userError s!"olean reader: {m} has only one of .olean.server / .olean.private"
  else
    return #[main]

def runDM (parts : Array Part) (x : DM α) : IO (α × DState) :=
  (x.run parts).run {}

/-- The imports of a module, read from its `.olean` alone. -/
def readImports (sp : Array System.FilePath) (m : Name) : IO (Array Import) := do
  let main ← loadPart (← findOlean sp m)
  let (is, _) ← runDM #[main] do
    let x ← ctor "ModuleData" main.root 0 5 1
    decArray "Array Import" (x.field 0) decImport
  return is

/-- The import closure in the order `importModulesCore` visits it (imports before importers). -/
partial def closure (sp : Array System.FilePath) (roots : Array Name) : IO (Array Name) := do
  let seen ← IO.mkRef ({} : NameSet)
  let out ← IO.mkRef (#[] : Array Name)
  let rec go (m : Name) : IO Unit := do
    if (← seen.get).contains m then return
    seen.modify (·.insert m)
    for i in ← readImports sp m do go i.module
    out.modify (·.push m)
  for r in roots do go r
  out.get

end OleanReader

=== Assemble.lean (old-environment and hybrid assembly)
import OleanReader
open Lean OleanReader

/-! Assembling an `Environment` in the running Lean from decoded `ModuleData`.
`ImportState`, `ImportedModule` and `CompactedRegion` keep their fields private; the structures
below mirror their layouts field for field and are cast with `unsafeCast`. -/

namespace Assemble

structure MRegion where
  filePath       : System.FilePath
  size           : USize
  isMemoryMapped : Bool
  baseAddr       : USize
  bufferOffset   : USize
  root           : NonScalar

structure MImportedModule extends EffectiveImport where
  parts        : Array (ModuleData × CompactedRegion)
  irParts      : Array (ModuleData × CompactedRegion)
  needsIRTrans : Bool

structure MImportState where
  moduleNameMap : Std.HashMap Name MImportedModule := {}
  moduleNames   : Array Name := #[]

/-- A region nothing points into; `Environment.freeRegions` is never called on these
environments. -/
unsafe def fakeRegion : CompactedRegion :=
  unsafeCast ({
    filePath := "<olean-reader>", size := 0, isMemoryMapped := false, baseAddr := 0
    bufferOffset := 0, root := unsafeCast (#[] : Array Nat) } : MRegion)

unsafe instance : Inhabited CompactedRegion := ⟨fakeRegion⟩

unsafe def decodedModule (m : Name) (md : ModuleData) : MImportedModule :=
  { module := m, importAll := true, isExported := false, isMeta := false, irPhases := .all
    hasData := true, parts := #[({ md with isModule := false }, fakeRegion)], irParts := #[]
    needsIRTrans := false }

unsafe instance : Inhabited MImportedModule := ⟨decodedModule .anonymous default⟩

structure Decoded where
  mods    : Array (Name × ModuleData)
  keyed   : Array (Name × Array Keyed)   -- extension name, keyed entries, over all modules
  stats   : ReadStats

/-- Decodes every module of the closure, one at a time, proofs omitted. -/
def decodeAll (sp : Array System.FilePath) (mods : Array Name) : IO Decoded := do
  let stats ← IO.mkRef ({} : ReadStats)
  let mut out := #[]
  let mut keyed : Std.HashMap Name (Array Keyed) := {}
  for m in mods do
    let parts ← loadModule sp m
    let ((md, ks), _) ← runDM parts (decModuleData true true parts.back!.root stats)
    out := out.push (m, md)
    for (e, es) in ks do
      keyed := keyed.insert e (keyed.getD e #[] ++ es)
  return { mods := out, keyed := keyed.toArray, stats := ← stats.get }

def checkMirror (s : MImportState) : IO Unit := do
  unless s.moduleNameMap.size == s.moduleNames.size do
    throw <| IO.userError s!"import state mirror: {s.moduleNameMap.size} map entries, {s.moduleNames.size} names"
  for n in s.moduleNames do
    unless s.moduleNameMap.contains n do throw <| IO.userError s!"import state mirror: {n} not in the map"

/-- The old environment alone: every module's decoded data, extension entries only for the
extensions the reader decodes. -/
unsafe def assembleOld (d : Decoded) : IO Environment := do
  let mut st : MImportState := {}
  for (m, md) in d.mods do
    st := { moduleNameMap := st.moduleNameMap.insert m (decodedModule m md), moduleNames := st.moduleNames.push m }
  checkMirror st
  enableInitializersExecution
  withImporting do
    finalizeImport (unsafeCast st) #[{ module := `Mathlib }] {} (leakEnv := true) (loadExts := true)

def whitelisted : NameSet := entryDecoders.foldl (fun s (n, _) => s.insert n) {}

/-- The key of a newest (natively imported) entry of a decoded extension, read at that
extension's entry type. -/
unsafe def newestKey (ext : Name) (e : EnvExtensionEntry) : Name :=
  let scp {α} (k : α → Name) : Name := scopedKey k (unsafeCast e : ScopedEnvExtension.Entry α)
  if ext == Name.mkNum `_private.Lean.Structure 0 ++ `Lean.structureExt then (unsafeCast e : StructureInfo).structName
  else if ext == `Lean.Meta.instanceExtension then scp (fun (i : Meta.InstanceEntry) => i.globalName?.getD .anonymous)
  else if ext == `Lean.classExtension then (unsafeCast e : ClassEntry).name
  else if ext == `Lean.Meta.coeExt || ext == `reducibilityExtra then scp (fun (p : Name × NonScalar) => p.1)
  else if ext == `Lean.protectedExt || ext == Name.mkNum `_private.Lean.Namespace 0 ++ `Lean.namespacesExt then
    (unsafeCast e : Name)
  else (unsafeCast e : Name × NonScalar).1

/-- The newest import, with every constant that the old version also has replaced by the old
`ConstantInfo` in place (same module index, so the newest IR and code stay addressable), old-only
constants in one extra module at the end, and — if `dataExts` — the decoded extensions' entries
replaced by the old ones, regrouped by the module index each key gets and sorted. -/
unsafe def assembleHybrid (d : Decoded) (dataExts : Bool) : IO (Environment × String) := do
  initSearchPath (← findSysroot)
  enableInitializersExecution
  let imports : Array Import := #[{ module := `Mathlib }]
  let (_, s) ← withImporting (importModulesCore imports |>.run)
  let ms : MImportState := unsafeCast s
  checkMirror ms
  let mut oldConsts : Std.HashMap Name ConstantInfo := {}
  let mut oldOrder : Array Name := #[]
  for (_, md) in d.mods do
    for n in md.constNames, c in md.constants do
      unless oldConsts.contains n do
        oldConsts := oldConsts.insert n c
        oldOrder := oldOrder.push n
  let mainPart (im : MImportedModule) : Nat :=
    if (im.parts[0]!.1).isModule then 2 else 0
  -- module index each name gets: first newest module listing it
  let mut idxOf : Std.HashMap Name Nat := {}
  for i in [0:ms.moduleNames.size] do
    let im := ms.moduleNameMap[ms.moduleNames[i]!]!
    if im.parts.isEmpty then continue
    for n in (im.parts[mainPart im]!.1).constNames do
      unless idxOf.contains n do idxOf := idxOf.insert n i
  let extraIdx := ms.moduleNames.size
  -- old entries per module index
  let mut perMod : Std.HashMap Nat (Std.HashMap Name (Array Keyed)) := {}
  if dataExts then
    for (e, es) in d.keyed do
      for k in es do
        let i := idxOf.getD k.1 extraIdx
        let m := perMod.getD i {}
        perMod := perMod.insert i (m.insert e (m.getD e #[] |>.push k))
  let mut oldKeys : Std.HashMap Name NameSet := {}
  for (e, es) in d.keyed do
    oldKeys := oldKeys.insert e (es.foldl (fun s k => s.insert k.1) {})
  let sortKeyed (ks : Array Keyed) : Array EnvExtensionEntry :=
    (ks.qsort (fun a b => Name.quickLt a.1 b.1)).map (·.2)
  let sortedEntries (i : Nat) : Array (Name × Array EnvExtensionEntry) :=
    (perMod.getD i {}).toArray.map fun (e, ks) => (e, sortKeyed ks)
  let mut keptNewest := 0
  let mut droppedNewest := 0
  let mut replaced : NameSet := {}
  let mut out := ms
  let mut nReplaced := 0
  let mut nDropped := 0
  for i in [0:ms.moduleNames.size] do
    let name := ms.moduleNames[i]!
    let im := ms.moduleNameMap[name]!
    if im.parts.isEmpty then continue
    let pi := mainPart im
    let (md, region) := im.parts[pi]!
    let mut cn := #[]
    let mut cs := #[]
    for n in md.constNames, c in md.constants do
      match oldConsts[n]? with
      | some oc =>
        if replaced.contains n then
          nDropped := nDropped + 1
        else
          replaced := replaced.insert n
          nReplaced := nReplaced + 1
          cn := cn.push n; cs := cs.push oc
      | none => cn := cn.push n; cs := cs.push c
    let mut entries := md.entries
    if dataExts then
      let olds := perMod.getD i {}
      let mut merged : Array (Name × Array EnvExtensionEntry) := #[]
      let mut seenExt : NameSet := {}
      for (e, es) in md.entries do
        if whitelisted.contains e then
          let ok := oldKeys.getD e {}
          let kept := es.filterMap fun x =>
            let k := newestKey e x
            if oldConsts.contains k || ok.contains k then none else some (k, x)
          keptNewest := keptNewest + kept.size
          droppedNewest := droppedNewest + (es.size - kept.size)
          merged := merged.push (e, sortKeyed (kept ++ olds.getD e #[]))
          seenExt := seenExt.insert e
        else
          merged := merged.push (e, es)
      for (e, ks) in olds.toArray do
        unless seenExt.contains e do merged := merged.push (e, sortKeyed ks)
      entries := merged
    let md' := { md with constNames := cn, constants := cs, entries }
    out := { out with moduleNameMap := out.moduleNameMap.insert name { im with parts := im.parts.set! pi (md', region) } }
  let mut xn := #[]
  let mut xc := #[]
  for n in oldOrder do
    unless replaced.contains n do
      xn := xn.push n; xc := xc.push oldConsts[n]!
  let extraName := `_olean_reader.OldOnly
  let extra : ModuleData := {
    isModule := false, imports := #[], constNames := xn, constants := xc,
    extraConstNames := #[], entries := if dataExts then sortedEntries extraIdx else #[] }
  out := {
    moduleNameMap := out.moduleNameMap.insert extraName (decodedModule extraName extra)
    moduleNames := out.moduleNames.push extraName }
  checkMirror out
  enableInitializersExecution
  let env ← withImporting do
    finalizeImport (unsafeCast out) imports {} (leakEnv := true) (loadExts := true)
  let msg := s!"hybrid: newest modules {ms.moduleNames.size}, old constants {oldConsts.size}, replaced in place {nReplaced}, later duplicates dropped {nDropped}, old-only {xn.size} (extra module), data extensions old: {dataExts} (newest entries kept for keys the old version lacks {keptNewest}, replaced {droppedNewest})"
  return (env, msg)

end Assemble

/-- `read <searchpath-file> <limit|all> <omit-proofs:0|1> <oracle.jsonl|-> <out-types.jsonl|->`:
reads every module of `Mathlib`'s closure once, one module at a time. -/
def readMode (spFile limitS omitS oracle outTypes : String) : IO UInt32 := do
  let sp ← readSearchPath spFile
  let omitP := omitS == "1"
  let t0 ← nowMs
  let mods ← closure sp #[`Mathlib]
  let t1 ← nowMs
  let mods := if limitS == "all" then mods else mods.extract 0 limitS.toNat!
  IO.eprintln s!"closure {mods.size} modules in {t1 - t0} ms"
  let mut wanted : Std.HashMap Name Unit := {}
  let mut oracleRecs : Array (Name × String) := #[]
  if oracle != "-" then
    for line in ← IO.FS.lines oracle do
      if line.isEmpty then continue
      let j ← IO.ofExcept (Json.parse line)
      let nameS ← IO.ofExcept (j.getObjValAs? String "nameStr")
      let ty ← IO.ofExcept (j.getObjVal? "type")
      let nj ← IO.ofExcept (j.getObjVal? "name")
      let n := (← IO.ofExcept nj.getArr?).foldl (init := Name.anonymous) fun acc c =>
        match c with
        | .str s => Name.mkStr acc s
        | .num k => Name.mkNum acc k.mantissa.toNat
        | _ => acc
      unless n.toString == nameS do throw <| IO.userError s!"name decode mismatch {n} vs {nameS}"
      wanted := wanted.insert n ()
      oracleRecs := oracleRecs.push (n, ty.compress)
  let stats ← IO.mkRef ({} : ReadStats)
  let mut found : Std.HashMap Name String := {}
  let mut ioMs := 0
  let mut decMs := 0
  let mut bytes := 0
  let mut objects := 0
  let mut red3Core := 0
  let mut red3Other := 0
  for m in mods do
    let a ← nowMs
    let parts ← loadModule sp m
    let b ← nowMs
    let root := parts.back!.root
    let ((md, ks), st) ← runDM parts (decModuleData omitP true root stats)
    let isCore := [`Init, `Std, `Lean, `Lake].contains m.getRoot
    for (e, es) in ks do
      if e == `reducibilityCore then
        for (_, x) in es do
          let p : Name × ReducibilityStatus := unsafe unsafeCast x
          if p.2 == .instanceReducible then
            if isCore then red3Core := red3Core + 1 else red3Other := red3Other + 1
    let c ← nowMs
    ioMs := ioMs + (b - a)
    decMs := decMs + (c - b)
    bytes := bytes + parts.foldl (· + ·.bytes.size) 0
    objects := objects + st.objects
    if !wanted.isEmpty then
      for ci in md.constants do
        if wanted.contains ci.name && !found.contains ci.name then
          found := found.insert ci.name (serialize ci.type).1.compress
  let s ← stats.get
  IO.eprintln s!"modules {mods.size}, bytes {bytes}, objects visited {objects}, constants {s.constants}, entries decoded {s.entriesDecoded}, entries not decoded {s.entriesSkipped} in {s.skippedExts.size} extensions"
  IO.eprintln s!"time: file reads {ioMs} ms, decoding {decMs} ms"
  IO.eprintln s!"reducibility value 3 read as instanceReducible: core modules {red3Core}, other modules {red3Other}"
  IO.eprintln s!"checked against the stored computed field: Name hashes {s.names}, Level data {s.levels}, Expr data {s.exprs}"
  for (e, k) in s.decodedExts.toArray.qsort (fun a b => a.1.toString < b.1.toString) do
    IO.eprintln s!"  decoded ext {e} {k}"
  for (e, k) in s.skippedExts.toArray.qsort (fun a b => a.2 > b.2) do
    IO.eprintln s!"  not decoded ext {e} {k}"
  if oracle != "-" then
    let mut same := 0
    let mut missing := 0
    let mut diff := #[]
    for (n, ty) in oracleRecs do
      match found[n]? with
      | none => missing := missing + 1
      | some t => if t == ty then same := same + 1 else diff := diff.push n
    IO.println s!"oracle: identical {same} of {oracleRecs.size}; not found {missing}; different {diff.size}"
    for n in diff.extract 0 10 do IO.println s!"  different: {n}"
  if outTypes != "-" then
    let h ← IO.FS.Handle.mk outTypes .write
    for (n, _) in oracleRecs do
      if let some t := found[n]? then h.putStrLn t
  return 0

def diagnoseOne (e : Expr) : MetaM String := do
  let stage (what : String) (x : MetaM String) : MetaM String :=
    tryCatchRuntimeEx x (fun ex => do return s!"{what} failed: {← ex.toMessageData.toString}")

def diagnose (env : Environment) (printOut : String) (k : Nat) : IO Unit := do
  let mut n := 0
  for line in ← IO.FS.lines printOut do
    if n ≥ k then break
    let j ← IO.ofExcept (Json.parse line)
    let pp := (j.getObjValAs? String "newPp").toOption.getD ""
    unless (pp.splitOn "failed to pretty print").length > 1 do continue
    n := n + 1
    let nameS ← IO.ofExcept (j.getObjValAs? String "nameStr")
    let some ci := env.find? nameS.toName | IO.eprintln s!"diag {nameS}: not found"; continue
    let msg ← try runMeta env (diagnoseOne ci.type) catch ex => pure s!"io: {ex}"
    IO.eprintln s!"diag {nameS}: {msg.take 600}"

  let mods := match (← IO.getEnv "U9_LIMIT").bind String.toNat? with
    | some k => mods.extract 0 k

  return 0

  let sp ← readSearchPath spFile
  let t0 ← nowMs

  let t1 ← nowMs
  IO.eprintln s!"decoded {d.mods.size} modules in {t1 - t0} ms"

  let t2 ← nowMs

    pure ()
  lookupAll env oracle lout

  let r ← newSide env oracle pout limitS.toNat!
  let t4 ← nowMs
  IO.eprintln s!"print {t4 - t3} ms"
  diagnose env pout 12
  return r

def rangeJ (r : DeclarationRange) : Json :=

def kindStr : ConstantInfo → String
  | .axiomInfo _ => "axiom" | .defnInfo _ => "defn" | .thmInfo _ => "thm" | .opaqueInfo _ => "opaque"
  | .quotInfo _ => "quot" | .inductInfo _ => "induct" | .ctorInfo _ => "ctor" | .recInfo _ => "rec"

def lookupCore (n : Name) : CoreM Json := do
  let env ← getEnv
  match env.find? n with
  | none => return Json.mkObj [("name", Json.str n.toString), ("found", toJson false)]
  | some ci =>
    let isStruct := isStructure env n
    let fields := if isStruct then (getStructureFieldsFlattened env n (includeSubobjectFields := false)).map (Json.str ·.toString) else #[]
    let ranges ← findDeclarationRanges? n
    let rangesJ := match ranges with
      | none => Json.null
      | some r => Json.arr #[rangeJ r.range, rangeJ r.selectionRange]
    let red ← getReducibilityStatus n
    let proj := match env.getProjectionFnInfo? n with
      | none => Json.null
      | some p => Json.arr #[Json.str p.ctorName.toString, toJson p.numParams, toJson p.i, toJson p.fromClass]
    let coe ← Meta.getCoeFnInfo? n
    let coeJ := match coe with
      | none => Json.null
      | some c => Json.arr #[toJson c.numArgs, toJson c.coercee, Json.str (reprStr c.type)]
    let mut eqns : Array Json := #[]
    let mut k := 1
    while true do
      match env.find? (Name.str n s!"eq_{k}") with
      | some e => eqns := eqns.push (Json.str (serialize e.type).1.compress); k := k + 1
      | none => break
    let eqDef := (env.find? (Name.str n "eq_def")).map fun e => (serialize e.type).1.compress
    let modName := match env.getModuleIdxFor? n with
      | some i => Json.str (env.header.moduleNames[i.toNat]!).toString
      | none => Json.null
    return Json.mkObj [
      ("name", Json.str n.toString), ("found", toJson true), ("kind", Json.str (kindStr ci)),
      ("levelParams", Json.arr (ci.levelParams.toArray.map (Json.str ·.toString))),
      ("type", Json.str (serialize ci.type).1.compress),
      ("isStructure", toJson isStruct), ("isClass", toJson (isClass env n)),
      ("isInstance", toJson (Meta.isInstanceCore env n)), ("fields", Json.arr fields),
      ("ranges", rangesJ), ("reducibility", Json.str (reprStr red)), ("projInfo", proj), ("coe", coeJ),
      ("protected", toJson (isProtected env n)), ("eqns", Json.arr eqns),
      ("eqDef", match eqDef with | some s => Json.str s | none => Json.null),
      ("module", modName)]
