      𝒜 is U+1D49C, above U+FFFF. That is where a site comes apart if one half of it counts characters differently from the other: the pages are written by a program that walks UTF-8, the search index is sorted in a browser that walks UTF-16, and the two orders agree everywhere except above U+FFFF. Search for 𝒜 and the entry is where the sort says it is.
